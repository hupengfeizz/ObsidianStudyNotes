# 任务:把 get_bev 的 RGB 换成 ResNet 特征图

## 一、背景(给新对话的上下文)

- 已完成:老师的 `get_bev.py`(逆向 IPM 查表法)已在 nuScenes mini 上跑通,输出正确——近处地面箭头/车道线被掰回俯视形状,远处立体物呈放射状拉丝(地面假设失效的正常表现),V 字形视野边界正确。
- 该代码的本质:在 BEV 网格(400×400,X 0~40m,Y ±20m,Z=0 地面假设,RES=0.1)铺 16 万点 → 地图系→自车系(手推 2D 刚体变换)→ 自车系→相机系(外参 Rt_full)→ 相机系→像素(内参 K,除 Zc)→ 双线性插值从原图取 RGB 填回 BEV 格子。属于 **gather / pull** 路线。
- 本任务定位:四点技术实践计划之外的一个补充练习,含金量高——把"查颜色"换成"查特征",同一套查表逻辑立刻变成真正的 **BEV feature 提取**,与 LSS/BEVFusion 的 view transform 只差"深度是假设的还是学出来的"。
- 学习约定:**这个任务可以直接提供完整代码**(涉及 PyTorch/torchvision 的用法我还在学习中),但请配合逐块讲解,让我理解每一步在做什么;讲解优先于代码量。

## 二、核心思路(一句话)

图像先过 ResNet backbone 得到 C 通道特征图,然后用**同一张查找表**(u, v 需按下采样倍数缩放)对特征图做双线性采样,输出 400×400×C 的 BEV 特征,最后想办法可视化验证。

## 三、流程分解

1. **提特征**:图像 → ResNet18(torchvision 预训练)→ 取中间某层输出。
   - 建议取 layer2 或 layer3 的输出(下采样 8x 或 16x),太深的层空间分辨率太低,BEV 会糊。
   - 输入图像需按 torchvision 惯例做 normalize(ImageNet 均值方差)。
2. **缩放查找表坐标(第一个坑)**:
   - 原查找表的 u、v 是按原图 900×1600 算的;特征图只有原图的 1/8 或 1/16 大小。
   - u、v 必须**除以下采样倍数**再去采样,否则全部采到特征图左上角一小块。
   - mask 的越界判断也要改成按特征图尺寸判断(或直接沿用原图尺寸判断后再缩放,二选一,想清楚哪个对)。
3. **采样**:两条路线任选。
   - **numpy 路线**:沿用 `map_coordinates`,把 C 通道摊平的技巧(transpose + reshape)照搬,只是 C 从 3 变成 128/256。
   - **PyTorch 路线(推荐)**:用 `F.grid_sample`。需要把 u、v 归一化到 [-1, 1](公式:`2*u/(W-1) - 1`),坐标 reshape 成 (1, 400, 400, 2),特征图为 (1, C, h, w)。这条路线的价值:grid_sample 可反向传播,正是真实 BEV 网络里用的算子。
4. **可视化(第二个坑)**:
   - 特征值是有正有负的浮点数,不能直接当图像存,直接存会一片黑。
   - 常见做法:取任意 3 个通道当 RGB,或对 C 维做 PCA 降到 3 维,再 min-max 归一化到 0~255。
   - 验收标准:BEV 特征图上应能看出**与彩色 BEV 图一致的空间结构**(车道线位置、视野 V 字边界、mask 黑区),纹理内容不同没关系。

## 四、预期的正确结果长什么样

- 空间布局与彩色 BEV 完全一致:同样的 V 字视野、同样的 mask 黑区、车道线在同样的位置出现响应。
- 远处同样有拉丝——地面假设没变,失效方式也不变。
- 如果整张图错位/缩成一角:九成是 u、v 没除下采样倍数,或除错了。
- 如果全黑:检查 mask 是否全零、归一化是否做反。

## 五、与面试的连接点

- 做完这个,就可以说:"我用地面假设版的 view transform 亲手生成过 BEV feature,和 LSS 的差别只在深度来源——它把 Z=0 换成 DepthNet 预测的深度分布,把单点采样换成沿射线的软分配(外积 + splat)。"
- grid_sample 归一化坐标、下采样倍数对齐,都是真实工程里天天碰的细节,被追问时有实操细节可讲。

## 六、环境

- 本地 4060,ResNet18 单图推理毫秒级,无压力。
- 依赖:torch、torchvision(grid_sample 路线);或继续 scipy(numpy 路线)。
- 基准:先保留彩色 BEV 输出作对照,同一帧图并排比较。

## 七、建议的动手顺序

1. 先写 ResNet 提特征那几行,打印特征图 shape,确认下采样倍数。
2. 把查找表 u、v 缩放,先用 numpy 路线跑通(改动最小)。
3. 可视化验收。
4. 再换成 grid_sample 路线重写一遍(为了学这个算子本身)。
5. (可选延伸)特征图后面接一个随机初始化的 1×1 卷积压到 3 通道看看,体会"BEV feature 接头"的感觉。
