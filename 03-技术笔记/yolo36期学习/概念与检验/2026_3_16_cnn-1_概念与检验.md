## 一、本节新概念 / 知识 / 原理清单

按视频时间顺序。**"熟"栏自己填**：✓ 说得出 / ？ 有印象说不清 / ✗ 完全空白。

### A. CNN 学到了什么（00:03:00 – 00:31:00）

| 概念 | 一句话 | 熟 |
|---|---|---|
| 特征图可视化 vs CAM | 老师展示的是**逐通道特征图**（类别无关）；CAM/Grad-CAM 是**按类别梯度加权**的类激活图（类别相关）。⚠ 老师把两者混为一谈 | |
| 浅层 = 几何特征 | 前几层学到的是边缘、梯度、纹理这类几何信息，人眼能看懂 | |
| 深层 = 语义特征 | 越深越抽象，**你看不懂才对**——它编码的是"这是猫"这类语义 | |
| CNN 的本质 | W 学的是"几何 → 语义"的映射 | |
| 多通道 = 多角度观察 | 同一目标被多个核从不同角度提特征 | |
| 通道数经验值 | 浅层 8/16/32，深层可到 2048；过多 → 信息过载 | |
| 浅层的副作用 | 噪声多 → 误检多 | |
| 特征工程的身份 | 不是替代网络，而是**强化先验**帮 W 更好地映射；过度做 → 垃圾数据 | |

### B. 小目标三板斧（00:31:00 – 00:44:03）★老师明说"每场面试都会问"

| 概念 | 一句话 | 熟 |
|---|---|---|
| 板斧一 | 把特征变清晰、变大（提高输入分辨率 / 浅层出检测头） | |
| 板斧二 | 减网络层数（少下采样，保住小目标的像素） | |
| 板斧三 | 增加通道数 | |

### C. 池化与反向传播（01:05:00 – 01:14:00）

| 概念 | 一句话 | 熟 |
|---|---|---|
| max pooling 反传 | 梯度**原位回填到 argmax 位置**，同窗口其余填 0 | |
| avg pooling 反传 | 梯度**均分**，每个位置得 1/k² | |
| 池化层无参数 | ⚠ 老师说"W 应该是 1、梯度我没查"——**池化根本没有 W**，只做梯度路由 | |
| 现代网络少用池化 | 改用 stride=2 的卷积下采样（可学习，信息损失小） | |

### D. 参数量与算力（01:22:00 – 01:58:01）★本节算术核心

| 概念 | 一句话 | 熟 |
|---|---|---|
| 参数量公式 | `W_count = Kh × Kw × Cin × Cout` | |
| 参数量与输入尺寸无关 | 公式里没有 H、W——这是权重共享的直接推论 | |
| FLOPs 公式 | `Ho × Wo × Cout × (Cin × Kh × Kw) × 2` | |
| 为什么 ×2 | 一次乘加 = 一次乘 + 一次加 = 两次浮点运算 | |
| im2col | 卷积在底层被展开成**矩阵乘**（这才是 GPU 跑得快的原因） | |
| 稀疏连接 | 一个输出节点只连 `Kh×Kw×Cin` 条边，不是全连接 | |
| 权重共享 | 同一套核滑过全图；老师说"90% 的人答不上来"的绝杀题 | |
| 神经元 ≠ 特征图像素 | 概念之争，面试按"一个输出位置对应一次线性变换"讲 | |

### E. 感受野与 1×1（02:00:00 – 02:40:00）

| 概念 | 一句话 | 熟 |
|---|---|---|
| 感受野 | 一个输出位置能"看到"的原图范围 | |
| 感受野要匹配目标大小 | 大目标要大感受野，小目标要小感受野（否则被背景噪声淹没） | |
| 2 个 3×3 = 1 个 5×5 | 感受野相同、参数更少（18C² vs 25C²）、多一次非线性。⚠ 老师先说"不同"后自我更正 | |
| 输出尺寸公式 | `Out = ⌊(In + 2p − k)/s⌋ + 1`（3_11 讲过，这里复用） | |
| 1×1 卷积六大作用 | 升降通道 / 跨通道融合 / 加非线性 / 替代 FC / 压缩还原降参 / 对齐分支通道 | |
| 压缩-还原的坑 | 中间通道设太大**反而增参**（课上算例 73,728 → 19,456 是降到 1/4；中间设 64 反而变 77,824） | |
| GAP 全局平均池化 | `7×7×512 → 1×1×512`，干掉全连接层的上亿参数 | |
| 一卷到底 | 用 1×1 完全替代 FC | |

### F. 卷积家族与上采样（02:41:00 – 03:20:00）

| 概念 | 一句话 | 熟 |
|---|---|---|
| 分组卷积 `groups=G` | 参数降到 1/G，但**组间通道不沟通会掉点** | |
| FLOPs 少 ≠ 延迟低 | GPU 上标准 3×3 算力利用率最高（RepVGG/ConvNeXt 那条线的结论） | |
| 深度可分离卷积 | `groups = Cin = Cout`，每通道独立卷（DW） | |
| DW 后必接 PW | 必须跟 1×1（PW）把通道信息重新混合，否则通道永不交流 | |
| 空洞卷积 `dilation` | 参数不变、感受野变大；但最多堆 2~3 层（栅格效应） | |
| 转置卷积 | `nn.ConvTranspose2d`，把 im2col 反过来做；带参数、有棋盘伪影 | |
| 上采样三方法 | nearest（复制）/ bilinear（插值）/ 转置卷积（可学习） | |
| 鬼影/伪影 | nearest 产生块状鬼影 → YOLOv5 里换 bilinear 即可缓解 | |
| bi / tri 的含义 | ⚠ 老师讲反了：bi/tri 指的是**维度数**（2D/3D），不是"求了三次" | |

## 三、参考答案与判分要点（答题时先别看）

**Q1** `128 × 256 × 3 × 3 = 294,912`。公式 `Cin × Cout × Kh × Kw`。含 bias 则 295,168。

**Q2** **不变**。公式里没有 H、W——权重共享的直接推论：同一套核滑过整张图。变的是输出尺寸和 FLOPs。
（老师原题，01:41:01。答"变"说明没抓住权重共享。）

**Q3** `32×32×256×(128×3×3)×2 ≈ 6.04×10⁸`（约 6 亿次）。×2 = 一次乘加算两次浮点运算。
⚠ 老师在 01:36:20 念了 DeepSeek 标注"这个数太大"的 339 亿那个错数字，该页正确值是 5.3 亿。

**Q4 ⚠ 老师讲错** max：梯度原位回填到 argmax，其余填 0；avg：均分，各得 1/k²。
**池化层没有权重，不需要更新**——无参算子，反向只做梯度路由。
老师 01:17:01 说"W 应该是 1、梯度我也不知道没查"。**这是本节唯一会让人面试翻车的点。**

**Q5** 感受野**一样**（都 5×5）；参数 2 个 3×3 更少（18C² vs 25C²，省 28%）；且多一次非线性。
⚠ 老师 02:12:36 先说"感受野不同"，随即自我更正为"一样"。

**Q6** 六个里说出三个即可：升降通道 / 跨通道融合 / 加非线性 / 替代 FC / 压缩还原降参 / 对齐分支通道。
后半：中间通道太大**反而增参**——课上算例 73,728 → 19,456（降到约 1/4、省 74%），
但中间设 64 时变成 77,824，比原来还多。行业惯例压到 1/4。
⚠ 老师 02:20:17 把"少 74%"说成"少了三分之一"。

**Q7** ①把特征变清晰变大（提分辨率 / 浅层出头）②减层数（少下采样保住小目标像素）③增通道数。
判分：这三条老师明说面试必问，答不全要回看 00:31:01–00:44:03（13 分钟，值得精听）。

**Q8** 朴素分组**组间不沟通会掉点**，且 FLOPs 少 ≠ 延迟低（GPU 上标准 3×3 算力利用率最高）。
极限特例是**深度可分离卷积 DW+PW**，仍是轻量化主力（MobileNet 系）。
⚠ 老师 02:44:52 说"分组基本不会用"、02:47:05 又说"深度可分离还在用"，表述冲突。

**Q9** DW 是每个通道独立卷，**通道之间完全没有信息交流**。必须接 1×1（PW）做跨通道混合，
否则网络等于 C 个互不相干的单通道网络，表达能力大幅下降。

**Q10** 改 `models/yolov5*.yaml` 的 head：
`[-1, 1, nn.Upsample, [None, 2, 'nearest']]` → 把 `'nearest'` 换成 `'bilinear'`。
（本节唯一真实代码画面，03:13:02）nearest 是复制像素→块状鬼影；bilinear 做插值更平滑。

**Q11** 栅格效应（gridding）：dilation 让核跳着采样，堆多层后某些像素**永远采不到**，
形成棋盘状的信息空洞。所以一般最多 2~3 层，或用混合 dilation rate。

**Q12** im2col 把每个滑窗位置的局部块**展平成一列**，整张图变成一个大矩阵，
卷积就等于「核矩阵 × 展开矩阵」的一次矩阵乘。意义：GPU 的 GEMM（矩阵乘）是最优化到极致的算子，
把卷积转成 GEMM 才能吃满算力——这也是"FLOPs 少 ≠ 快"的底层原因。

**Q13 ⚠ 老师讲错** 不是一回事。老师展示的是**逐通道特征图可视化**（类别无关，直接看某层某通道的激活）；
**CAM/Grad-CAM 是类别相关的**——按目标类别的梯度对通道加权求和，回答"模型认为图里哪块让它判成猫"。
面试要区分，答混了会被追问。

**Q14** 浅层核只做局部小范围的加权，学到的是边缘/梯度/纹理这类**几何**信息，可视化出来像素描；
越深经过多次组合抽象，编码的是"有没有猫脸""是不是轮子"这类**语义**信息，
在像素空间没有直观对应物，所以人眼看不懂。这正好说明 **CNN 的 W 学的是"几何 → 语义"的映射**。

**Q15 ⚠ 老师讲反** bi/tri 指的就是**维度数**：bilinear = 2D（x、y 两个方向做线性插值），
trilinear = 3D 体数据（x、y、z）。双线性内部确实做 3 次单线性插值，但那不是命名来源。
**2D 图像上采样一律用 bilinear。**
老师 03:22:56 说"就是求了三次，不是三个维度"——反了。
