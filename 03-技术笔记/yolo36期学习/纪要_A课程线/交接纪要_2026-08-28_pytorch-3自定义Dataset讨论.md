## 二、已讨论并确认的点

1. **index 发牌机制**:sampler 无放回随机发牌,一个 epoch 每条数据恰好一次。用户已确认理解"无放回"。
2. **一个真疑问及其解**:用户觉得"课程说 Dataset 随机取数"与"顺序由 DataLoader 控制"冲突。澄清结论——**Dataset 三件套里没有一行随机代码,getitem 给几返回几,完全被动;老师说的"随机取一个数"省略的主语是 DataLoader 的 sampler**。口诀:发牌员决定顺序,Dataset 只是被动查表。想要顺序,Dataset 什么都不用改,shuffle=False 即可。
3. **验证集 shuffle=False**:用户自己推理正确——验证只求指标,顺序不影响结果;附加收益:每次评测顺序一致、便于对拍。
4. **反向检验题(用户答对)**:若 getitem 偷偷随机取而不老实返回第 index 条 → DataLoader 的顺序意图被覆盖;且同一 epoch 有的样本被抽多次、有的一次没有,无放回保证失效,验证不可复现。
