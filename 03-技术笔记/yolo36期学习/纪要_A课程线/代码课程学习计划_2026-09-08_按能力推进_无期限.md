### 动手任务

1. 用 P3 天气数据；附件不可用时，用已有且标签明确的小型图片分类数据替代。后续 P8、J5 继续复用，不为每一课换数据集。

### 验收标准

- [ ] `dataset[0]` 和一个 batch 均能显示图片及正确标签；训练/验证样本不交叉。
- [ ] 保存划分清单与类别映射，重复启动后划分不变。相关连拍或同源样本按组划分，避免随机拆散产生泄漏。
- [ ] 训练集和验证集分别绑定各自的 transform；验证集没有训练用的随机增强。
- [ ] 在关闭随机增强的小样本上，训练 loss 明显下降、分类准确率接近100%；达不到先定位，不靠盲目加 epoch。
- [ ] 统计 loss/accuracy 时正确累计样本数，最后不足一整批也不会算错。
- [ ] 新进程重新加载保存的权重与类别映射，固定输入的预测与保存前一致或在数值误差内一致。
- [ ] 至少能根据一次实际报错定位到读取、shape、设备或标签中的具体问题；没有遇到报错，不为凑记录故意制造。

## 5. 阶段2：把 CNN 模块写成能复用的代码

### 2A. J1 只取残差结构

材料：[第J1周：ResNet-50算法实战与解析](../../../../%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A/%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A_365%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%96%87%E6%A1%A3/365-%E8%BF%9B%E9%98%B6%E8%90%A5/1.CNN%E7%AE%97%E6%B3%95%E8%A7%A3%E6%9E%90/%E7%AC%ACJ1%E5%91%A8%EF%BC%9AResNet-50%E7%AE%97%E6%B3%95%E5%AE%9E%E6%88%98%E4%B8%8E%E8%A7%A3%E6%9E%90.md)。不要求完整复现和训练 ResNet50。

验收：两种残差路径均能前向与反向；能在相加前写出两路 shape；能解释何时必须投影。已有两份模板若能通过检查，直接复用。

## 6. 阶段3：SE 单模块必做，DenseNet 全套暂缓

材料：[第J5周：SE注意力机制](../../../../%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A/%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A_365%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%96%87%E6%A1%A3/365-%E8%BF%9B%E9%98%B6%E8%90%A5/1.CNN%E7%AE%97%E6%B3%95%E8%A7%A3%E6%9E%90/%E7%AC%ACJ5%E5%91%A8%EF%BC%9ASE%E6%B3%A8%E6%84%8F%E5%8A%9B%E6%9C%BA%E5%88%B6.md)，选择新版 PyTorch 代码。

先按概念写 `SEBlock`：全局平均池化 → 降维 → 激活 → 升维 → sigmoid → 通道广播相乘。随后接入阶段1的小 CNN，保留无 SE 的基线配置。

验收：

- [ ] 能标出 `[B,C,H,W] → [B,C] → [B,C,1,1] → [B,C,H,W]` 的变化。
- [ ] 输入输出形状不变，至少覆盖两种通道数与非正方形输入。
- [ ] 降维通道不为0；明确参数合法范围或使用下界保护。
- [ ] 反向传播后 SE 参数有有限梯度，优化步骤后至少一个可学习参数发生变化。
- [ ] 同一划分与训练设置下跑基线和 SE 版本，记录结果。没有涨点也可以通过，重点是模块正确接入、结论如实。
- [ ] 不看课程代码能重写模块，并说明“层参数通过训练学习，当前图片的通道权重由前向计算产生”。

**不要求先做 J2/J3/J4，不要求复现 DenseNet，不要求89%。** 此处的 SE 接入只是练手；后续真仓库改动继续服务你的 YOLO 项目。

## 7. 阶段4：补上课程之外最需要的检测数据练习

### 4A. 检测 Dataset、变长标签与画框

材料：[YOLOv8白皮书-1.训练自己的数据集](../../../../%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A/%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A_365%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%96%87%E6%A1%A3/365-%E8%BF%9B%E9%98%B6%E8%90%A5/3.YOLO%E7%99%BD%E7%9A%AE%E4%B9%A6/%E6%97%A7%E5%86%85%E5%AE%B9/YOLOv8%E7%99%BD%E7%9A%AE%E4%B9%A6-1.%E8%AE%AD%E7%BB%83%E8%87%AA%E5%B7%B1%E7%9A%84%E6%95%B0%E6%8D%AE%E9%9B%86.md) 的数据准备和标签转换部分，配36期目标检测入门。

- [ ] 用同一套固定划分生成仓库需要的数据配置，不重新随机划分。

不在这一步扩展 Mosaic 等复杂增强，也不用自己的教学 Dataset 替换整个 YOLO 数据加载器。

### 4B. IoU + NMS

听完36期 `4_17` 的解码/NMS 后做；若视频未到，可以先完成4A并进入阶段5的基线部分。

## 9. 阶段6：只做一项真仓库改动，再决定是否扩展

前置：阶段5基线通过。材料以 J5 为模块参考；[第Y2周｜YOLOv12：添加SE注意力机制](../../../../%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A/%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A_365%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%96%87%E6%A1%A3/365-%E8%BF%9B%E9%98%B6%E8%90%A5/3.YOLO%E7%99%BD%E7%9A%AE%E4%B9%A6/%E7%AC%ACY2%E5%91%A8%EF%BD%9CYOLOv12%EF%BC%9A%E6%B7%BB%E5%8A%A0SE%E6%B3%A8%E6%84%8F%E5%8A%9B%E6%9C%BA%E5%88%B6.md) **只借鉴“模块定义—导入—解析—yaml接入”的操作思路**，不运行其 v12 模型，也不直接粘贴其 `tasks.py` 修改到 v8。

## 10. 支线 A：注意力只练必要模块，不刷 NLP 全套

材料：[第TR2周：图解Self-Attention与Multi-HeadAttention](../../../../%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A/%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A_365%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%96%87%E6%A1%A3/365-%E8%BF%9B%E9%98%B6%E8%90%A5/6.Transformer%E7%99%BD%E7%9A%AE%E4%B9%A6/%E7%AC%ACTR2%E5%91%A8%EF%BC%9A%E5%9B%BE%E8%A7%A3Self-Attention%E4%B8%8EMulti-HeadAttention.md) 和 [第TR3周：Pytorch复现Transformer](../../../../%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A/%E5%B0%8F%E7%BA%A2%E4%B9%A6K%E5%90%8C%E5%AD%A6%E5%95%8A_365%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%96%87%E6%A1%A3/365-%E8%BF%9B%E9%98%B6%E8%90%A5/6.Transformer%E7%99%BD%E7%9A%AE%E4%B9%A6/%E7%AC%ACTR3%E5%91%A8%EF%BC%9APytorch%E5%A4%8D%E7%8E%B0Transformer.md) 的 shape 变化、Scaled Dot-Product Attention、多头注意力部分。

配合36期 `3_27`、`3_29`、`4_1`，自己写带 batch 的单头，再拆头/合头，最后增加一次 Q 与 K/V 长度不同的 cross-attention。

验收：

- [ ] self-attention 输入 `[B,N,D]`、输出 `[B,N,D]`；能解释 softmax 的轴与缩放因子。
- [ ] 多头中 scores 为 `[B,H,Nq,Nk]`，不能把 token 数和每头维度混淆。
- [ ] Q 长度与 K/V 长度不同仍能运行，输出序列长度等于 Q 的长度。
- [ ] 掩码确实传入并改变被遮挡位置的注意力权重；测试样例避免一整行全部遮挡。
- [ ] 能反向传播；将权重、布局等条件对齐后，与框架实现或清晰的单头参考计算对拍。

不要求整套 Transformer 翻译/文本分类训练；TR1 当结构字典，TR5/TR6 暂缓。这个练习建立注意力张量直觉，**不能替代 BEVFormer 专门的空间、时序与采样机制学习**。

## 13. 使用答案与课程代码的规则

先读任务与结构，自己写接口和关键步骤；卡住后只看相关函数，关闭答案再复写，并主动改一次通道、尺寸、数据或模块位置。可以查 API，不要求背库函数签名。请助手协助时先要错误定位或局部提示，避免整份答案替代自己的首次尝试。

抽查发现的几个具体阅读点，练到对应课时再处理：

- **P8：**`C3(32,64,3,2)` 的第四个位置参数对应 `shortcut`，不是 stride。自己的实现用关键字参数。原分类头有 `802816 → 100` 的大线性层，没有必要为此消耗训练资源。
- **P8/P9：**对同一个带训练 transform 的 Dataset 做 `random_split`，不会自动让验证子集使用单独声明的 `test_transform`。加入随机增强时尤其要检查实际绑定关系。
- **P9：**文中声明主干有删改，又接了分类头；不能把它当完整 YOLO 检测器。卷积 padding 和线性层输入维度要依据自己的 shape 验证。
- **TR3：**抽查到 `MultiHeadAttention.forward` 接收 `mask`，但调用 `ScaledDotProductAttention` 时未传入；有些 shape 注释也不准确。自己实现时要实际验证 mask 与 Q/K 不同长度。
- **v8 旧文：**有路径或描述沿用 v5 的情况；以固定运行版本中的实际符号为准。这里只规划任务，安装和修改时再核对该版本接口。

这些是局部代码检查结论，不是全部问题清单。训练脚本能运行之后，仍要检查划分、标签、梯度与评估，不能只看曲线。
