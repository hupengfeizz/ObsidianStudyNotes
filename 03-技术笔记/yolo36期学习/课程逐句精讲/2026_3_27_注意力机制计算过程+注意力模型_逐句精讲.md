**一句话主旨**：注意力机制就是一个**观察者模型**——观察者带着问题（Q）去看被观察者的外在特征（K），算出一个和为 1 的权重分布，再拿这个分布去加权提取被观察者的内在信息（V）；整个过程只有三步，其中**只有第一步（QKV = 三个全连接）有权重要训练**，后两步是纯固定运算。

## Part 1 · 复习：RNN 的循环边、时序数据、LSTM 三条门（00:00:00 – 00:12:03）

**【本段在讲什么】** 谢博用 12 分钟把上节课的 RNN 线索重新串一遍，串法是"两个问题 + 三件事"：RNN **怎么做的**（循环边 + 可自定义 module）、**为什么要有**（解决时序问题）、以及具体例子 **LSTM**（三条门）。最后落到 "Why not RNN" 三条理由，把今天的主角——注意力——推上台。这一段本身干货不多，但它示范了一种复习方法：**先给知识点分类，再往类里填内容**，这正是他反复强调的"有逻辑的输出"。

### 01 上节课讲了三件事：怎么做、为什么、一个具体例子（00:00:00 – 00:01:35）

> **谢博**：「上节课讲了什么呀？讲的循环神经网络。讲了两个问题：第一个怎么做的，第二个为什么。就讲这两个问题啊。」

- **【直译】** 老师给"讲一个网络结构"定了一个固定模板：**怎么做（结构） → 为什么（动机） → 具体例子（一个真实网络）**。上节课的三件事就是按这个模板排的。
- **【为什么】** 这个模板是他后面讲注意力时用的同一把尺子。你回看今天的脉络会发现：00:12:03–00:35:04 讲"注意力是什么"（模型），00:35:04–01:35:02 讲"怎么算"（怎么做），01:37:00–02:05:03 讲"为什么要它"（动机）。他自己就在演示这套结构。
- **【连接】** 面试被问"讲讲 Transformer"时，直接套这个模板：结构（多头自注意力 + FFN + 残差 + LayerNorm）→ 动机（RNN 三宗罪）→ 例子（BERT / GPT / BEVFormer）。比想到哪说到哪强得多。

---

### 02 循环边 vs 残差边：长得像，方向反了（00:01:35 – 00:03:20）

> **谢博**：「讲到这里的时候我们还尤其对比了一下残差，是不是？本来这两件事情没太大关系，但是他们那条边很有点像。残差那个我们叫直连边、残差边、跳跃边；循环边呢，它是不是反着来的呀？我把这个箭头换一下，这个是不是就很像残差边呢？」

- **【直译】** 残差的 skip connection 是**向前**的（把浅层输出接到深层），RNN 的循环边是**向后**的（把当前时刻的输出接回自己的输入）。画在图上只差一个箭头方向。
- **【推导/代码】** 残差：`y = F(x) + x`，同一次前向里两条路并行。循环：`h_t = F(x_t, h_{t-1})`，跨的是**时间步**不是层。前者展开后仍是 DAG，后者展开后是沿时间轴复制的链——这就是 BPTT（沿时间反向传播）和普通反传的区别。
- **【为什么】** 老师强调"框里面的内容是一个 module，可以自行设计，对颜值没有要求"：**边定义了拓扑，module 定义了容量**，这两件事是解耦的。
- **【连接】** YOLOv8 的 C2f 就是"残差边 + 自定义 module"的典型。你改 CA 注意力时把 CA 塞进 Bottleneck 后面，本质也是在换 module，边没动。

---

### 03 什么叫时序数据：前后有依赖关系（00:03:22 – 00:05:40）

> **谢博**：「我要输入 X1、X2、X3，如果 X3 和 X2 和 X1 之间有关系，这种就叫时序嘛。有依赖关系就叫时序。那你比如说你现在做的卷积的这个分类网络，输入的 X1X2X3 有关系吗？没关系啊，他们都自己计算自己的呀。」

- **【直译】** 时序 ≠ "有时间戳"，时序 = **前后样本之间有依赖**。图片分类里三张图互不相干，所以不是时序。
- **【推导/代码】** 学员的典型反问被老师提前堵死了："我不是合成一个 batch 输进去吗？" ——**batch 维是并行维，不是依赖维**。`(N,C,H,W)` 里 N 个样本在网络里各算各的，梯度才在最后求平均。而 RNN 的时间维 T 是有依赖的：`h_t` 必须等 `h_{t-1}` 算完。
- **【为什么】** 这个区分是理解"RNN 无法并行训练"的前提：batch 能并行是因为无依赖，时间步不能并行是因为有依赖。
- **【连接】** BEVFusion 单帧推理时，多视角的 6 张图在 batch/view 维是并行的；但 BEVFormer 的 **temporal self-attention** 要用上一帧的 BEV 特征，那一维是真正的时序维，训练时得像 RNN 一样按帧串行喂。

---

### 04 循环边里的 module 可自行设计 → 引出 LSTM（00:05:38 – 00:07:30）

> **谢博**：「我们说这个里面是个 module，可以长成各种各样子，那你就随便写，都可以。但是你写这个网络结构要有意义啊，虽然你叫循环神经网络，但是可能是毫无意义的循环神经网络呀，不能解决任何问题的呀，毫无设计逻辑的呀。所以我们是不是看了一个具体的例子——大名鼎鼎的 LSTM，叫长短时记忆。」

- **【直译】** "循环神经网络"是一个**结构族**（有循环边就算），不是一个具体网络。要能解决问题，还得设计块内部结构，LSTM 就是被公认最成功的那个设计。
- **【画面】** PPT 第 18 页标题 **LSTM**，正文只有一行"**3条门**"，右侧贴了那张经典的三格展开图（`X_{t-1} → A → h_{t-1}`、中间格画出 σ/σ/tanh/σ 四个门单元与逐点乘加），图例标注：**神经网络层 / 逐点操作 / 向量传输 / 连接合并 / 拷贝**。
- **【为什么】** 老师这里在教"网络设计的合法性"：能跑通 ≠ 有意义。设计要有**问题导向**——LSTM 三条门就是冲着"当前 vs 历史谁更重要"这个具体问题去的。这对你改 YOLO 很实用：往 backbone 里塞注意力模块，如果说不出"它解决了什么具体问题"，那就是"毫无设计逻辑"。CA 的合法性来自"SE 把空间信息全池化掉了，位置信息丢了"，这是一个明确的问题陈述。

---

### 05 三条门：乘法软开关，开合由 W 训练出来（00:07:30 – 00:12:00）

> **谢博**：「一个输入门，一个是遗忘门，还有一个输出门。他要解决一个什么问题啊？这个输出是依赖过去的历史状态多一点，还是跟当前的输入关联性更强一点。如果说跟过去没关系，那是不是这条门就把它关紧一点呢，不要漏风呢。……那我这个神经网络怎么就知道呢？靠训练。这里是不是有 W 啊？你训练好了，损失降很低，说明这个 W 就是合适的 W 了，它就能够分辨。当然了他运气不太好，Transformer 出来太早了，如果没那么早出来他应该有希望得图灵奖。现在它已经被打入冷宫了。」

- **【直译】** 三条门 = 三个"要不要让信息通过"的阀门：**遗忘门**管旧记忆留多少、**输入门**管新输入进多少、**输出门**管当前结果往后传多少。门开多大不是人设定的，是 W 学出来的。
- **【推导/代码】** 每条门都是 `sigmoid(W·[h_{t-1}, x_t] + b)`，输出落在 (0,1)，然后**逐元素相乘**：`c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t`，`h_t = o_t ⊙ tanh(c_t)`。"关紧一点"就是那个 sigmoid 输出接近 0。
- **【为什么】** ★ 门控 = 乘法式的软开关，和注意力权重是**同一个思想**：先算一个 0~1 的系数，再去缩放信息流。区别在于门控系数是**逐通道**、只看自己和上一时刻；注意力系数是**跨对象**的概率分布，要和别人比。同时"权重靠训练"这句是本课主线伏笔——01:34:01 老师会明确指出注意力里可训练的 W **只在第一步**。
- **【连接】** 你的 CA 注意力就是这个套路：算出 `sigmoid` 的两张系数图（H 方向、W 方向），再逐元素乘回原特征。所以 **SE/CBAM/CA 在数学形态上更接近 LSTM 的门，而不是 QKV 注意力**——这是面试可以主动抛出来的区分点，也解释了为什么它们"参数很少但管用"：可训练的只有那一两个 1×1 卷积。

### 06 Why not RNN 三条罪状（00:12:03 – 00:17:40）

> **谢博**：「为什么又不用循环神经网络呢，要用 Transformer 呢，要用注意力呢？是不是讲了三点理由：叫长距离依赖不足，然后隐状态特征表示能力不足，还有一个是无法并行训练。」

- **【画面】** PPT 第 19 页标题 **Why not RNN**，正文三条原文：**1. 长距离依赖不足 2. 隐状态特征表示能力不足 3. RNN无法并行训练**。老师在旁边用红笔写了 `c_t = f((c_{t-1}, h_t))`，下面标 `x_1, x_2`，再往下写了一排 `P1 P2 P3 … P4 P5` 和 `obs`——那是他提前在铺注意力的观察者例子。
- **【推导/代码】** 三条的技术成因：① 信息要沿时间链一步步传，传 100 步后早期梯度乘了 100 次 <1 的雅可比，指数衰减；② 无论句子多长，历史全部被压进一个固定长度的 `h`（比如 512 维），这是信息瓶颈；③ `h_t` 依赖 `h_{t-1}`，GPU 上并行度为 1。
- **【为什么】** 注意力对这三条是**逐条正面解决**的：① 任意两个位置直接一次矩阵乘就连上了，路径长度 O(1)；② 不压缩成一个向量，每个位置都保留自己的 K/V；③ 全序列一次 matmul，天然并行。这个"三罪三对策"的对照表是面试标准答案。
- **【连接】** 代价也要背：注意力的复杂度是 O(n²·d)，序列一长显存就炸。这就是为什么视觉里 ViT 要切 patch、BEVFormer 要用 **deformable attention**（每个 query 只采样 4 个点而不是和全图算），本质是在买回 RNN 的线性复杂度。

---

**【小结】** ① 循环边和残差边只差一个方向，边定拓扑、module 定容量；② 时序 = 前后有依赖，batch 维不是依赖维；③ LSTM 三条门是乘法软开关，门的开合由 W 训练得到——这个"权重靠训练"的结论会原封不动搬到注意力上。

## Part 2 · 观察者模型：注意力 = 权重分布 = f(观察者, 被观察者)（00:12:03 – 00:22:01）

**【本段在讲什么】** 老师把上节课建立的"观察者模型"重新过一遍，并且开始做**三级细化**：`Attn = f(观察者, 被观察者)` → `f(自主性提示, 非自主性提示)` → `f(Q, K)`。每一级细化他都要问一句"进步在哪里"，并用一个具体例子证明新写法能区分旧写法区分不了的情况。这一段是全课**方法论价值最高**的部分——它示范了"把一个模糊概念逐步变成可计算表达式"的完整过程。

### 07 一谈注意力，就想观察者模型（00:12:21 – 00:14:05）

> **谢博**：「一谈注意力机制，它是一个什么样的模型呢？观察者模型。那这个模型里面有什么呀？有两个角色：一个角色是观察者，一个角色是被观察者。然后他们之间什么关系呢？观察者去观察这些被观察者，他为什么要观察？是为了提取信息。当你面前有多个对象的时候，那你提取到的总的信息，是不是就跟一个所谓的权重分布有关系啊？那这个权重分布我们就叫注意力。」

- **【直译】** 注意力机制的心智模型只有三个词：**两个角色（观察者/被观察者）+ 一个动作（观察）+ 一个目的（提取信息）**。注意力就是这个提取过程中的权重分布。
- **【为什么】** 老师坚持先建"人话模型"再建数学模型，是因为公式 `softmax(QKᵀ/√d)V` 里没有任何东西告诉你 Q、K、V 分别扮演什么角色。**一旦你把 Q 对应到"观察者的问题"、K 对应到"被观察者的招牌"、V 对应到"被观察者的干货"，公式就再也忘不掉了。**
- **【连接】** 拿这个模型去看 BEVFormer 的 spatial cross-attention 立刻就通：**观察者 = BEV 平面上的每一个网格点（BEV query）**，**被观察者 = 6 路相机的图像特征**。BEV 格子带着"我这个位置上有什么"这个问题，去 6 张图上找证据，加权把图像特征搬到 BEV 上。这就是整个 BEVFormer 的一句话总结。

---

### 08 注意力具体是什么：一个 tensor，长度=对象数，和=1（00:14:44 – 00:16:35）

> **谢博**：「这个注意力具体来说是一个权重分布。假如说你现在要观察五个对象，那它就是一个 tensor，里面几个数啊？里面有五个数。而且这些数加起来等几啊？等一嘛。比如 P1、P2、P3、P4、P5，分给 P1 多少注意力、分给 P2 多少注意力……比如 0.1、0.5，然后点点点。这就叫注意力。」

- **【直译】** 注意力落地成代码就是**一个一维张量**，两条硬约束：**长度 = 被观察者的个数**、**元素和 = 1**（且非负）。
- **【推导/代码】** 这两条约束直接决定了实现里必须有 `softmax(dim=-1)`——`dim=-1` 就是"被观察者那一维"。写代码时 softmax 的 dim 选错是最常见的 bug：选成 query 维，得到的是"每个 key 在所有 query 上的分布"，语义完全反了。
- **【为什么】** 老师把"和为 1"抬到"合法性检查"的高度（00:48:00 他会拿这两条去否定两个错误的候选值）。物理含义是：**注意力是一种有限资源的分配**，你多看 P1 一眼就必然少看 P2 一眼。不加这个约束的话，网络可以给所有对象都打 100 分，等于没做选择。
- **【连接】** 反过来看你的 CA 注意力：它的系数是 `sigmoid` 出来的，**逐通道独立、不做归一化、和不为 1**。所以严格说 SE/CA 是"门控/重标定（recalibration）"，QKV 才是"注意力分配"。这个差别在面试里说出来很加分。

---

### 09 【画面】d2l 原文：Query / Key / Value 的官方定义（00:17:57 画面）

> **谢博**：「我们上节课建立了这个——一说注意力，你就通过这个观察的模型来理解。」

- **【画面】** 老师切到浏览器里的《31-Diffusion模型.pdf》第 **14/38** 页，标题 **"自主性提示+非自主性提示=注意力=权重向量"**，正文三行对照：
  - **自主性提示：Query/查询**
  - **非自主性提示：Key**
  - **感官输入：Value**
  - 下方 d2l 原文解释：**非自主性提示**"是基于环境中物体的突出性和易见性……面前有五个物品：一份报纸、一篇研究论文、一杯咖啡、一本笔记本和一本书。所有纸制品都是黑白印刷的，但咖啡杯是红色的……不由自主地引起人们的注意"；**自主性提示**"喝咖啡后，我们会变得兴奋并想读书，所以转过头，重新聚焦眼睛，然后看看书……受试者的主观意愿推动，选择的力量也就更强大"。
  - 右侧配图 **图10.1.1**（红杯子吸引视线）、**图10.1.2**（想读书→视线被引到书上）、**图10.1.3**（键=非意志线索、值=感觉输入、查询=意志线索，经"注意力汇聚"输出）。
- **【直译】** 这就是《动手学深度学习》10.1 节的原文。**非自主性 = 环境驱动、被动**（红杯子跳出来）；**自主性 = 意图驱动、主动**（我想读书）。
- **【为什么】** 记住这两个词的中文很拗口，但它们的英文很直白：**bottom-up（自下而上，数据驱动）vs top-down（自上而下，任务驱动）**。K 是 bottom-up 的招牌，Q 是 top-down 的意图，注意力就是两者的匹配度。
- **【连接】** 注意 d2l 把 Value 叫"**感官输入**"而不是"特征"——它是被观察者真正被搬走的那份内容。老师后面统一叫它"信息量/特征"，两种叫法要能对上。

### 10 第一级细化：Attn = f(观察者, 被观察者)（00:18:28 – 00:19:35）

> **谢博**：「你的注意力是不是跟观察者有关系，又跟被观察者有关系？所以这个注意力也就是这个权重，要计算出来，是不是这个观察者和被观察者的函数啊？怎么去一步步细化啊？」

- **【直译】** 第一步把"注意力"写成一个二元函数：`Attn = f(观察者, 被观察者)`。这一步唯一的信息量是：**注意力不是单方面决定的**，看的人和被看的东西都有份。
- **【推导/代码】** 这条对应到公式里就是 `attn_score = f(Q, K)`——注意 **V 不参与打分**。这是初学者最常搞错的地方：V 只在第三步被加权，完全不影响权重本身。
- **【为什么·连接】** "一步步细化"是**建模的标准流程**——先写出最粗的函数依赖，再逐层把自变量替换成更具体的量，直到每个自变量都是可计算的 tensor。这个流程你在 BEV 里会重复用：`BEV特征 = f(多视角图像, 相机参数)` → `f(图像特征, 投影关系)` → `f(FPN输出, LSS深度分布 / deformable采样点)`。每细化一级，代码就落地一层。

---

### 11 第二级细化：为什么要拆成"自主性/非自主性提示"（00:19:35 – 00:22:25）

> **谢博**：「跟观察者的什么有关系啊？自主性提示。跟他本身的内容有没有关系啊？没关系。比如说现在上课，我是观察者，小杨是一个被观察者。比如他今天搞了一个光头——这就是他的非自主性提示，我可能被吸引了。但是我跟他的自主性提示没什么关系啊：比如小杨在想"谢博关注我，快关注我"，他在心里默念，那我的注意力能到他那里去吗？不行呢。因为我们俩没有通过脑机接口连接起来。」

- **【直译】** 第二级细化：`Attn = f(观察者的自主性提示, 被观察者的非自主性提示)`。写成这样的**进步**在于——它明确排除了两件事：① 观察者本身的内容不参与；② **被观察者的自主性提示不参与**。
- **【为什么】** ★ 这是全课我最推荐记住的一个论证。老师没有说"就是这么定义的"，他构造了一个**反例来证明旧写法不够用**：小杨心里默念（他的自主性提示）不影响我的注意力，但小杨的光头（他的非自主性提示）影响。旧写法 `f(观察者, 被观察者)` 区分不了这两种情况，新写法能——**这就是"细化"的合法性证明**。
- **【推导/代码】** 落到实现上：被观察者虽然也能算出自己的 `Q_p`，但在"ob 观察 p1,p2"这个任务里它是**死代码**。01:26:04 老师会明说："ob 的 KV 是没用的，P 的 Q 是没用的，你也可以不计算，少用几个全连接。"
- **【连接】** 这在 cross-attention 里就是标准做法：BEVFormer 的 spatial cross-attention 里，**BEV query 只出 Q，图像特征只出 K 和 V**，各自另外两路根本不建。你读代码时看到 `self.attn = MultiheadAttention(...)` 后面传的是 `(query, key, value)` 三个不同来源的张量，就是这个意思。

---

**【小结】** ① 一说注意力就画观察者模型：两个角色、一个动作、一个目的；② 注意力落地是一维张量，长度=被观察者数、和为 1；③ 细化的合法性靠反例证明——新写法必须能区分旧写法区分不了的情况。

## Part 3 · QKV 三个概念的出处与归属（00:22:01 – 00:35:04）

**【本段在讲什么】** "自主性提示/非自主性提示"太抽象，老师用两个程序员都学过的旧知识给它们找了名字：**Query 来自 SQL 的 select，Key/Value 来自字典**。然后做了本课最容易被忽略但极其关键的一次切分：**观察者 ob 和它的 query 是两个不同的 tensor**，Q 是 ob 的函数。这一刀切下去，第一步"计算 QKV"才有存在的理由。

### 12 Query 的出处：SQL 里的 select（00:22:38 – 00:24:10）

> **谢博**：「这个自主性提示、非自主性提示还是很抽象，是不是？那我们这里引出了另外一个概念，叫 QKV。自主性提示我们叫什么呢？叫 query，查询的意思。你们以前上没上过数据库？是不是有个 SQL 语言，你会哪一个？是不是会 select。比如说这张表里面有一百条记录，我说 select 名字等于什么……那这条语句是不是叫一个 query 啊？query 就是"我想要"。我想要好好听课，我想要多看小杨一眼——这种叫自主性提示。」

- **【直译】** Query = **"我想要什么"**。数据库里 `SELECT * FROM t WHERE name='X'` 表达的是检索意图，注意力里 Q 表达的是观察意图。
- **【推导/代码】** 类比可以推得更远，而且很准：数据库检索是**硬匹配**——`name='X'` 要么中要么不中，返回 0/1；注意力是**软匹配**——`Q·Kᵢ` 给出一个连续的相似度分数，再 softmax 成权重。所以有人把注意力叫 "**soft dictionary lookup**（软字典查询）"，一句话讲透。
- **【为什么·连接】** 老师坚持用旧知识锚定新概念（01:22:01 他自己点破："这个东西跟你以前的知识是不是有继承性"）——新名词一律先找一个你已经熟的东西挂上去。这个"软字典"类比写代码时很实用：`attn = softmax(Q @ K.T) @ V` 读作"用 Q 去查这张字典，K 是键、V 是值，返回所有值的加权平均"。

---

### 13 Key / Value 的出处：字典的外在与内在（00:24:20 – 00:26:20）

> **谢博**：「在字典数据结构里面是不是有 key 还有 value？就一个对象，他有两部分的描述：key 就是他名字、外在的东西、外部特征。那内部的信息量叫什么呢？内在的东西，就是那个 value。比如说这个咖啡的杯子，颜色是红色的——这个就是 key，外在的东西。或者他的形状啊、颜色啊、气味啊。还有什么呢？内在的东西，特征，就叫 value。」

- **【直译】** 同一个被观察者要产出**两套表示**：**K = 用来被找到的外在招牌**，**V = 被找到之后真正交出去的内在内容**。
- **【为什么】** ★ 为什么必须分成两套而不能共用一套？因为**"容易被找到"和"有用"是两件事**。一个词可能因为词性、位置这些表层特征被匹配上（K 的活），但它真正贡献的语义是另一回事（V 的活）。共用一套等于强迫检索特征和内容特征长得一样，表达力会被砍掉一大截。
- **【推导/代码】** 工程上还有一个副作用：K 和 V 的维度可以不同。论文公式写的是 `softmax(QKᵀ/√d)V ∈ ℝ^{n×v}`——`d` 是 Q/K 的维度，`v` 是 V 的维度，两者本来就是分开的符号。Q 和 K 必须同维（要做点积），V 可以另设。
- **【连接】** 大模型推理里的 **KV Cache** 正是因为这个分工才成立：自回归生成时，历史 token 的 K 和 V 算一次就固定了（它们是"被观察者"的属性，不随新 query 变），只有新 token 的 Q 每步都要新算。缓存 K、V 不缓存 Q，是这个角色划分的直接工程后果。

---

### 14 Attn = f(Q, K)，V 不参与打分（00:26:24 – 00:27:15）

> **谢博**：「现在我们这里面看三个概念出来了：自主性提示、非自主性提示和特征。这就是我们常说的，你一提注意力机制，就要想到 QKV。那我们这个函数是不是就可以再细化了呀，可以表达成这个样子：f(Q, K)。因为注意力是跟观察者的自主性提示有关，跟被观察者的非自主性提示有关。」

- **【画面】** PPT 第 20 页《注意力机制模型》，正文六条（这是全课最该抄下来的一页）：
  - 观察者模型
  - **Attn = weight distribution = [0.1, 0.2, ...]**
  - **Attn = f(观察者, 被观察者) = f(自主性提示, 非自主性提示)**
  - **自主性提示：Query，我想要...**
  - **非自主性提示：Key，外在的...**
  - **特征：Value，内在的...，被观察者自身的信息量**
  - **Attn = f(Q, K)**
- **【直译】** 第三级细化完成，注意力的自变量正式落地为两个可计算的张量 Q 和 K。**V 不出现在这个式子里**。
- **【为什么】** 这一页把三级细化并排列出来了，从最模糊到最具体一行一行往下走。这个"细化阶梯"就是你复述整节课的骨架。
- **【连接】** 顺带把常见误解清一下：Self-Attention 里 Q、K、V 都从**同一个输入**算出来（三个不同的 W），所以叫 self；Cross-Attention 里 Q 来自 A、K/V 来自 B。BEVFormer 两种都有：temporal self-attention（BEV 和历史 BEV）+ spatial cross-attention（BEV 和图像）。

---

### 15 分清归属：Q 是观察者的，K、V 是被观察者的（00:27:15 – 00:28:00）

> **谢博**：「这里要分清楚：这个 query 是属于观察者还是被观察者？观察者的。K 呢？K 是被观察者的。value 呢？被观察者的。」

- **【直译】** 一句口诀：**Q 归观察方，K、V 归被观察方**。
- **【推导/代码】** 这条归属决定了张量形状。设有 n 个观察者、m 个被观察者：`Q: (n, d)`、`K: (m, d)`、`V: (m, v)` → 打分矩阵 `QKᵀ: (n, m)` → 输出 `(n, v)`。**打分矩阵的行数由 Q 决定、列数由 K 决定**，这是所有 shape 报错的根源。
- **【为什么】** 老师在 00:49:00 会强调"注意力分布的长度取决于被观察者有多少个，不是 K 有多少个"——其实二者相同，但他要强调**因果方向**：因为有 m 个被观察者，所以才有 m 个 K，所以权重才是 m 维。
- **【连接】** 你调 BEVFormer 时，`num_query = 200×200`（BEV 网格数）决定输出的行数，`num_key = 6×H×W`（六路图像特征的空间位置数）决定要 attend 的候选数。attention map 的规模是 40000×(6HW)——这就是为什么必须用 deformable 而不能用全量注意力。

---

### 16 ★ ob ≠ Q：这是两个 tensor（00:28:00 – 00:29:50）

> **谢博**：「首先你要明白哦，这个 ob 和 query，观察者和 query 是两个东西，你不能把他当作一个东西。你比如说小杨假如他是一个观察者，那他的自主性提示是"我想要听课"，但是你不能说"我想要听课"等于小杨。那如果映射到我们的算法世界里面，他是一个 tensor 还是两个 tensor？那就是两个 tensor。但是这两个 tensor 是不是有关系？有关系。Q 这个自主性提示，他是谁产生的？是 ob 产生的。所以 Q 是不是这里面又可以产生一个函数啊——ob 通过计算产生 Q。」

- **【直译】** **人 ≠ 人的想法**。ob 是一个 tensor，它的 query 是另一个 tensor，两者之间是函数关系：`Q = Q(ob)`。
- **【为什么】** ★ 这一刀不切，第一步"计算 QKV"就不存在了——如果 Q 就是 ob 本身，那直接拿 ob 去点积就完了，也就没有 `W_Q` 这个可训练参数，注意力也就**无法学习**。**整个注意力机制的可训练性，全部押在这一刀上。**
- **【推导/代码】** 顺带解释了一个常被问的问题："Q 和 ob 的维度必须一样吗？" 不必。01:18:00 老师明说："我想要多看小杨一眼，这个玩意和我自己，肯定不是同一类型的东西，那 tensor 长度是不是就可以不一样。为了简单我就搞成一样了。"实现上就是 `nn.Linear(d_model, d_k)`，`d_k` 可以自选。
- **【连接】** 多头注意力就是靠这个自由度实现的：`d_model=512`、`num_heads=8` 时每个头的 `d_k=64`，8 个头各自把 512 维的输入投影到 64 维，最后再 concat 回 512。如果 Q 必须等于输入本身，多头根本无从谈起。

---

### 17 被观察者同理：P1 产生 K1 和 V1（00:29:51 – 00:31:20）

> **谢博**：「P1 他会产生什么？P1 他是不是有 key 和 value 啊？他有他外在的东西，还有他的内涵，就他的信息量 value。所以这里是不是又有三个 tensor 了：P1 是被观察者，K1 是 P1 的非自主性提示，V1 是他的信息量、特征。K1 是 P1 的函数，V1 是 P1 的函数——要不然就不能叫 V1 是 P1 产生的呀。」

- **【直译】** 每个被观察者贡献 **3 个 tensor**：它自己（P）、它的招牌（K = k(P)）、它的干货（V = v(P)）。
- **【推导/代码】** 数一下这个例子里到底有多少个 tensor：**原始 3 个**（Ob、P1、P2）+ **派生 5 个**（Q、K1、V1、K2、V2）= 8 个。派生用了 5 个函数，也就是 5 个全连接层——但因为共享，实际只需要 3 个：`W_ob_Q`、`W_p_K`、`W_p_V`（P1 和 P2 共用同一套 K/V 投影，因为它们是"同一个类的不同对象"）。
- **【为什么】** 这里藏着一个 Transformer 的关键设计：**所有 token 共享同一套 W_Q / W_K / W_V**。老师 00:36:01 用"这不就是你的类的概念吗，他们是一个类，但是对象不一样，对象不一样就是里面的值不一样"讲的正是这个——同类对象走同一个投影矩阵，不同的只是输入值。
- **【连接】** 这正是权重共享在注意力里的形态。跟卷积的权重共享（同一个核扫过所有空间位置）是同一个思想：**参数量与序列长度/分辨率无关**。所以 Transformer 能吃变长序列，跟 YOLO 能吃不同分辨率是同一个原因。

### 18 没有注意力时的基线：V1 + V2（00:31:20 – 00:34:00）

> **谢博**：「如果没有注意力分布，他最后得到信息量——OB 来观察 P1P2，他得到信息量是不是 V1 加 V2？因为 P1 的信息量就是 V1。但如果说有了注意力之后，那 V1V2 是不是不是这样平均分布啊？那就变成有重点地去提取信息了。比如说这个 P1 比较会来活，然后 OB 呢又比较喜欢他，那给这个 P1 的注意力是不是要更多一点啊，比如说 0.9 和 0.1 这样一个权重分布。那最后他提取到的信息量是不是 0.9 乘以 V1 加上 0.1 乘以 V2。」

- **【直译】** 先立一个**baseline**：没有注意力就是简单求和（等价于所有权重都是 1）。有注意力就是加权求和，权重和为 1。
- **【推导/代码】** 严格说"平均分配"应该是 `0.5·V1 + 0.5·V2`，老师写的是 `V1 + V2`（权重都是 1，和为 2）。这不影响结论——两者只差一个常数因子 2，但**用来对照 [80,82] 和 [32,33] 这两个具体结果时要留意**：[32,33] 不是 [80,82] 的重排，而是 [40,41]（均值）附近偏向 V1 的结果。
- **【为什么·连接】** 立 baseline 是老师的固定套路（讲卷积时用全连接、讲注意力时用求和）：**先给出"什么都不做"的结果，新方法的价值才有参照物**。这个"加权求和 vs 直接求和"的对比在 BEV 里对应 **LSS 的深度加权 splat vs 简单投影**——都是把图像特征搬到 BEV，前者按深度概率加权，后者一视同仁。

---

**【小结】** ① Q 来自 SQL 的 select（"我想要"），K/V 来自字典（外在招牌 / 内在干货）；② Attn = f(Q, K)，V 不参与打分；③ **ob ≠ Q，P ≠ K/V** —— 这一刀切出了第一步"计算 QKV"，也切出了注意力唯一可训练的那组 W。

## Part 4 · 建模：三个 tensor 到 Q/K/V 的六个数（00:35:04 – 00:46:01）

**【本段在讲什么】** 老师重新画一遍模型，这次全部落到具体数字上。"建模其实就是用 tensor 来表示它"——三个原始 tensor 各给一个二维向量，五个派生 tensor 各给一个二维向量。这一段没有难点，但**这套数字是全课的骨架**，后面所有矩阵运算都在这套数字上跑，务必背下来。

### 19 建模 = 用 tensor 表示它，【画面】Ob:[1,2] P1:[2,3] P2:[3,4]（00:35:04 – 00:37:20）

> **谢博**：「所以我们怎么去建这个模型？建模型其实就是用 tensor 来表示它。OBS 是一个什么样的 tensor 呢？我用一个二维的向量来表示它，可不可以？为什么是二？三四行不行？也可以啊，没所谓。……P 是不是也是个 tensor？那这个 tensor 肯定跟 OBS 那个不一样嘛，因为他们是不同的人嘛。我们是不是一般说，这个观察者是一个长度为二的，那被观察者是不是也可以长度为二啊？这样是不是比较统一一点了。这不就是你的类的概念吗——他们是一个类，但是对象不一样，对象不一样就是里面的值不一样嘛。」

- **【画面】** PPT 第 21 页《实例》，前两条原文：
  ```
  1. Ob → p1, p2
  2. 三个tensor：
       • Ob: [1,2]
       • P1: [2,3]
       • P2: [3,4]
  ```
- **【直译】** **建模 = 给每个概念指派一个张量并写下形状**。三个对象都用长度 2 的向量表示：**同类对象同维度、不同对象不同值**——这就是"类与实例"在张量世界的对应。
- **【推导/代码】** 这里的"二"就是后面公式里的 **d = 2**。老师 01:31:00 会明确说："这个 D 就是你这个向量的长度。我们的 QKV 长度是二，所以这里就除以根号二。"选 2 是为了**手算得动**，真实模型里 `d_model=512/768/1024`，逻辑一模一样。
- **【为什么】** 统一维度不是必须的，但极大简化实现：所有被观察者共享同一个 `W_K`、`W_V`，前提就是它们同维。如果 P1 是 2 维、P2 是 5 维，你就得为每个被观察者单独建投影层，参数量随序列长度爆炸。
- **【连接】** 这就是 NLP 里 embedding 的作用——**把任意的字/词统一映射到 d_model 维**，让所有 token 变成"同一个类的不同对象"。这也正是本课最后留的债（02:03:01："你还不知道这个'市'这个字到底对应的 token 是什么样子"）。老师这套"用最小可行数字走通全流程"的教法你该照搬：把 BEVFormer 的 200×200 BEV 缩成 2×2 手推一遍，比读十遍代码有用。

### 20 【画面】Query = [10, 11]（00:38:40 – 00:39:40）

> **谢博**：「OBS 产生自主性提示，这个函数可以叫 Q。我又不知道这个函数长什么样子，他们都什么关系？但他们一定有关系，那就可以用个函数来表示。……那比如说这个提示，我随便写，10、11 好吧。为了简单，其实可以不一样的。因为你的自主性提示和你这个人，比如说"我想要多看小杨一眼"这个玩意和我自己，肯定不是同一类型的东西啊，那 tensor 长度是不是就可以不一样。为了简单我就搞成一样了。」

- **【画面】** PPT 第 3 条原文：**`Query, Q(ob), ob→Query, 自主性提示, [10, 11]`**
- **【直译】** `Q = Q(ob) = [10, 11]`。这个值不是从 `ob=[1,2]` 算出来的，是老师随手指定的——因为此刻 `W_ob_Q` 还没登场。
- **【推导/代码】** 事后可以反推：要让 `[1,2] @ W = [10,11]`，`W` 是 2×2 有无穷多解，比如 `W = [[0,1],[5,5]]` → `[0+10, 1+10] = [10,11]`。也就是说这个 W 完全由训练决定，老师给的只是一个"训练完之后可能长这样"的快照。
- **【为什么】** 老师故意先给结果、后给函数，是因为**先讲数据流、再讲参数**比反过来好懂。他 01:22:01 自己点破了："我不是说一开始就直接讲这个东西，你肯定听不懂的。我要先把思路给你说出来，然后再慢慢的细化。"
- **【连接】** 这个"先给数值、后给来源"的讲法，正好对应你调试网络的姿势：先 `print(x.shape)` 看数据流通不通，再回头查是哪个层的权重把值搞成这样。

### 21 【画面】K1/V1、K2/V2 的四个数（00:39:51 – 00:42:40）

> **谢博**：「被观察者会产生什么？他产生 K 和 V 嘛。这个 K1 肯定是一个函数，比如说这个函数就叫 k，它里面自变量是谁呢？是 P1 这个 tensor。这个就表示 P1 产生 K1，就叫非自主性提示。……那它也是个 tensor，比如说是 [20,21]。然后这里有个 Value1，是不是也是个函数？谁产生的呢？P1。这叫 P1 的特征或者信息量……比如说 30、31。」

- **【画面】** PPT 第 4、5 条原文（注意 PPT 上把"非自主性"打成了"**非自住性**"，是原稿错字）：
  ```
  4. P1→(Key1, Value1)
       • Key1 = k(p1), p1的非自住性提示, [20,21]
       • Value1=v(p1), p1的特征或者信息量, [30,31]
  5. P2→(Key2, Value2)
       • Key2 = k(p2), p2的非自住性提示, [40,41]
       • Value2=v(p2), p2的特征或者信息量, [50,51]
  模型的基本元素，构建完毕
  ```
- **【直译】** 六个派生张量全部就位：**Q=[10,11]，K1=[20,21] V1=[30,31]，K2=[40,41] V2=[50,51]**。数值刻意设计成 10/20/30/40/50 开头，就是为了你一眼看出谁是谁。
- **【推导/代码】** 记忆技巧：**十位数字就是身份证**。1x = Query，2x = Key1，3x = Value1，4x = Key2，5x = Value2。后面所有算式里看到 30、50 就知道在算 V，看到 20、40 就知道在算 K。
- **【为什么】** 老师说"我先把思路讲清楚，你不要究竟那么细节的东西"——数值本身没有物理意义，重要的是**函数关系**：K1 是 P1 的函数，V1 也是 P1 的函数，但是两个不同的函数。这一点在 01:19:00 会兑现成"三个全连接必须不一样"。
- **【连接】** 这套 8 个张量的清单就是你写代码时的变量表。真去实现作业时，`obs = torch.tensor([[1.,2.]])`、`p = torch.tensor([[2.,3.],[3.,4.]])` 两行就把输入建好了。

### 22 模型的基本元素构建完毕，接下来才开始计算（00:42:41 – 00:44:55）

> **谢博**：「它这个模型是不是就建完了呀？模型的基本元素构建完毕。接下来怎么办呢？接下来是不是就开始计算了呀。这个就叫建模啊，你如果搞什么建模竞赛，第一步就要干这种事情。建完这个模型，我们为什么要建这个模型呢？是因为我们要研究这个 OBS 去观察这个 P1P2 的时候，最后我们总的信息量是多少。」

- **【直译】** 全流程被切成两半：**建模（定义有哪些张量、它们之间什么函数关系）** 和 **计算（沿着这些关系把数走一遍）**。到这里第一半结束。
- **【为什么】** 这个切分很值钱：初学者读注意力代码时最容易在 `forward` 里迷路，就是因为没先把"有哪些张量"列清楚。**先画张量清单和依赖图，再读 forward**，一次就能读懂。
- **【连接】** PyTorch 的 `nn.Module` 本身就是这个切分的产物：`__init__` 里建模（声明有哪些层/参数），`forward` 里计算（数据怎么流）。你的 MNIST 默写模板就是这个结构，注意力模块也一样：`__init__` 里三个 `nn.Linear`，`forward` 里 matmul-softmax-matmul。

---

**【小结】** ① 建模 = 给每个概念指派张量并写下形状；② 全课就这 8 个张量，十位数字是身份证；③ 建模和计算是两个阶段，对应 `__init__` 和 `forward`。

## Part 5 · 算出来：[80,82] vs [32,33]，与三步总结（00:46:01 – 01:06:00）

**【本段在讲什么】** 数字全部到位后，老师把两条路都算了一遍：没有注意力得到 [80,82]，有注意力得到 [32,33]。中间插了一段很重要的"合法性检查"——他连给三个候选权重，让学员判断哪个合理，用反例把"长度=被观察者数、和=1"这两条约束钉死。最后 01:03:02 给出三步总结，这是整节课的**中心结论**。

### 23 没有注意力机制：V1 + V2 = [80, 82]（00:44:58 – 00:46:10）

> **谢博**：「OB 观察 P1、P2 得到的总的信息量，或者是特征——你叫特征以后就不叫信息量了——怎么计算呢？是不是就是 V1 加 V2？V1 是多少呢？V1 是 3031。然后 Value2 呢，看到没有，5051。那等于多少呢？这个是 80，是不是啊。」

- **【画面】** PPT 原文：
  ```
  ob观察p1和p2，得到的总的信息量/特征：
  没有注意力机制：
  Value1+Value2=[30,31]+[50, 51]=[80, 82]
  ```
- **【推导/代码】** 逐元素加：`30+50=80`，`31+51=82`。形状 (1,2) + (1,2) → (1,2)。
- **【为什么】** 老师顺带纠了一个用词："你叫特征以后就不叫信息量了"——**信息量是人话，特征（feature）是术语**。面试里说 feature，讲给外行说信息量。同一个东西两个口径要能自由切换。
- **【连接】** 这一步在真实网络里对应的是**全局平均池化**这类无差别聚合。SE 注意力的第一步 `AdaptiveAvgPool2d(1)` 就是这个"没有注意力的 baseline"，它对所有空间位置一视同仁；CA 之所以要改成 X/Y 两个方向分别池化，就是嫌这个 baseline 把位置信息全抹了。

### 24 有注意力：先算权重，函数叫 attn()（00:46:10 – 00:48:20）

> **谢博**：「那有了注意力机制，那你的逻辑就变成什么了？第一步要计算注意力权重。那是不是要有个函数啊？比如说我这个注意力权重叫 a，等什么呢？这个函数就叫 attn。然后这个函数它的自变量应该是谁呢？是不是跟 Q，跟这个自主性提示；然后还跟谁有关系？是不是跟 K 有关系。K 这里是不是两个啊？……其实现在也可以告诉你，它是一个什么计算呢？矩阵相乘。特别简单。」

- **【画面】** PPT 原文：
  ```
  有注意力机制：
  1. 计算注意力权重分布： a = attn(Query, (Key1, key2))=[0.9,0.1]
  2. 计算总的特征： 0.9*Value1+0.1*Value2=[0.9*30+0.1*50, 0.9*31+0.1*51]
  ```
- **【直译】** `a = attn(Q, (K1, K2))`。注意写法：**Q 只有一个，K 是一个集合**——这直接决定了输出是一个长度为 2 的分布。
- **【推导/代码】** 老师这里"泄密"说 attn 就是矩阵相乘，但严格说完整的 attn 是 **matmul → (÷√d) → softmax** 三件套，01:11:03 他才把 softmax 补上。你写代码时别只写 matmul。
- **【为什么】** 他故意先不讲 attn 的内部实现，而是先讨论"**它的输出必须长什么样**"。这是一种很好的接口思维：先定契约（输出是长度 m、和为 1 的向量），再谈实现。
- **【连接】** 这就是 PyTorch 的 `F.scaled_dot_product_attention(q, k, v)` 的契约。你调这个 API 时不需要知道内部是 FlashAttention 还是朴素实现，只需要知道输入形状和输出形状。

### 25 ★ 合法性检查：三个候选权重，两个被否（00:48:20 – 00:50:20）

> **谢博**：「你不管它是怎么计算的，但出来的结果你知道吗？它有一点特殊要求：首先里面是不是两个元素啊？为什么是两个元素呢？对，有两个被观察者嘛，所以你的注意力就分别给他们两个嘛。第二个，它的数字加起来要等于几啊？等于一嘛。……假如说这个注意力权重分布是这样子，合理不合理啊？不合理嘛，加起来不等于一啊。……假如说这样子合理吗？也不合理啊，为什么？因为你只有两个被观察者啊，怎么你的注意力分布会有三份呢？不是因为只有两个 K，是因为你只有两个 P。」

- **【直译】** 两条硬约束再确认一遍：**① 长度 = 被观察者个数 ② 元素和 = 1**。老师连给两个反例逐个否掉。
- **【为什么】** ★ 最后那句"**不是因为只有两个 K，是因为你只有两个 P**"值得单独抄下来。K 只是 P 的一个投影，是**表象**；真正决定分布长度的是**建模时纳入了几个被观察对象**，是**本质**。这个因果方向搞对了，你调网络时就不会去改 K 的形状来"凑" attention map 的尺寸。
- **【推导/代码】** 落到代码：`attn_weights.shape == (n_query, n_key)` 且 `attn_weights.sum(-1) == 1`。写单元测试时这两条就是 assert 的内容——`assert torch.allclose(w.sum(-1), torch.ones(n))`。
- **【连接】** padding mask 的必要性就来自第一条：batch 里句子不等长，短句被 pad 到同长后，pad 位置也会分到注意力，等于凭空多了几个不存在的"被观察者"。所以必须把 pad 位置的分数置为 `-inf`，softmax 后自动变 0。这就是【画面】01:29:02 那张 PPT 上第 2 条 **masked_softmax** 说的"超出有效长度位置被掩蔽并置零"。

### 26 权重长度取决于你建模纳入多少对象（00:50:20 – 00:51:45）

> **谢博**：「那你比如说你现在你的被观察者是谁啊？你在听课，那也不全是是吧。你的被观察者太多了：我当然是你一个被观察者，还有你隔壁小单，还有你的电脑、你的鼠标、还有这个灯光、还有外面的噪声，对此刻的你来说都是被观察者。……那你这个权重长度多少，取决于被观察者有多少个。可能有些同学他考虑三个对象，有些同学考虑三十个对象。这代表什么？这代表你建立这个模型是否更符合实际情况。但计算逻辑是一样的。」

- **【直译】** 建模纳入的对象越多，模型越贴近现实，但**计算逻辑完全不变**——只是矩阵变大。
- **【推导/代码】** 从 m=2 到 m=30，代码一行都不用改：`(1,d) @ (d,m) → (1,m)`，m 是运行时形状。这就是矩阵化实现的好处。但复杂度是 **O(n·m·d)**，n=m 时就是著名的 O(n²)。
- **【为什么】** 这句话回答了"注意力窗口/上下文长度"这个大模型热词的本质：**context length 就是 m**。GPT 从 4k 涨到 128k，就是把被观察者的数量从 4000 个 token 扩到 128000 个，逻辑不变，代价是注意力矩阵从 4k² 涨到 128k²（16000 倍）。
- **【连接】** BEVFormer 的 deformable attention 就是在砍 m：每个 BEV query 不看全部 6HW 个位置，只按学出来的偏移采样 **4 个点**，m 从几万降到 4。这是把 O(n·m) 压回 O(n) 的标准手法，也是你面试讲 BEVFormer 时的关键技术点。

---

### 27 第二步：按权重提取特征 → [32, 33]（00:51:45 – 00:54:10）

> **谢博**：「所以有注意力分布，那这个问题就要分两步了：第一个要计算这个权重分布，第二步再计算这个特征，就是我们提取到的总的信息。这个时候我们怎么算呢？是不是就按权重去提取这个特征呢。就变成 0.9 乘以 Value1，然后再加上 0.1 乘以 Value2。……0.9 乘以 30 加上 0.1 乘以 50，然后 0.9 乘以 31 加上 0.1 乘以 51。注意力就是我们权重分布，按注意力的大小、按他的权重分布，是干嘛呢？就提取特征。」

- **【推导/代码】** 把结果算完（PPT 上没给最终值，这是你该自己补的一步）：
  - 第 0 维：`0.9×30 + 0.1×50 = 27 + 5 = 32`
  - 第 1 维：`0.9×31 + 0.1×51 = 27.9 + 5.1 = 33`
  - **最终输出 = [32, 33]**
- **【推导/代码】** 对比三个结果很有意思：无注意力求和 = **[80,82]**；均匀加权（各 0.5）= **[40,41]**；0.9/0.1 加权 = **[32,33]**。加权结果**落在 V1=[30,31] 附近**——注意力大的那个几乎主导了输出。这就是"有重点地提取信息"的数值体现。
- **【为什么】** ★ 注意加权求和有一个重要性质：**输出永远落在所有 V 的凸包内**（因为权重非负且和为 1）。它不会造出新的数值范围，只会在已有的 V 之间"挑选/混合"。这也是注意力被称为"soft selection（软选择）"的原因。
- **【连接】** 这个性质解释了为什么 Transformer 里注意力后面必须接 **FFN**：注意力只做凸组合，不增加表达能力的"高度"，非线性变换要靠后面的 MLP 来提供。面试问"为什么 Transformer block 里要有 FFN"，这就是标准答案。

---

### 28 每个对象其实都能产生自己的 QKV（00:54:45 – 00:56:10）

> **谢博**：「所以整个模型看到没有，有几个 tensor 啊？观察者一个 tensor，被观察者两个 tensor。然后他产生 KV，他产生 Q。那他其实可不可以产生 KV 啊？其实他也可以产生 KV。为什么？万一他成为别人的观察对象呢。其实每个对象他都可以产生自己的 QKV。你在桥上看风景——他看别人，别人也可以看他呀。」

- **【直译】** Q/K/V 不是对象的固有属性，是**角色赋予的**。同一个 tensor 当观察者时用 Q，当被观察者时用 K/V。角色可以同时兼任。
- **【为什么】** ★ 这就是 **Self-Attention** 的定义。老师用卞之琳的"你在桥上看风景，看风景的人在楼上看你"点破了它——序列里每个 token 既是 query 又是 key/value，所有人互相看一遍。这一句话把 cross-attention 和 self-attention 的关系讲清楚了：**self 是 cross 的特例（A=B）**。
- **【推导/代码】** 实现上：self-attention 就是 `Q = X @ W_Q, K = X @ W_K, V = X @ W_V`，三个投影都吃同一个 X。cross-attention 是 `Q = A @ W_Q, K = B @ W_K, V = B @ W_V`。代码差别只有一个变量名。
- **【连接】** 01:26:04 老师会给一个工程提醒："在这里因为是 ob 观察 p1p2，所以 ob 的 KV 是没用的，P 的 Q 是没用的，你也可以不计算，少用几个全连接。"——**cross-attention 里省掉无用的投影，是真实的省参手段**。BEVFormer 的实现里 BEV query 确实只建 Q 的投影。

---

> 🗀 折叠【00:56:14 – 01:03:33】课间 + 面试经验闲聊（约 7 分钟）。老师说面试的"气质"由两点决定：① **表达/语气**（紧张和不会，面试官能分辨出来）② **逻辑性**（答非所问 vs 言之有物、有没有专业术语），"这些在前面三五分钟就已经决定了"。他强调**刻意练习**——别指望考前突击，现在就练"有逻辑的输出"，比如主动给同学讲一遍。

### 29 ★ 三步总结：QKV → 权重分布 → 特征（01:03:36 – 01:05:15）

> **谢博**：「我们接着说课的内容。整体的宏观的逻辑就介绍清楚了。总的来说分三步——跟大象装冰箱是一样的。哪三步呢？第一步是不是计算 QKV 啊。第二步计算什么呢？计算权重分布，这个权重分布就是注意力分布，也叫注意力。注意力本质上就是一个权重分布。第三个什么呢？计算特征。……每一步结果像 QKV 是不是个 tensor，OB P1 P2 是不是 tensor，然后权重分布是不是 tensor，提取到的特征是不是 tensor。」

- **【画面】** PPT 右侧老师现场敲的**总结**（这是全课最该背的一块）：
  ```
  总结：
  1. 计算QKV
  2. 计算权重分布，注意力分布
  3. 计算提取到的特征
  ```
- **【直译】** 注意力机制的**全部内容就是这三步**。任何注意力变体（多头、mask、deformable、flash）都是在这三步上打补丁，主干不变。
- **【为什么】** "跟大象装冰箱一样"这个玩笑其实是重点：**三步是一个闭包**——逻辑起点是"已知 ob、p1、p2 三个 tensor"，逻辑终点是"求提取到的总特征"。老师 01:25:02 会明确强调："你要分清楚他的逻辑的起点和终点是什么。逻辑起点就是已知手里面有什么，然后目的是要干嘛。"这是解任何题的通用姿势。
- **【连接】** 把这三步跟你熟悉的卷积对照：卷积也是三步（取局部窗口 → 与核做内积 → 写入输出位置），但**卷积的"权重"是学出来的常量，与输入无关**；注意力的权重是**由输入现算的**。这就是"静态权重 vs 动态权重"，是 CNN 和 Attention 最根本的分界线，也是面试高频题。

---

**【小结】** ① 无注意力 [80,82] vs 有注意力 [32,33]，后者被 V1 主导；② 权重合法性两条：长度=被观察者数、和=1，长度由 **P** 的个数决定而不是 K；③ **三步：算 QKV → 算权重分布 → 算特征**，每一步的输入输出都是 tensor。

## Part 6 · 细化第二、三步：MatMul → softmax → MatMul（01:06:00 – 01:16:00）

**【本段在讲什么】** 老师先跳过第一步，直奔第二、三步的具体计算。核心不是"矩阵相乘"这四个字（那太简单），而是"**怎么摆位置**"——K1、K2 是横着摆还是竖着摆？V1、V2 呢？他把这件事和以前手撕全连接时 `x⊗w` 还是 `w⊗x` 的纠结挂上钩，得出统一结论：**只要摆得让语义对上就行**。这一段的板书是全课信息密度最高的画面。

### 30 ★【画面】K1 K2 竖着摆：[10,11] @ [[20,40],[21,41]]（01:05:53 – 01:08:40）

> **谢博**：「QKV 已经有了。第二步，这里是不是一个 attention 的函数？他把 query 和 K1、K2 作为自变量，得到一个权重分布。刚刚我其实已经泄密了，我说这个函数其实是一个矩阵相乘。……Q 是不是 10 和 11？圈谁呢？是不是 K1、K2。K1K2 它就两种摆法呀：一种是并排摆，一种是上下摆。那你觉得应该是怎么样摆呢？竖着摆。为什么呢？因为我要算它的注意力，只有 Q 和 K1 的关系、Q 和 K2 的关系。那如果我这样写的话，那是不是行乘列啊？所以 K1 你看这一列应该摆什么了？应该摆 K1 的值啊。……这一行乘这一列，这个是不是 1 乘 2 的呀？这个肯定是 2 乘 2 的。」

- **【画面】** 蓝色板书（01:08:32 帧，全课最关键的一张）：
  ```
  [10, 11]  ⊗  ⎡20  40⎤  =  [        ]
    1×2         ⎣21  41⎦        1×2
                  2×2
  ```
  Q 下面标着 `1×2`，K 矩阵下面标着 `2×2`。
- **【推导/代码】** **K1=[20,21] 竖着放成第 1 列，K2=[40,41] 竖着放成第 2 列**——这个 2×2 矩阵就是 `Kᵀ`（因为 K 按行堆是 `[[20,21],[40,41]]`）。这就是论文公式里那个转置的来历。算出来：
  - `Q·K1 = 10×20 + 11×21 = 200 + 231 = 431`
  - `Q·K2 = 10×40 + 11×41 = 400 + 451 = 851`
  - 得分向量 = **[431, 851]**
- **【推导/代码】** ★ 这里有个老师没往下算、但极有价值的事实：**如果真把 [431, 851] 送进 softmax，`exp(851)` 在 float32 下直接溢出成 inf**。即使先除 √2（→ [304.8, 601.7]）也照样溢出。所以 PPT 上写的 [0.9, 0.1] 是**老师假设的值，不是算出来的**。这恰恰从反面证明了 √d 缩放的必要性，以及为什么真实实现里 softmax 都要先减去每行最大值（`x - x.max()`）做数值稳定。你写作业时如果直接 `torch.softmax(torch.tensor([431., 851.]))` 会得到 [0, 1]，跟 PPT 对不上——这不是你写错了。
- **【连接】** 这个"点积当相似度"的选择也值得记：`Q·K` 是未归一化的余弦相似度。K 和 Q 方向越一致，分数越高——**"招牌"和"需求"越对味，注意力越大**，几何意义完全对得上观察者模型。

---

### 31 摆位置的逻辑：跟手撕全连接时 x⊗w vs w⊗x 一样（01:08:40 – 01:10:30）

> **谢博**：「这个其实矩阵相乘你知道这意思吗，但是你要合理的安排他们的位置。这是不是跟我们以前手撕全连接的时候是一样的？我们还研究说 x⊗w 还是 w⊗x，我是不是告诉你都可以啊，没所谓，只要乘对了就可以了。那乘对就是要安排他们的位置啊，使得它要符合这个逻辑。因为我们说我们对 P1 的注意力，是跟 Q 和 K1 有关系，跟 K2 没关系。」

- **【直译】** 矩阵乘法本身没有"正确摆法"，**正确性由语义定义**：结果矩阵第 (i,j) 个元素必须恰好等于"第 i 个 query 对第 j 个 key 的匹配度"。摆对了就是对的。
- **【推导/代码】** 检验方法：算出来的 `(1,1)` 位置必须是 `Q·K1`（只含 Q 和 K1，不含 K2）。用竖摆：第 1 行 × 第 1 列 = `10×20 + 11×21`，只含 K1 ✓。如果横摆（K 按行堆成 `[[20,21],[40,41]]`），`Q @ K` 的 (1,1) 位置 = `10×20 + 11×40`，把 K1 和 K2 混在一起了 ✗。
- **【为什么·连接】** 老师把这条经验抬到方法论层面：**你不需要背转置在哪，你需要能自己验一遍语义**。面试写代码题忘了 `.transpose(-2,-1)` 加在哪，就用这个办法现推。这也是 `nn.Linear` 权重形状为 `(out_features, in_features)` 而 forward 里写 `x @ W.T` 的原因；BEV 代码里大量的 `permute(0,2,1,3)` 也是同一回事：把要相乘的那两维调到最后两位。

### 32 发现漏洞：结果不是概率 → 加 softmax（01:10:30 – 01:12:20）

> **谢博**：「然后我们很快就发现了一个漏洞：他不是个概率，是不是？因为这个值可能不是 0 到 1 之间的；第二个他们加起来也不会等于 1。这个时候你怎么解决这个问题呢？用个什么函数？你看这不是已经会了吗——是不是把它再经过一个 softmax 函数啊。一说 softmax，是不是他们加起来也等于 1 了？……先 MatMul，MatMul 是不是矩阵相乘；第二个是不是 softmax。就这个 attn。」

- **【直译】** `attn() = MatMul + softmax`。matmul 给出分数，softmax 把分数变成合法的概率分布。
- **【推导/代码】** `softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)`。它同时满足两条约束：非负（exp 恒正）、和为 1（分母就是全和）。用 [431, 851] 代入（数值稳定写法先减最大值）：`softmax([431,851]) = softmax([-420, 0]) = [e^-420, 1]/(1+e^-420) ≈ [0, 1]`。
- **【为什么】** 老师用"发现漏洞→找工具补"的叙事而不是"公式里就有 softmax"，是因为这样你能记住 **softmax 的位置和理由**，而不是硬背公式。同时他复用了学员已有的 softmax 知识（分类任务里学过），"你看这不是已经会了吗"。
- **【连接】** 顺带对照一下：分类头里的 softmax 是在 **类别维**上归一化（这张图属于哪一类），注意力里的 softmax 是在 **key 维**上归一化（这个 query 该看谁）。同一个算子、两种语义，dim 参数不同。写代码时问自己一句"我在哪一维上做选择"，就不会选错 dim。

---

### 33 ★【画面】第三步：[0.9,0.1] @ [[30,31],[50,51]]（01:12:20 – 01:15:35）

> **谢博**：「这里面我又泄密了，他又是一个矩阵相乘。怎么看得出来呢？我们的权重分布是不是这样子的，里面 0.9……这个是什么，1 乘 2 的是不是？这个是 2 乘 2。这个时候你要安排哦，这里面的数是放谁啊？是不是放 V1 V2 啊。……不管怎么样放，30 肯定在这里，我们唯一要讨论的是 31 在这里还是 31 在那里。那你是不是看这个公式就知道怎么凑了呀？31 乘以 0.9 是不是，那你 31 是不是在这里啊……0.9 乘以 30 加上 0.1 乘以 50，是不是放这个位置。」

- **【画面】** 蓝色板书（01:15:20 帧）：
  ```
  [0.9, 0.1]  ⊗  ⎡30  31⎤  =  [ 32   33 ]
     1×2          ⎣50  51⎦        1×2
                    2×2
  ```
  PPT 右侧同时补上了**细化清单**：
  ```
  细化：
  1. 权重计算: attn(), MatMul --》 softmax
  2. 计算总的特征：
       • Matmul
  ```
- **【推导/代码】** ★ 关键对比：**这次 V 是横着摆的**（V1=[30,31] 是第 1 行，V2=[50,51] 是第 2 行），而上一步 K 是竖着摆的。原因很直接——上一步要的是"Q 和每个 K 做内积"，这一步要的是"每个 V 按权重加权求和"。所以 `a @ V`，V 按行堆；而 `Q @ Kᵀ`，K 要转置。**论文公式 `softmax(QKᵀ/√d)V` 里 K 有转置、V 没有，原因就在这。**
- **【推导/代码】** 完整形状链（把它背下来，这是所有注意力代码的骨架）：
  ```
  Q (1,2) @ Kᵀ (2,2) → scores (1,2) → softmax → a (1,2) @ V (2,2) → out (1,2)
  一般式：Q(n,d) @ Kᵀ(d,m) → (n,m) → softmax(dim=-1) → (n,m) @ V(m,v) → (n,v)
  ```
- **【为什么】** 老师教了一个很实用的"凑"法：**不要去背转置规则，看着目标公式凑位置**。他先确定 30 一定在左上（因为 0.9 要乘 30），再讨论 31 该往哪放，用 `0.9×31 + 0.1×51` 这个已知结果反推出 31 在第一行第二列。这是手推矩阵形状的正确姿势。
- **【连接】** 这个形状链直接对应 `torch.nn.MultiheadAttention` 的文档：`query: (L,N,E)`、`key/value: (S,N,E)`、输出 `(L,N,E)`——L 是 query 数（我们的 n），S 是 source 数（我们的 m）。你以后看到 L 和 S 两个字母，就知道谁是观察者谁是被观察者。

---

**【小结】** ① 第二步 K **竖摆**（= Kᵀ），第三步 V **横摆**，这就是论文公式里转置只加在 K 上的原因；② attn() = MatMul + softmax，两次 matmul 夹一个 softmax 就是全部；③ 摆位置不靠背，靠"看结果第 (i,j) 位是不是应有的语义"来验。

## Part 7 · 细化第一步：QKV = 三个不同的全连接（01:16:00 – 01:37:00）

**【本段在讲什么】** 最后一块拼图：ob 这个 tensor 到底怎么变成 Q？答案是"**一层全连接**"，而且 Q、K、V 必须用**三个不同的**全连接。老师先画神经网络图（输入 2 个节点、输出 2 个节点），再翻译成向量表达 `Q = ob ⊗ W_ob_Q`，最后把这个表达跟论文公式对上。这一段还给出了本课最重要的工程结论：**训练注意力模型 = 只训练第一步的那几个全连接**。

### 34 第一步的函数就是全连接，而且先只学一层（01:15:35 – 01:17:05）

> **谢博**：「现在你唯一还有个不清楚的是什么呢？第一步。第一步就是我们要研究这个函数——叫 OB 这个 tensor 怎么变成 Q。就是全连接。……当然不一定是唯一的，你现在就学简单的：一层全连接。你问全连接是不是又会问几层呢？现在我告诉你一层。」

- **【直译】** `Q = FC(ob)`。而且是**最简单的一层线性层，不带激活**（老师说"那全连接他肯定有激活函数嘛，这个就不说嘛"，但标准实现里 QKV 投影确实是纯线性的）。
- **【为什么】** "不一定是唯一的"这句留了口子——原理上任何可微映射都行，只是实践中一层线性最好使：够用、参数少、可并行、易训练。这也是深度学习的常见现象：**最简单的选择往往就是最终选择**。
- **【连接】** 对照你的 MNIST 模板：`nn.Linear(784,128)` 就是一层全连接。注意力的三个投影跟它是同一个算子，只是输入输出维度不同。所以说"注意力没有引入任何新算子"，它只是把已有的 Linear + matmul + softmax 重新编排了一下。

---

### 35 这一层全连接长什么样：2 进 2 出（01:17:05 – 01:18:25）

> **谢博**：「你现在的 ob 是谁啊？是不是个 tensor？他是不是二？然后我们说他产生了一个 Q，他的 Q 是长什么样子啊？是不是 10、11？所以这个转换是通过一个全连接的。那你知道这个全连接长什么样子啊？输入有几个节点啊，输出呢？是不是也是两个。……那其实他可以不一样啊长度，那可以是 3 了，也就是说 query 可以是长度是 3，那这一层全连接是不是就有三个神经元。」

- **【直译】** 输入层 2 个节点（对应 ob=[1,2]），输出层 2 个节点（对应 Q=[10,11]），全连接 → **4 个权重 + 2 个偏置**。
- **【推导/代码】** `nn.Linear(2, 2)` → `weight.shape = (2,2)`，`bias.shape = (2,)`。如果 Q 要 3 维就写 `nn.Linear(2, 3)`，输出层变 3 个神经元、6 个权重。**输出神经元的个数 = Q 的长度**，这是全连接的基本对应关系。
- **【为什么】** 老师特意把"Q 的长度可以不等于 ob 的长度"再强调一遍，因为这个自由度在多头注意力里是核心机制。
- **【连接】** 注意一个约束：**Q 和 K 的长度必须相等**（要做点积），但 V 的长度可以不同。这正是【画面】01:29:02 那页 PPT 第 1 条 **"softmax：Q和K长度相等"** 和第 3 条 **"加性注意力：Q和K长度不等；Q和K分别做线性变换，再Add"** 的区别所在——加性注意力（Bahdanau）就是为了处理 Q、K 不同维的情况才发明的。

### 36 ★ 三个全连接必须不一样（01:18:25 – 01:20:00）

> **谢博**：「现在我问你了：这个全连接网络和这个全连接网络是一样的吗？一样还是不一样？肯定不一样嘛。如果一样的话，那就意味着 obs 产生的 QKV 数值是一样的呀，那怎么可能呢？因为他这三个特征表示的是不一样的东西啊：Q 是表示他的自主性提示——我想要什么；K 表示我的外部特征——我现在外部的一个特征；然后 V 是我自己的信息量、我内在的东西。所以他肯定是要用三个全连接。」

- **【画面】** 老师在 PPT 空白处用红笔画了**两张交叉连线的全连接图**（各 2 个输入节点 × 2 个输出节点、4 条交叉线），分别标注 `ob`，示意"同一个 ob 走两条不同的全连接"。
- **【推导/代码】** 反证很干净：如果 `W_Q = W_K = W_V`，那么 `Q = K = V`，于是 `QKᵀ = QQᵀ`（对称矩阵，每个 token 的最高分永远给自己），输出 `= softmax(QQᵀ)Q` —— 网络只能做"自己加权自己"，完全丧失区分"检索意图/被检索特征/被传递内容"三种角色的能力。
- **【为什么】** ★ 这是"**为什么是三个投影而不是一个**"的完整回答，面试高频题。标准答法就照老师的话讲：三者语义不同（意图 / 招牌 / 干货），必须由三个独立的线性变换从同一个输入里"抽"出三个不同的子空间。
- **【连接】** 参数量账本也顺带算清了：一个注意力头的参数 = `W_Q + W_K + W_V + W_O`，每个 `d_model × d_k`。`d_model=512`、8 头时约 `4 × 512 × 512 ≈ 1M` 参数。这就是 Transformer 里注意力部分的全部可训练参数——比你想的少得多。

### 37 ★【画面】向量表达：Q = ob ⊗ W_ob_Q（01:20:00 – 01:22:15）

> **谢博**：「你后面会看到这样子，所以他会写成这样子：Q 等于什么呢？等于 ob 圈 W_Q。这个表达式是不是代表这个全连接啊？那 K 呢？是不是也是 ob——看到没有这个函数关系就这样子的——W_K。你不能是 W_Q，知道这意思吗？这个 W_K 就代表这个神经网络嘛，这一层全连接嘛。那我这样写：W 下标 ob_Q，W 下标 ob_K。为什么？因为你 P 还会产生的。」

  K = ob ⊗ W_ob_K

### 38 作业：把 ob 观察 p1,p2 写成代码（01:22:55 – 01:27:30 + 01:31:52）

> **谢博**：「用向量的方式那你手写吗？那不可能。那我们肯定是要写代码嘛。……那你要实现这个注意力机制的时候，前提条件是什么？你必须要告诉我 ob 的特性是什么、p1 p2 的特性是什么。……第一步计算 QKV，那我是不是要创建三个全连接呀？比如说我叫 ob_fc……然后第二步计算权重分布，权重分布是不是分两步：第一步矩阵相乘，第二步再加一个 softmax。好，第三步计算提取到的特征，按权重去取特征，那是不是又一个矩阵相乘？完了。你的代码就这样写。」

- **【直译】** 作业 = 把三步用 PyTorch 前向实现一遍。逻辑起点：已知 Ob=[1,2]、P1=[2,3]、P2=[3,4]；逻辑终点：求 ob 观察 p1,p2 提取到的总特征。
- **【推导/代码】** 骨架（按老师的口径，不用官方 API）：
  ```python
  ob = torch.tensor([[1., 2.]])              # (1,2)
  p  = torch.tensor([[2., 3.], [3., 4.]])    # (2,2)
  fc_q = nn.Linear(2, 2); fc_k = nn.Linear(2, 2); fc_v = nn.Linear(2, 2)
  Q = fc_q(ob)          # (1,2)   ob 的 K、V 用不上，可以不建
  K = fc_k(p)           # (2,2)   p 的 Q 用不上，可以不建
  V = fc_v(p)           # (2,2)
  scores = Q @ K.transpose(-2, -1) / math.sqrt(2)   # (1,2)
  a = torch.softmax(scores, dim=-1)                 # (1,2) 和为1
  out = a @ V                                       # (1,2)
  ```
- **【为什么】** 老师澄清了两个必答疑问：① **"全连接里的权重是多少？"——随机的，"现在让你做是不是只相当于做一个前向传播的过程"**，跟当初手写卷积前向、全连接前向是一回事；② **官方的 `nn.MultiheadAttention` 跟这个不一样**，因为它是"多头 + 多个 ob 同时观察多个 p"，是本过程的 **repeat 版本**——"就像我们做神经网络的时候，一个样本进去计算预测值，实际上我们是一个 batch"。
- **【连接】** 这个 batch 类比很准：本课的 `(1,2)` 就是"单样本"，真实的 `(B, H, L, d)` 就是加了 batch 维和 head 维的同一个式子。你写完这份朴素版，再去读 mmdet3d 的 attention 实现，中间隔的只是 reshape。

### 39 ★ 训练注意力模型 = 只训练第一步（01:34:50 – 01:35:40）

> **谢博**：「第二个问题你应该能够想到：在刚刚我们谈到的整个三步的计算过程中，是不是在第一步 QKV 计算过程会涉及到全连接、会涉及到权重？你马上就想到，其实我们训练注意力模型，就是要训练这个 QKV 的计算过程嘛。为什么呢？因为第二步和第三步是不是没有权重啊？全是固定的计算啊。」

- **【直译】** ★ **注意力机制里唯一可训练的东西，就是第一步的三个（或四个，含输出投影）线性层。** MatMul、softmax、加权求和都是无参算子。
- **【为什么】** 这句话把整个机制的"可学习性"定位清楚了。网络学的不是"该看谁"（那是算出来的），而是"**怎么把输入投影成合适的 Q 和 K，使得点积恰好反映我们想要的相关性**"。权重是动态的，但**产生权重的规则是学出来的**。
- **【推导/代码】** 反过来看：如果把 `W_Q`、`W_K` 都冻住成单位阵，注意力就退化成"输入向量之间的原始相似度"，完全没法针对任务调整。所以微调时 LoRA 常常只挂在 `W_Q` 和 `W_V` 上——因为这就是注意力的全部可塑性所在。
- **【连接】** 这条也解释了 CA 注意力的可训练部分：CA 里可训练的是那个共享的 `1×1 Conv`（降维）+ 两个 `1×1 Conv`（升回 C），池化和 sigmoid 都无参。**"找出模块里哪几行有参数"** 是你分析任何注意力变体的第一步，也是面试问"你的改进增加了多少参数"时的答案来源。

### 40 ★【画面】回到论文公式：softmax(QKᵀ/√d)V（01:27:36 – 01:31:35）

> **谢博**：「这个公式是不是现在看得懂了呀？Q、K 做矩阵相乘，这里加了个转置，转置是为了对上他的位置。做完 softmax 得到权重分布，再跟 V 做矩阵相乘。……除根号 d 的目的是要对这个值进行缩放：比如原来算出来是 100、110，除以根号 d（比如说是 10），是不是就变成 10 和 11 啊。他就跟你的 Norm 是一样的性质、一样的目的——本来这些数是从负无穷到正无穷的区间，你要把它压缩到 0 到 1 或者负 1 到 1。这个就叫缩放点积注意力，矩阵相乘是不是也叫点积嘛。这个 d 就是你这个向量的长度——在我们刚刚那个例子里面，我们的 QKV 长度是二，所以这里就除以根号二。」

- **【画面】**《31-Diffusion模型.pdf》第 **15/38** 页《注意力评分函数》，正文四条：
  ```
  1. softmax：Q和K长度相等
  2. masked_softmax：
       • Q和K，长度不等，超出有效长度位置被掩蔽并置零
       • 注意力选择，忽略部分输入
  3. 加性注意力：
       • Q和K长度不等
       • Q和K分别做线性变换，再Add
  4. 缩放点积注意力：
  ```
  下方黑框公式：**softmax(QKᵀ/√d)·V ∈ ℝ^{n×v}**；右侧 d2l 原文 (10.3.1) `f(q,(k₁,v₁),…,(kₘ,vₘ)) = Σᵢ α(q,kᵢ)vᵢ ∈ ℝ^v`，(10.3.2) `α(q,kᵢ) = softmax(a(q,kᵢ)) = exp(a(q,kᵢ)) / Σⱼ exp(a(q,kⱼ)) ∈ ℝ`；还有图 10.3.1 的结构图（键 → 评分函数 a → softmax → 注意力权重 → 与值相乘 → 求和 → 输出）。老师在 (10.3.2) 旁用红笔写了 `[100, 10]` 做例子。
- **【推导/代码】** 公式逐项对照本课板书：**Q** = [10,11]（n=1, d=2）；**Kᵀ** = K1/K2 竖着摆 = [[20,40],[21,41]]（m=2）；**√d** = √2 ≈ 1.414；**softmax(·)** → [0.9,0.1]；**V** = V1/V2 横着摆 = [[30,31],[50,51]]（v=2）；**输出 ∈ ℝ^{n×v}** = [32,33]（1×2）。
- **【为什么】** 关于 √d，老师给的是"缩放/归一化"的直觉，这个直觉方向对，但严格理由更精确：假设 Q、K 各分量独立、均值 0 方差 1，则 `Q·K` 的方差是 **d**（d 项独立乘积求和），标准差 √d。除以 √d 把方差拉回 1。**为什么必须拉回来？因为 softmax 在输入尺度大时会饱和**——分数一大，输出就趋近 one-hot，梯度接近 0，网络学不动。这正是本课 [431, 851] 那个例子的真实后果。
- **【连接】** 四种评分函数要记住选择依据：**Q/K 同维就用点积（快，能矩阵化）；不同维就用加性注意力（Bahdanau，多一层 tanh + 线性）；需要屏蔽 padding 或做因果遮挡就用 masked_softmax**。BEV/Transformer 里几乎全是缩放点积，因为它能吃满 GPU 的矩阵乘算力。
- **【为什么·读论文】** 01:35:50 老师补了一句关键的："这个'1'就相当于 ob 这个 tensor，或者是 p1 p2。你过去看论文，他不会像我这样画个全连接放在这里，他就是这个公式。"——**论文只给向量式，不给网络图，这是读论文的门槛**。你要练的技能是反向还原：`XW` = 一层全连接、`softmax(·)` = 归一化、`⊙` = 逐元素门控。拿这个去读 CA 的公式：`z^h_c(h)=(1/W)Σx_c(h,i)` 是沿 W 方向平均池化、`f=δ(F₁([z^h,z^w]))` 是 concat 后 1×1 conv+BN+非线性、`g^h=σ(F_h(f^h))` 是 1×1 conv+sigmoid。三行公式还原成结构图，你改进它时才知道该动哪一块。

---

**【小结】** ① 第一步 = 三个**不同**的一层全连接，`Q = ob ⊗ W_ob_Q`；② 三个必须不同，否则 Q=K=V，机制退化；③ **注意力唯一可训练的就是这几个 W**，第二三步纯固定运算；④ 论文公式 `softmax(QKᵀ/√d)V` 里每一项都能在板书上找到对应。

## Part 8 · 为什么要注意力：自然语言的上下文歧义（01:37:00 – 02:05:03）

**【本段在讲什么】** 前面 90 分钟都在讲"怎么算"，最后 28 分钟回答"为什么要它"。老师的答案很聚焦：**注意力是为自然语言而生的**，因为语言有歧义，消歧要靠上下文，而"结合上下文"落到神经网络里就是"观察"，观察就是注意力。他用"咬死猎人的狗"和"武汉市长江大桥"两个段子把这条链走通，最后推出建模的两条要求——**每个字都要问、每个字要问多个问题**——那就是多头注意力和自注意力的由来。

### 41 注意力适合 NLP 不适合图片：因为时序（01:37:03 – 01:39:45）

> **谢博**：「这个注意力机制，他是适合解决处理图片问题呢，还是自然语言问题呢？是不是自然语言问题啊。为什么？他是一个时序，他能处理时序数据。然后我们的对话、包括我们的句子，是不是有依赖、有时序啊？这就你们说的上下文了。你要结合上下文来理解这个词在这个句子里面到底是什么意思，尤其是中文，讨厌的中文。……我们用卷积处理图片，首先这个处理对象、这个 tensor 长什么样子我们清楚了：CHW 嘛，每个像素值 0 到 255 嘛。那我们现在研究对象换成句子了呀，光是句子我们的神经网络能搞定他吗？不能，要把它变成 tensor。」

- **【直译】** 视觉的处理对象是 `(C,H,W)` 的数值张量，语言的处理对象是**字符串**——第一件事就是把它变成张量。这是本课最后留的债。
- **【为什么】** "适合 NLP 不适合图片"这个说法在 2017 年成立，2020 年之后被 ViT 推翻了。老师说的是**设计初衷**：Transformer 的原始动机是机器翻译，而不是"注意力天然不能处理图像"。你答面试要补一句：ViT 把图像切成 16×16 的 patch 序列后，注意力照样能干视觉——**关键是先把对象变成"一串 token"**。
- **【连接】** BEV 里这个转换更直接：BEVFormer 把 200×200 的 BEV 平面当成 40000 个 query token，把 6 路图像特征当成 key/value token。**只要能变成序列，注意力就能上**。你转 BEV 岗时这条是必答题。
- **【为什么·工具箱盘点】** 01:39:45 老师顺带列了没有注意力时的全部选项："第一招全连接，第二招卷积，第三招循环。本来循环是用来处理句子的，但是这个不好。"三招的伤：**FC** 输入长度固定、句子变长就废；**CNN** 感受野受核大小限制、捕捉长距依赖要堆很多层；**RNN** 有 Part 1 的三宗罪。注意力一次矩阵乘就把任意两个位置连上，且长度可变、可并行。PPT 第 16 页的标题就是这条主线：**FC → CNN → RNN → Transformer**——这四个词就是整门课的骨架。

### 42 ★【画面】两个歧义句：咬死猎人的狗 / 武汉市长江大桥（01:40:30 – 01:44:20）

> **谢博**：「比如说有一个叫"咬死猎人的狗"，这句话啥意思？到底谁死了？如果光是给你这个句子，是不是有多种理解？第一个是猎人死了，是狗把猎人咬死；还有也可能是说把猎人的狗给咬死了呀。这到底是谁死的？不知道，这要看上下文。比如说狗死，后面可能说猎人很伤悲，然后拖着狗的尸体，找个风水好的地方给他埋了——那后面如果是这样的句子，那还会理解错吗？……这个段子有没有听过：武汉市长江大桥。一个是武汉市/长江大桥，还有一个是武汉市长/江大桥。」

- **【画面】** PPT 第 22 页《为什么要用注意力？》原文：
  ```
  1. 咬死猎人的狗，
       • 猎人死？？
       • 狗死？？
  2. 武汉市长江大桥

  结合上下文，就是观察！！！

  武汉市长江大桥, 江市长一心为人民服务。
  ```
- **【直译】** 两个歧义句都是**分词/句法结构歧义**：同一串字符有两种合法切分，选哪种取决于上下文。
- **【为什么】** 这两个例子选得极好，因为它们证明了**歧义不在词的层面，而在词与词的关系层面**。"市"这个字本身没歧义，有歧义的是"它和左边的'汉'绑还是和右边的'长'绑"。而注意力算的恰恰是**每一对元素之间的关系强度**——工具和问题严丝合缝。
- **【连接】** 老师加的下文 **"江市长一心为人民服务"** 是关键设计：它把答案钉死成"武汉市长/江大桥"。这就是消歧的信息源——**歧义由上下文解决，而上下文的量化方式就是注意力权重**。

### 43 结合上下文 = 观察 = 注意力，观察单位是 token（01:44:20 – 01:50:30）

> **谢博**：「什么叫结合上下文呢？本质上就是要看当前这个句子和上下文之间的一个关系。关系是什么？就是我要去观察他。结合上下文的实现手段就是观察。那就观察，观察是不是就是注意力嘛。……观察者模型就要区分两个角色。那在这个句子里面，观察者和被观察者是谁呢？这个时候就产生了你们经常听到的一个概念，叫 token。token 这个概念它中文叫词元——当你这样说毫无意义，我用一个陌生的词来解释一个陌生的词。什么叫 token 呢？最简单的一种理解方式：一个字就是一个 token。」

- **【直译】** 完整推理链：**理解句子 → 需要消歧 → 消歧靠上下文 → "结合上下文"= 观察 → 观察 = 注意力 → 观察的最小单位 = token（先当成"字"）**。
- **【为什么】** 老师骂"词元"这个翻译"用一个陌生的词解释一个陌生的词"，然后给了个可操作的近似："一个字就是一个 token"。他也承认这不完全对，但**先给一个 80% 正确、100% 可用的定义**，比给一个精确但无法想象的定义有效得多。
- **【推导/代码】** 严格说 token 粒度由 tokenizer 决定：字级 / 词级 / 子词级（BPE、WordPiece、SentencePiece）。中文大模型多数是字级 + 常见词合并，所以"一个字≈一个 token"对中文基本成立；英文里一个词常被拆成 2~3 个 subword（估 API 成本时中文按字数、英文按 `词数×1.3`）。

### 44 ★ "市"作为观察者：query = 我跟谁组成一个词（01:50:30 – 01:55:00）

> **谢博**：「"市"这个字，他到底要跟谁在一起呢？是跟"长"在一起，还是跟"武汉"在一起？这就产生一个 query 啊。他在问"我跟谁在一起"。他就带着这个问题去观察他的同伙：观察"长"、观察"江"、观察"大"、观察"桥"，每个他观察一遍。……所以在这里面谁是观察者呢？"市"就是观察者，"长""江""大""桥"是被观察者。……那如果说你的模型是对的，我们知道这句话里面应该是"市"和"长"放在一起才合适，所以他的注意力最大应该分配给谁呀？分配给"长"嘛，就这个位置肯定是 0.9 吧。」

- **【画面】** 老师在 PPT 上用橙笔从"市"字画出多条弧线连到句中其他字，并在旁边写 **`Q: 谁 出 词`**（意为"谁跟我组成一个词"）。
- **【直译】** 把观察者模型套进句子：**观察者 = "市"这个 token，被观察者 = 句中所有 token，query = "我跟谁的关系更紧密/能组成一个词"，注意力分布的峰值就是答案。**
- **【推导/代码】** 具体到形状：句子 "武汉市长江大桥" 有 7 个字 → 7 个 token。"市"作为 query 得到一个 **长度 7 的分布**，理想情况下 `attn["市"]["长"] ≈ 0.9`。所有 7 个字各做一遍，就得到一个 **7×7 的注意力矩阵**。
- **【为什么】** ★ 这是整节课最漂亮的一处闭环。00:14:00 讲的抽象"权重分布"，在这里变成了一个可解释、可验证的东西——**你可以把 attention map 画出来，看它是不是把"市"和"长"连起来了**。这也是注意力可视化论文的全部内容。
- **【连接】** 老师顺带打了个类比："这是不是就很像我们以前说卷积提取特征了？他提取的是轮廓是什么东西。" 对照记：**卷积核提取的是"什么样的局部图案"，注意力提取的是"哪些位置该关联"**。前者是内容检测器，后者是关系检测器。

### 45 每个字都要观察，而且不止问一个问题（01:57:30 – 02:00:35）

> **谢博**：「那我们要彻底理解这句话，那"长"要不要观察别人？是不是也要。"江"是不是也要观察，"大"是不是也要，"桥"是不是也要。每个人都要观察自己周围的人，他才知道"我在这个句子里面到底是什么意思"。而且他还不止观察一遍。为什么呢？因为你去观察的时候，比如说"武"去观察的时候，他产生一个 query，他只产生一个问题，最后得到这个权重分布是关于这个问题的权重分布。但是他只问一个问题就够了吗？肯定不行嘛。他可能还会问其他的问题，比如说：我是不是主语啊？我的修饰词是谁啊？我的宾语是谁啊？我是什么词性呢？我在这个句子结构里面属于什么位置啊，是定语还是状语还是补语啊？他问的问题越多，是不是这个句子就理解得越透彻。」

- **【直译】** 两条推论：① **每个 token 都要当一次观察者**（→ self-attention）；② **每个 token 要问多个问题**（→ multi-head attention）。
- **【推导/代码】** 数一下：句子长 n，每个 token 问 h 个问题 → 需要 `n×h` 次观察，每次得到一个长度 n 的分布 → 注意力张量形状 `(h, n, n)`。这就是多头注意力的输出形状（再加 batch 维就是 `(B, h, n, n)`）。
- **【为什么】** ★ 老师列的那串问题（主语？修饰词？宾语？词性？定语状语补语？）是多头注意力**最好的直觉解释**：每个头学一种关系类型。BERT 的可视化论文（Clark et al.）实证过——确实有的头专门连"动词-宾语"，有的头专门连"名词-限定词"。
- **【连接】** 用你的 CA 经验对照：CA 把注意力拆成 **H 方向和 W 方向两支**，某种意义上也是"问两个问题"，然后把两个答案相乘。**多头 = 多问几个问题再拼起来**，思想相通，只是 CA 的"头"是人工设计的方向，Transformer 的头是学出来的。

### 46 ★【画面】建模两条要求 + 多头 = 多组全连接（02:00:35 – 02:04:30）

> **谢博**：「所以这里面，对一个句子的理解，我们叫结合上下文，在神经网络的模型怎么来实现呢？就是注意力机制，就是观察者模型。然后这里面建模的时候就会产生两个要求：第一，每个人都去问；第二个，要问多个问题。那每个人都去问，那不就是我讲的那个过程的一个重复吗？那每个人问多个问题，那不也是重复吗？……比如说每个人问四个问题，那是不是就会产生四个全连接？Q1 Q2 Q3 Q4 是不是。然后有还会产生 K 的时候，是不是又是四个全连接。」

- **【画面】** PPT 第 22 页最后三行原文：
  ```
  建模：观察者模型，观察者--》被观察者
  1.  每个字（Token）都去问
  2.  每个字（Token）都会问多个问题
  ```
  老师另在旁边手写了 **`Tokenize`**。
- **【推导/代码】** 把"问几个问题"参数化：老师说"你可以设置一个超参数，比如说每个人问四个问题"——**这个超参数就是 `num_heads`**。h=4 时需要 4 组 `W_Q`（以及 4 组 `W_K`、4 组 `W_V`）。实现上不会真建 12 个 Linear，而是建 3 个大 Linear 再 `view` 成 h 份：`d_model=512, h=8` → 每头 `d_k=64`。
- **【为什么】** ★ 这里给出了本课**最重要的整合结论**：官方的多头注意力 = 本课那个单 ob 单 query 过程的 **两重 repeat**（对 token 重复 + 对 head 重复）。老师 01:32:00 说得更直白："官方给的那个实际上是我刚刚讲这个过程的 repeat 重复版本……而是 ob1 观察 p1p2、ob2 观察 p1p2，甚至他们之间相互观察。他们把相互观察的这个过程放在一起就计算出来了，那样的话你可能就看不懂到底谁观察谁。"
- **【连接】** 这就是为什么老师坚持让你先手写单 query 版本再看官方实现：**官方实现把两层 repeat 折叠进了张量维度，谁观察谁被 batch 和 head 维掩盖了**。你手写一遍 `(1,2)` 版本，再去看 `(B,h,n,d)` 版本，就知道每一维是什么。

### 47 tokenize 与下节课的债：字怎么变成 tensor（02:02:26 – 02:05:10）

> **谢博**：「那当然你会看到说我这个解释不一样啊，我们 token 的解释不是说每个字就是一个 token 呢？那取决于那个 token 化的方法，模型是不是有很多种。每个字变成一个 token，他也是一种模型呢。有些模型他能够区分出来，就是有些词他会把某两个词放在一起作为一个 token。……因为把一个字变成一个 token，这中间有一个过程，我们叫 tokenize。……现在有个问题：你虽然给我讲了这个东西，我还是不知道怎么对这句话进行注意力计算。为什么呢？你还缺个什么东西？不是缺个函数——你还不知道这个"市"这个字到底对应的 token 是什么样子。如果说我告诉你"市"是什么呢？是 1、2；"长"是什么呢？2、3——那你是不是就会算了吗？」

- **【直译】** 最后的缺口：**字符串 → 张量**。老师明确点破，只要告诉你"市"=[1,2]、"长"=[2,3]，整个注意力计算就跟前面 Ob=[1,2]、P1=[2,3] 的例子**一模一样**。
- **【为什么】** ★ 这个收尾极妙：他用同一组数字 [1,2]、[2,3] 把 NLP 场景和前面的抽象例子对上了——**Ob 就是"市"，P1 就是"长"**。整节课的例子从头到尾是同一个，只是最后揭示了它的现实含义。
- **【推导/代码】** 补一下下节课的答案：字 → 张量分两步。① **tokenize**：查词表把字映射成整数 id（"市" → 2356）；② **embedding**：`nn.Embedding(vocab_size, d_model)` 查表把 id 映射成 d_model 维向量。第二步的那张表也是训练出来的。所以严格说，注意力模型的可训练参数还要加上 embedding 矩阵。
- **【连接】** 老师最后说"就像你的图片怎么变成一个 tensor 一样"——这个类比很到位。图像是 `ToTensor()` + 归一化（现成的、无参数的），文本是 tokenize + embedding（要建词表、要训练）。**文本比图像多了一层"离散符号 → 连续向量"的学习**，这是 NLP 比 CV 多出来的那道工序。

---

**【小结】** ① 注意力为语言而生：语言有歧义，消歧靠上下文，"结合上下文"= 观察 = 注意力；② "市"当观察者、query 是"我跟谁组词"、注意力峰值落在"长"上——抽象的权重分布在这里变得可解释；③ 建模两条要求（每个 token 都问 + 每个 token 问多个问题）= self-attention + multi-head；④ 最后的缺口是 tokenize/embedding，下节课还债。

### 复习最小集（三句话，能背下来就算过关）

1. **注意力 = 观察者模型**：观察者出 **Q**（我想要什么），被观察者出 **K**（我的外在招牌）和 **V**（我的内在干货）；注意力就是那个"长度 = 被观察者个数、和为 1"的权重分布。
2. **三步就是全部**：① 算 QKV（三个**不同**的全连接，`Q=ob⊗W_ob_Q`）② 算权重分布（`Q @ Kᵀ / √d` 再 `softmax`，K 竖摆）③ 算特征（权重 `@ V`，V 横摆）。**只有第一步有可训练的 W**，第二三步纯固定运算。
3. **数值锚点背下来**：`Ob=[1,2]`、`Q=[10,11]`、`K1=[20,21] V1=[30,31]`、`K2=[40,41] V2=[50,51]`；无注意力 = **[80,82]**，权重 [0.9,0.1] 时 = **[32,33]**；形状链 `(1,2)@(2,2)=(1,2)` 走两遍。
