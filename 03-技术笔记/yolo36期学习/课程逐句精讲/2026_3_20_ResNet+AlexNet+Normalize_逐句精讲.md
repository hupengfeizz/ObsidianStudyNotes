## Part 1 · 坐标系：architecture 与 module 两个层次（00:00:00 – 00:07:01）

**【本段在讲什么】** 谢博开场没有直接讲 AlexNet，而是先给了一个"看网络的坐标系"：任何一个神经网络都可以从两个层次去关注它——**整体架构（architecture）**和**模块（module）**。他用 LeNet-5 和 GoogLeNet 做对照：前者告诉我们最扁平的设计长什么样，后者的历史意义是提出了 Inception module，从此**设计单位从 layer 升级成 module**。这个坐标系是本课后面判断"ResNet 是模块级创新还是架构级创新"的尺子，务必先立住。

---

### 01 学得开心比学得好重要 + 本课的坐标系（00:00:00 – 00:02:43）

> **谢博**：「看到你们这种状态我稍微有点放心了，我是不管学得好不好，学得开心很重要……对一个神经网络的设计，我们其实有两个层面去关注它：一个是从整体架构去关注它，整体架构这个是比较难的；第二个是从模块去关注它。」

- **【直译】** 开场半分钟是调节情绪（Whisper 在这里输出了一长串乱码 `D,C,D,C…`，⚠ 是静音幻觉，画面上是 PPT 封面）。真正的内容是那句方法论：看网络分两层——architecture 和 module。
- **【为什么】** 这不是废话。绝大多数人看经典网络是"背结构表"（AlexNet 几层、每层多少通道），背完考完就忘。谢博的角度是"**这个网络给设计者留下了什么可复用的东西**"：LeNet-5 留下的是范式，GoogLeNet 留下的是 module，AlexNet 留下的是多分支+三要素，ResNet 留下的是残差块。这才是面试里能讲出层次的答法。
- **【连接】** 你看 BEVFusion 的配置文件时也是这两层：`model.encoders.camera.backbone` 那一层是 architecture（相机分支/雷达分支/融合/头怎么接），而 `SECOND` 里那一串 `BasicBlock` 就是 module。你改网络时改哪一层，决定了风险和收益的量级完全不同。

---

### 02 从 LeNet-5 到 GoogLeNet：设计单位升级了（00:01:54 – 00:03:50）

> **谢博**：「上一次我们总结了两个网络，一个是 LeNet-5。LeNet-5 给我们一个什么启发呢？就是说神经网络那种最扁平的神经网络的设计，就是先什么呢，C-P C-P，卷积部分提取特征，再拿全连接做分类。然后升级到 GoogLeNet，GoogLeNet 里面很重要的一个就是提出了一个 Inception 这个 module 的概念。module 这个概念提出之后，我们的设计就变成了用 module 来堆叠了，以前是用 layer 来堆叠的。」

- **【直译】** LeNet-5 的贡献是给出"卷积提特征 + 全连接分类"这个最扁平的骨架；GoogLeNet 的贡献是把若干层打包成一个可复用的 Inception module，之后大家搭网络就是在堆 module 而不是堆 layer。
- **【为什么】** 这个"升级"决定了后面所有网络的写法。堆 layer 时你写的是 `conv1/conv2/conv3…`；堆 module 时你写的是 `self.layer1 = self._make_layer(BasicBlock, 64, 2)`。前者每加深一次就要手写一遍，后者只要改一个数字。ResNet 能做到 152 层，前提就是它是 module 化的。
- **【连接】** 你的 MNIST 默写模板还停在 layer 堆叠（`conv1 → relu → pool → conv2 → …`）。从这节课开始，你应该练习把它改写成 module 堆叠：定义一个 `ConvBNReLU` 或 `BasicBlock`，然后 `nn.Sequential(*[BasicBlock(64,64) for _ in range(n)])`。YOLOv8 的 `C2f`、BEVFusion 的 `SECOND` 都是这个写法。

### 03 现代网络是 module 套 module，还带多头（00:03:50 – 00:07:01）

> **谢博**：「你看现在的这个神经网络都是靠 module 来堆叠的。看到没有，这是 module，这是 module……你比如说这个 module 叫 C2f，这个 module 你看在这里它又靠更小的 module 来堆叠。所以它这个 module 里面用了三种不同的子 module……我们这个现在看这个网络，它其实也有多头，看到吗？有三个头。」

- **【直译】** 老师现场点开的是 YOLOv8 的结构图（【画面】一张自上而下的彩色模块图，蓝/绿/红三色块交替，尾部分出三个输出）。他要说明两件事：①module 是可以递归嵌套的（大 module 里套小 module）；②这个网络尾部有三个头。
- **【为什么】** "递归嵌套"是理解现代 backbone 的关键。你看 YOLOv8 的 C2f，拆开是若干 Bottleneck，Bottleneck 拆开是两个 ConvBNReLU，ConvBNReLU 拆开才是 `Conv2d + BatchNorm2d + SiLU`。所以读代码要**自上而下拆三层**，而不是一开始就盯着最底层的 Conv2d 看。
- **【连接】**【画面】那张 YOLOv8 图尾部有三个 `softmax` 分叉，对应 P3/P4/P5 三个检测头。老师这里埋了一个对比：**GoogLeNet 的多头是"辅助头"（只在训练时用来辅助监督，推理只用主头），而 YOLO 的三个头是"并行头"（三个结果都要输出）**。这个区分下面 Part 2 会详细展开，也是面试常问点。

**【小结】** ①看网络分两层：architecture 与 module；②LeNet-5 给范式、GoogLeNet 给 module，设计单位从 layer 升级到 module；③现代网络是 module 递归嵌套 + 多头输出，多头又分辅助头和并行头两种。

## Part 2 · 补课：辅助头怎么写进损失函数（00:07:01 – 00:18:00）

**【本段在讲什么】** 这 11 分钟是在还上节课 GoogLeNet 的债：辅助头听起来很美，但**它的标签是什么？** 谢博的答案很反直觉——**辅助头的标签跟主头一模一样，都是最终标签**，区别只在损失函数里乘的系数。然后他用"梯度下降是贪心算法"解释了为什么乘一个系数就能起作用，最后补了两个让这套做法成立的现实前提。这一段是本课教学质量最高的段落之一，因为它把一个"结构上的 trick"落到了"损失函数的一行式子"上。

---

### 04 三个输出 → 三项损失，标签全是 10（00:07:01 – 00:10:09）

> **谢博**：「这里是不是有个输出 O1，这个呢也有个输出，这个也有个输出。那他的损失函数是不是就会有三部分？比如说输入 0，我们目标是要 10。这个位置大概输出 7 就很 OK 了，这个位置输出 3 或者 4……那这个输出他的标签是多少呢？你说 7 是我们假设的呀，其实你拿到的样本，S1 的 X 和 Y，X 是 0，Y 是 10。」

- **【推导/代码】【画面】** 老师在 YOLOv8 结构图旁边手写：`S1: X=0, Y=10`；三个输出分别标 `→10 O1`、`7→10 O2`、`4→10 O3`；损失写成
  `LOSS(W) = (10 − O1)² + (10 − O2)² + (10 − O3)²`，下面画了个箭头 `L → 0`。
- **【直译】** 一个样本只有一个标签（10）。你可能"希望"中间层输出 7、4 这样的过渡值，但**你根本不知道中间层应该是多少**——7 和 4 是老师随口举的例子，不是数据里有的东西。所以三个辅助头的监督目标只能都写成 10。
- **【为什么】** 这解开了初学者最大的困惑："辅助头哪来的标签？"答案是**没有额外标签，共用同一个标签**。这也顺带解释了为什么辅助头只能做同质任务（都是分类/都是回归），不能一个分类一个检测。
- **【连接】** YOLOv7 的 aux head、PP-YOLOE 的 aux branch 用的就是这一套：辅助头和主头共用同一批 GT，只是分配策略和损失权重不同。你以后读到 `aux_loss_weight=0.25` 这种配置项，脑子里应该直接浮现出这三项式子。

### 05 不加系数会把活全压到前几层（00:10:09 – 00:11:43）

> **谢博**：「那你说这样我就不就完蛋了吗？我们最终的目标是要到 0，到 0 那这个位置就直接输出 10 了呀，这个位置也要输出 10 了呀。那就意味着你把工作压力都压到这一段去了，相当于后面这一段啥事也没干……就会造成这个神经网络实际上你虽然有 30 层，实际上只有前面 10 层在干，后面的 20 层相当于啥都没干。」

- **【直译】** 如果三项损失都是权重 1，优化器为了让总损失到 0，会强迫**第一个辅助头所在的位置就已经输出正确答案**。那后面所有层就变成了"把 10 原样传下去"的摆设。
- **【推导/代码】** 形式化说：`L = Σᵢ (y − Oᵢ)²`，若 L→0 则每项都要→0，即 O₂ = O₃ = y。而 O₂ 是浅层输出、O₃ 是更浅层输出，等价于要求网络在第 10 层就完成全部任务，第 11~30 层被逼成恒等映射。
- **【为什么】** 这个推理链非常值得学：老师不是直接给结论，而是**先把"如果照字面做会怎样"推到荒谬**，再引出修正方案（加系数）。面试时被问"辅助头为什么要加权"，你按这条链讲，比背"为了平衡损失"高一个档次。
- **【连接】** 同样的逻辑在 BEV 里出现在多任务损失上：BEVFusion 的 `loss = loss_det + λ·loss_seg`，如果 λ 给太大，检测分支就会被分割分支带偏。权重不是拍脑袋，是在决定"哪一段网络承担哪部分工作"。

---

### 06 系数 0.5 / 0.1：离终点越远折扣越狠（00:11:43 – 00:14:04）

> **谢博**：「那我们就要在前面加个系数，比如说给他乘个 0.1……你觉得哪个系数要大一点呢？这个是 0.5，这个乘以 0.1，这样合理吗？合理。为什么呢？你想想最后我们这个 O1 输出 10 了其实就已经很正确了，然后这两个地方是允许他有误差的，也就是他的误差我们要把他权重降低。」

- **【推导/代码】** 最终形式：
  `L(W) = (10 − O₁)² + 0.5·(10 − O₂)² + 0.1·(10 − O₃)²`
  O₁ 是主头（离输出最近），系数 1；O₂ 中间，0.5；O₃ 最浅，0.1。
- **【直译】** 辅助头的目标仍然是 10，但**允许它离 10 远**。允许的方式就是给它的误差打折——O₃ 理想值可能只有 4，硬凑到 10 不合理，那就把这一项的 6 分误差乘 0.1 变成 0.6 分。
- **【为什么】** 老师给的判据是"**离最终输出越远，允许的误差越大，系数就越小**"。这个单调关系是可解释的：浅层特征本来就抽象程度不够，逼它直接给出最终答案是不讲理的。
- **【连接】** 对比 YOLO 的三个并行头：P3/P4/P5 的损失权重通常是**按目标尺寸/正样本数**分配的（比如 `box: 7.5, cls: 0.5, dfl: 1.5` 再乘各层的 stride 缩放），不是按"离输出多远"。两种多头，权重逻辑完全不同——这正是"辅助头 vs 并行头"这个区分的实用价值。

### 07 梯度下降是贪心算法：占便宜的算法（00:14:04 – 00:18:01）

> **谢博**：「损失函数会选择——我们说梯度下降算法，他是什么？他是占便宜的算法，就是哪个地方水最多他就会优先优化哪一项……这一项我把它的差距减少了 1，那对我整个损失是不是就减少了 1？如果这一项前面乘了个 0.5，是不是只有 0.5 的能力？这一项乘 0.1，就只减少了 0.1。专业术语叫贪心算法。」

- **【推导/代码】** 反向传播时 `∂L/∂O₃ = 0.1 · 2(O₃ − 10)`，梯度天生被缩小 10 倍。所以"乘系数"不是修辞，它**直接等比例缩放了那条支路回传的梯度**。优化器在同样的步长下，自然优先动主头那条链。
- **【直译】** 为什么乘个系数就有用？因为梯度下降只认"改动同样多，哪项让总损失掉得最多"。乘 0.1 的那项性价比低，优化器就少花力气在它身上。
- **【为什么】** 这一段之后老师补了两个让辅助头成立的**现实前提**（00:16:23 起）：①`L` 实际上永远训练不到 0，所以"后 20 层全白干"的荒谬结论不会真发生；②正因为不可能到 0，加权后的三项会形成一个折中——浅层被"往目标方向推"但不被"逼到目标"。
- **【连接】** "贪心 + 加权 = 控制哪条支路多学"这个思路，你在 BEV 里可以直接拿来解释：为什么 BEVFusion 训练时相机分支容易学不动？因为 LiDAR 分支的梯度更"便宜"（收敛快、损失下降明显），优化器会优先照顾它——所以论文里才要冻结/预训练相机分支，或者给它单独的损失权重。

**【小结】** ①辅助头没有独立标签，共用最终标签；②不加权会把整个任务压到网络前段，后段退化成恒等传递；③加权之所以有效，是因为梯度下降是贪心算法，系数直接等比缩放回传梯度。

## Part 3 · AlexNet：多分支、三大要素、ReLU 与 Dropout（00:18:00 – 00:49:02）

**【本段在讲什么】** 这 31 分钟是 AlexNet 专场，但重点完全不在"AlexNet 有几层"。谢博讲了四件事：①**网络架构上的贡献是多分支（branch）**，并且现场把 AlexNet 的两条支路翻译成了 PyTorch 的写法；②**历史上的贡献是奠定了"数据 + 模型 + cuda 显卡"三大要素**；③首次引入 ReLU；④首次引入 Dropout——然后借 Dropout 顺势把"能放哪、不能放哪"和"过拟合的主语是谁"讲透。【画面】PPT 第 8 页右上角把这四条明明白白写着，转写里完全没有。

### 08 多分支登场：先把 55×55×48 读对（00:18:57 – 00:22:08）

> **谢博**：「这个叫多分支。这个是一个 224 的一个 RGB 的图，然后用一个卷积，这个卷积是 11 乘以 11，得到一个特征图。这个特征图是不是 55，然后 48？那这个卷积核有多少个呢？48 个嘛……你们是不是把这个 55 以为是通道数？」

- **【推导/代码】【画面】** PPT 第 8 页的 AlexNet 原图：输入 `224×224×3`（图上标 `224`、`Stride of 4`、核 `11×11`）→ 上下两条支路各得 `55×55×48` → MaxPooling → `27×27×128` → `13×13×192` → `13×13×192` → `13×13×128` → MaxPooling → dense `2048` → dense `2048` → 输出 `1000`。
- **【直译】** 图上的立方体，**两个 55 是 H 和 W，那个 48 才是通道数**。老师专门停下来纠这个，因为学生很容易把 55 当通道。反推卷积配置：核 11×11、stride 4、核的个数 = 输出通道 = 48。
- **【为什么】** 这是"读结构图"的基本功：图上标注的三个数按 `H × W × C` 排，而 `C` 唯一地告诉你**这一层用了多少个卷积核**。上节课的两条铁律在这里复用——`C_out = 核的个数`，`核的通道数 = C_in`。
- **【连接】** ⚠ 这里有个业界公案：AlexNet 原论文写 224，但按 `(224−11)/4+1 = 54.25` 算不出 55，实际要 227 才对（`(227−11)/4+1 = 55`）。老师照着 PPT 念的 224，面试时你可以补一句"论文标 224，实际需 227"——这是加分项，不是抬杠。

---

### 09 两条分支独立发展：48 个核 ≠ 48 个核（00:22:08 – 00:25:20）

> **谢博**：「同一个 x 又经过一个卷积，得到一个 55×55×48 的。所以这边是不是又有 48 个核？这两个是一样的？形状一样，但是你不要以为这 48 个核和这 48 个核值是一样的——不一样。他两个是独立的分支。」

- **【直译】** 上下两支的形状完全对称（都是 48 个 11×11 核），但**权重是两套独立的参数**，各自随机初始化、各自训练。
- **【为什么】** 这是"分支"的定义性特征：**同一个输入，不同的权重，独立演化**。如果两支的权重相同，那就是把同一个结果算了两遍，纯粹的数据冗余——这跟上节课"两个卷积核的 W 必须不一样"是同一条原则。
- **【连接】** 历史上 AlexNet 分两支的直接原因是 GTX 580 只有 3GB 显存，一张卡装不下，所以劈成两半放两张卡。但**工程上的妥协变成了架构上的启发**——这正是本课"从设计角度看网络"的绝佳案例。你在 BEVFusion 里看到的相机分支 / LiDAR 分支，也是同一个输入场景、两套完全独立的权重。

### 10 分支写成代码：x1 = C1(x)，x2 = C2(x)（00:25:20 – 00:27:02）

> **谢博**：「假如说你写代码的时候，这个卷积你要搞一个算子，比如说 C1 等于 nn.Conv2d，然后 C2 等于 nn.Conv2d，然后这里填你的参数。好，那你在 forward 里面怎么写呢？x 进来，x1 = C1(x)，x2 = C2(x)。x1 就代表这个特征图，x2 就代表这个特征图，就不能写成 x = C(x) 了。」

- **【推导/代码】** 对应的 PyTorch 骨架：`self.c1/self.c2 = nn.Conv2d(3, 48, 11, stride=4)` 两个独立算子，`self.c3 = nn.Conv2d(48, 128, 5, padding=2)`；forward 里 `x1 = self.c1(x)`、`x2 = self.c2(x)`、`x3 = self.c3(x1)`（C3 的输入是 x1，不要乱串）。
- **【为什么】** 老师反复强调"**不能写成 `x = C(x)`**"。单主干网络可以一路 `x = layer(x)` 覆盖变量，但一旦有分支，你必须给每个中间张量单独命名，否则前一支的结果会被后一支冲掉。这是新手写多分支网络最高频的 bug。
- **【连接】** 这条纪律在残差块里更要命——`x = self.conv1(x)` 一写，那个要被加回去的原始 `x` 就没了。Part 6 第 38 张卡里老师给的残差写法 `x1 = C1(x); x2 = C2(x1); x = x + x2` 正是这条纪律的直接应用。

---

### 11 concat 融合：两个 team 中期同步（00:27:02 – 00:30:20）

> **谢博**：「这两个卷积出来的结果要做 concat 操作。concat 操作是不是把两个特征图按照通道把它堆在一起？操作你知道怎么做了，那我问这个操作的目的是干嘛？融合特征……用最简单的例子来说就是分组做项目：现在有个大的 problem，把它分成两个 task，这个分支干第一个 task，这个分支干第二个 task。那你这两个小组中间不能没有交流啊，到最后要交项目的时候再放在一起，这合适吗？过两个礼拜大家就要把自己的研究成果同步一下——这就是 concat 操作。」

- **【直译】** concat = 按通道维把两个特征图摞起来。它的**目的**是特征融合，而不是"改变形状"。老师的类比：两个 team 各干各的 task，但中途必须同步，最后再汇总。
- **【为什么】** 这里藏着多分支为什么有效的完整论证链：**分工（独立提不同的特征）→ 中期融合（信息交换，避免各自跑偏）→ 末端汇总（全连接必须看到全部信息）**。老师特别指出末端那次融合是**必须的**："已经到总结部分了，你不得综合全面的信息啊。"
- **【连接】** ⚠ 转写里 concat 全被听成了 **"CAD 操作"**，共出现 6 次。这个类比对你理解 BiFPN 很有用：BiFPN 的每个节点做的就是"中期同步"——P4 既接收自己那条路的特征，也接收 P3 上采样和 P5 下采样过来的特征。而 YOLOv8 的 `C2f` 里那个 `torch.cat(y, 1)`，也是同一件事的最小实现。

---

### 12 多分支在 YOLO 与 SSD 里：以及多分支 vs 多头（00:31:08 – 00:39:11）

> **谢博**：「这个在我们现在的神经网络里面也用到。你看这个是主干，到这里来就分支了。branch 1、branch 2、branch 3——branch 1 和 branch 2 要不要讨论呢？要，看到没有，这里有个箭头，他们的结果共享分享……分支可以在过程中，也可以在输出。如果这个分支是直接在输出部分，那我们就有了一个更加具体的名字，叫多头。它本质上都是多分支。」

- **【直译】** 两个层级关系：**多分支是大概念，多头是"分支落在输出端"的特例**。老师现场翻出 SSD 的结构图【画面】（Stanford CS231n 的目标检测讲义页，标题"目标检测 SSD 网络结构"）说"他有六个分支"——SSD 从 backbone 的六个不同深度各拉一条支路出来做预测。
- **【为什么】** 这个层级关系能帮你把一堆名词收编：Inception 的四条并行路 = 模块内多分支；ResNet 的直连边 = 两分支（一条恒等、一条卷积）；FPN/PAN = 架构级多分支 + 多次融合；YOLO 的 P3/P4/P5 = 多头；GoogLeNet 的 aux = 多头（辅助型）。**全是同一个东西在不同位置的实例化。**
- **【连接】** BEVFusion 就是一个教科书级的多分支：相机分支（Swin/ResNet + LSS）和 LiDAR 分支（VoxelNet/SECOND）独立提特征 → 在 BEV 平面上 concat 融合 → 共享 CenterPoint 头。你完全可以用老师的"两个 team + 中期同步"来向面试官解释它。

### 13 AlexNet 真正的历史贡献：数据 + 模型 + 显卡（00:32:45 – 00:36:43）

> **谢博**：「AlexNet 的贡献还不止这个。他还有一个是奠定了我们现代人工智能的一个基本框架，什么框架呢？三大要素：数据 + 模型 + 显卡……在 AlexNet 之前，训练这种神经网络是无法在消费级的显卡上面完成的，是在那种高性能计算机里面完成的。AlexNet 是第一次把神经网络跑在消费级的显卡上面训练出来。所以英伟达的崛起离不开他，老黄很喜欢他。」

- **【画面】** PPT 第 8 页右上角原文四条：「网络架构：多分支，branch / 多组分工合作 / 贡献：1. 三大要素：数据+模型+cuda显卡 2. 首次引入ReLU 3. 首次引入Dropout」——这是本节最核心的一张画面增量。
- **【直译】** LeNet-5 提出了卷积算子，但没展示出威力；真正证明"卷积神经网络能吃下大规模图像识别"的是 AlexNet。它成立的三个支柱是：ImageNet（数据）、深层 CNN（模型）、CUDA 消费级显卡（算力）。
- **【为什么】** 三要素这个框架至今没变，只是数值变了：数据从 1400 万张图变成万亿 token，模型从 6000 万参数变成 671B，显卡从 GTX 580 变成 H100。你判断任何一个 AI 项目能不能做成，就问这三格填得满不满。
- **【连接】** 作者：Alex Krizhevsky（一作）、Ilya Sutskever（后来 OpenAI 联创）、Geoffrey Hinton（图灵奖）。⚠ 老师顺口说的"Alex 在淘宝上找显卡"是段子，实际是两块 GTX 580。

### 14 首次引入 ReLU 与 Dropout：Dropout 能放哪不能放哪（00:39:11 – 00:43:26）

> **谢博**：「AlexNet 是第一次引入 ReLU 这个激活函数，同时还采用了 Dropout。Dropout 是什么意思？随机丢掉一些神经元，为了解决过拟合的问题……那我问你，这个输出层可不可以 Dropout？这一层是一个全连接，有 1000 个节点。不行。输入层和输出层都不能 Dropout……那我问你，Dropout 这个操作可不可以用在卷积上面？可以的，因为它是针对神经元来说的，你卷积和全连接是不是都是有神经元的？」

- **【直译】** 三条结论：①Dropout 的操作对象是神经元，随机置零；②**输入层和输出层不能做**——输出层 1000 个类，丢掉一半就等于凭空少了 500 个类别；③**卷积层可以做**，因为卷积也有神经元（上节课"特征图有几个数就有几个神经元"）。
- **【为什么】** 学生最常见的误解是"Dropout 是全连接专属"。老师用"它针对的是神经元，而卷积也有神经元"一句话破掉。工程上确实主流是 `nn.Dropout2d`（按通道整片丢）而非按点丢，但概念上没有禁区。
- **【连接】** ⚠ 转写把 Dropout 听成了 **"揪发我它 / Jobout / Jobalt / 就发的"** 等至少 5 种写法，是本课最严重的转写噪声。你的 MNIST 模板里如果有 `nn.Dropout(0.5)`，检查一下它是不是接在最后的 `Linear(*, 10)` 前面——那正是老师说的"输出层"，应该往前挪一层。

---

### 15 靠近输入做 Dropout = 特征选择："我不听我不听"（00:43:26 – 00:45:02）

> **谢博**：「这一层的卷积我们不用 Dropout。为什么呢？因为在这里如果做 Dropout，它会产生一个特征选择的作用。你给我这么多个数，224×224×3 这么多个特征，我一 Dropout，假如说 Dropout 50%，那我其实只用了一半……我有一半的特征没有采纳。就像你说"谢博我给你 10 个理由"，我一 Dropout，你说完 5 个我就说我不听我不听我不听——我一上来就拒绝你了。」

- **【直译】** 越靠近输入做 Dropout，丢掉的越是**原始特征**（还没被加工过的），等价于"没听完就下结论"。而在中间隐藏层做 Dropout，丢的是已经被加工过的中间表示，网络还有别的路径能补回来。
- **【为什么】** 这条给出了"Dropout 一般用在中间隐藏层"这个惯例的真实理由——不是习惯，是**信息可恢复性**。原始输入丢了就是永久丢失；中间表示丢了，同一信息往往在别的通道里还有副本（这正是 Dropout 想强迫网络学到的冗余性）。
- **【连接】** 这跟本课后半段的 ResNet 有一条暗线：Dropout 怕的是"浅层信息传不到深层"，残差边解决的也正是"浅层信息传不到深层"。一个是通过不阻断，一个是通过开旁路。你可以把它们放在一起记。

---

### 16 过拟合的主语是"模型函数"，且样本永远带偏差（00:45:02 – 00:49:13）

> **谢博**：「我们说 Dropout 是为了防止过拟合。那过拟合说的是谁？是数据集，还是模型函数？过拟合是模型函数，是这个神经网络……现象是什么？他在训练集很 OK，但是在测试集很差。为什么？因为这个模型太复杂了。本来我是一个线性的模型，但是你把这个模型设计成一个二次的，那你就会完美地拟合这个样本的分布，但是样本的分布本身就存在错误。」

- **【推导/代码】** 老师画的图：三个采样点，真实模型是一条直线，但用二次函数去拟合，就会拐着弯穿过三个点——**误差被当成规律学进去了**。
- **【为什么】** "过拟合的主语是模型，不是数据"这个纠正很有价值。日常说"这个数据集过拟合了"其实是错的，过拟合描述的是"模型函数的复杂度超过了数据能支撑的信息量"。
- **【连接】** 00:47:38 起老师用**小杨的体重**延伸："这世界上没有人知道他多重。买个电子秤称 10 次取平均，准确吗？我们拿到的数据永远只能无限接近真值。"——**数据带偏差是常态**。对应你在 BEV 上的痛点：nuScenes 的 3D 框标注本身就有误差，模型在训练集上刷到 0.99 多半是在拟合标注噪声。

**【小结】** ①AlexNet 的架构贡献是多分支，两支权重独立、中途 concat 融合；②历史贡献是奠定"数据+模型+显卡"三要素，还首次引入 ReLU 与 Dropout；③Dropout 针对神经元，卷积层能用，但输入层/输出层不能用，越靠近输入越像"特征选择"；④过拟合的主语是模型函数，且样本本身永远带偏差。

## Part 4 · ResNet 结构：什么才算"残差"（00:49:02 – 01:00:01）

**【本段在讲什么】** 从这里进入本课的重头戏。谢博先只讲"**怎么做**"——一条直连边，把输入原样加到两层卷积的输出上。然后他把定义反复拧了三遍：几个模块算不算？全连接算不算？pooling 算不算？答案分严格与广义两套口径。最后回到名字本身：为什么叫"残差"而不叫"相加"，这个名字来自 `F(x) = H(x) − x` 这个变换视角。【画面】PPT 上有英文原始定义和何凯明的论文出处，转写完全没读。

### 17 直连边就是残差：plain 与 residual 的分野（00:51:12 – 00:53:34）

> **谢博**：「ResNet 的结构呢是这样子的：这里有一个叫 weight layer，那你可以把它换成，比如说这个是卷积，两个卷积。正常来说我们是没有这条边的。那残差网络呢，他就是有一条直连边——这个就是残差网络……有了残差之后，我们的网络结构可以分为两种：一种叫扁平的，plain，plain 就是扁平的意思，比如 VGG；这个就是残差的。」

- **【推导/代码】** 最小残差块的 forward 只多一行：
  ```python
  out = self.conv2(self.relu(self.conv1(x)))
  out = out + x          # ← 这一行就是全部的"残差"
  ```
- **【直译】** 网络世界从此二分：**plain（一杆子通到底，VGG 是代表）** vs **residual（带直连边）**。老师强调"两个模块加一条残差边"是最标准的形态。
- **【为什么】** 老师这里的教学顺序值得学：**先讲"怎么做"（一条边），再讲"为什么"（后面 40 分钟）**。因为"怎么做"简单到一句话，学生一旦被复杂的动机绕住，反而记不住这个极简结构。
- **【连接】** ⚠ 转写里 ResNet 被听成 **zlet / rease net / 残仓 / 残查 / 常常网络 / 瑞士代**，VGG 被听成 **vc data / vvc**，plain 被听成 **play / 排种 / 点平**。你在 BEVFusion 的 `SECOND` 里看到的每一个 `BasicBlock`，就是这里的"两个卷积 + 一条边"。

### 18 几个模块、什么模块都行，关键在 weight layer（00:53:34 – 00:55:13）

> **谢博**：「三个模块加一条残差边，这叫不叫残差网络呢？只要有直连边，就叫残差模块或者叫残差网络。那假如这个模块是个全连接呢？也叫残差……它这里面叫的是什么呢？叫 weight layer，weight layer 就是带权重的。那假如说这里是 pooling 呢？严格来说按照这个定义来说，这种就不叫残差，为什么呢？因为没有 weight。pooling 有 weight 吗？没有。」

- **【推导/代码】** 严格口径：跨过去的必须是 **weight layer**（有可训练参数），所以 `FC` 可以、`Conv` 可以、`Pooling` 不可以。广义口径：不管中间是啥，只要有直连边就叫残差。
- **【为什么】** 这个区分有实际意义。残差的两个作用（前向保浅层特征、反向 +1 保梯度）里，**反向那个作用只有在跨过带权重的层时才有价值**——pooling 本来就不怎么衰减梯度，跨它没意义。所以"weight layer"不是措辞讲究，是机制要求。
- **【连接】** 你在 BEVFusion 的 `BasicBlock` 里会看到 `downsample` 分支：当主路 stride=2 改变了形状，直连边上会插一个 `1×1 Conv + BN`。注意——**那个 1×1 卷积是 weight layer**，所以严格意义上它已经不是纯 identity 了，业界叫它 projection shortcut。面试问"identity mapping 和 projection shortcut 的区别"，答案就在这里。

### 19 【画面】PPT 的英文原始定义与论文出处（00:55:13 – 00:56:26）

> **谢博**：「这篇残差论文对行业影响很大，这篇论文是现在人类有史以来引用因子最高的，不仅局限于人工智能计算机科学，所有学科里面。好像据说已经有 30 万引用次数了。所以说比如像何凯明来到中国，一定要给他一个院士人家才会来，不是靠年龄的。」

- **【画面】** 老师这时打开的是 `D:/AI课程资料/1-讲义v1/11-卷积神经网络/11-7 ResNet与DenseNet.pdf` 第 1 页，PPT 原文三条（转写一个字没念）：

  - For some reason, need to skip at least two layers

  图上标注：`x → weight layer → relu → weight layer → ⊕ → relu`，旁路标 `x identity`，左侧标 `F(x)`，加法处标 `F(x) + x`。

### 20 H(x) = F(x) + x ⇒ F(x) = H(x) − x：吃剩的那桌菜（00:56:03 – 00:58:22）

> **谢博**：「F(x) 代表这两层模块的函数，然后这边是 x，所以这个地方输出来是 F(x) + x。那为什么叫残差呢？我们把整个这个过程看作一个函数，假如说这个叫 H(x)，他是不是等于 F(x) 加上 x？你变换一下，那 F(x) 等于多少呢？等于 H(x) 减去 x。他是从这个表达式来说的，叫残差……吃剩的一桌饭，有 H 这么多菜，吃掉了 x，剩下的就叫残差。如果从 H(x) 这个角度来讲，他就不叫残差了，他叫 add module，或者叫 combine module。」

- **【推导/代码】** 两个视角，同一个结构：
  - **相加视角**：`H(x) = F(x) + x` —— 这是代码里实际发生的事，所以叫 add / combine。
  - **残差视角**：`F(x) = H(x) − x` —— 这是命名的来源。整块要学的目标是 H(x)，其中 x 部分白送，卷积分支只需要学**差额** F(x)。
- **【为什么】** 这个变换是理解残差威力的钥匙：**假设理想映射就是恒等（H(x)=x），那么 F(x) 只要学成 0 就行**——把一堆权重压到 0，比让它们精确拟合出恒等矩阵容易几个数量级。这就跟上一张卡 PPT 里那句 "make it easy to represent the identity mapping" 对上了。
- **【连接】** 面试标准答法：「残差块并不学目标映射本身，而是学它相对于输入的残差。当最优解接近恒等映射时，把残差压到 0 远比拟合恒等容易，所以加深网络不会变差。」这一句就把 Part 5 的退化问题也一起答了。

### 21 module 级创新可以升级成 architecture 级（00:58:22 – 01:00:00）

> **谢博**：「ResNet 他的创新不是整个网络的架构，他这个是 module 层的创新，就是他提出了一个 module。那整个网络怎么构建呢？就反复地堆叠这个 module 就可以了……当然我们后面也会把这个 module 扩展到整个网络架构层面。怎么个简单法呢？你比如说这个地方我就把这个特征图在这里再加一条边，到这里来，然后把这个特征图和这个特征图相加，再往后面传播——这不就是整个架构层面的吗？」

- **【直译】** 回到 Part 1 的坐标系：ResNet 的创新落在 **module 层**（提出 BasicBlock），网络本身就是把它堆 18/34/50/101/152 次。但**同一个思想可以升级到 architecture 层**——在整个网络的两个远距离位置之间拉一条长跳连。
- **【为什么】** 这就是 U-Net、FPN、DenseNet 的思想来源。老师这里其实是在给 DenseNet（01:34:02 会讲）铺路：DenseNet 把"每两层一条边"推到极致，变成"每一层都连到后面所有层"。
- **【连接】** 这条"module → architecture"的升级路径，你在 BEV 里天天见：BEVFusion 的 `SECOND` 里是 module 级残差（每个 BasicBlock 内部），而 `FPN` neck 把 `(64,512,512)` 那一级的特征跨越几十层直接送到 `(384,128,128)` 那一级去融合——那就是 architecture 级的跳连。两者一起用，不冲突。

**【小结】** ①残差 = weight layer 组 + 一条直连边，跨几层、跨什么层都行，但严格定义要求跨的是带权重的层；②`H(x)=F(x)+x ⇒ F(x)=H(x)−x`，"残差"这个名字来自后一个式子，本质是让恒等映射变得容易表达；③ResNet 是 module 级创新，但同一思想可以升级到 architecture 级。

## Part 5 · 为什么以前堆不动：退化问题（01:00:01 – 01:10:00）

**【本段在讲什么】** 这 10 分钟回答"为什么需要残差"。谢博先给出行业事实：在 ResNet 之前，20 层是天花板。然后带着读那张著名的退化曲线图，指出一个反常现象——**更深的网络连训练误差都更高**。接着他做了一个非常漂亮的论证：**理论上这不该发生**（杀鸡用牛刀，牛刀最差也能退化成杀鸡刀），实际发生是因为算力、时间、优化器三个现实约束都不理想。最后给出残差对设计者的意义：从此层数不是需要纠结的超参数。

### 22 天花板 20 层：ImageNet top-5 从 28.2% 到 3.57%（01:00:47 – 01:02:00）

> **谢博**：「残差最大的作用是什么呢？可以把网络的层数从十几层直接堆到 100 多层。那我们现在就有个问题了：为什么我们以前一直在十几层就成为我们行业的天花板了呢？」

- **【画面】** PPT 第 113 页（共 197 页）左侧文字："层数：不会超过 20 层 / ImageNet：1400 万个样本、2 万个类别、图像识别（分类）/ Top-5 error：[0.6, 0.2, 0.003, …]"；右侧是经典柱状图 *Classification: ImageNet Challenge top-5 error*，逐年数据见上文核心常量表（'10 shallow **28.2** → '12 AlexNet 8层 **16.4** → '14 GoogLeNet 22层 **6.7** → '15 ResNet **152 层 3.57**）。
- **【推导/代码】** Top-5 error 的定义顺带解释了 PPT 上那个 `[0.6, 0.2, 0.003, ...]`：模型输出 2 万类的概率向量，取概率最大的 5 个类，只要真值在这 5 个里就算对。
- **【为什么】** 这张表是"残差价值"的量化证据：从 22 层（6.7）到 152 层（3.57），错误率**腰斩**，而唯一的结构变化就是加了直连边。3.57% 也是第一次低于人类标注水平（约 5%）。
- **【连接】** 这张表你应该背下来，是面试讲"CNN 发展史"的标准骨架，且顺序恰好是本课的讲课顺序：AlexNet → VGG → GoogLeNet → ResNet。

### 23 两张退化曲线怎么读（01:02:40 – 01:05:04）

> **谢博**：「哪张图是 ResNet 的，哪张是 plain 的？横坐标是 iteration 迭代次数，纵坐标是 error。error 是大好还是小好？肯定小好。这是 18 层的，这是 34 层的，34 层在下面意味着它错误率低，效果好——这是不是符合你的预期？层数越多网络越复杂，越复杂是不是代表模型越好？……看这个不是残差的，横坐标还是迭代次数，纵坐标错误率，你看他网络越复杂，错误率越高，那网络越复杂又不行。」

- **【画面】** PPT 第 9 页放的是 ResNet 论文 Figure 1 + Figure 4 的组合：
  - **左二联图（plain）**：CIFAR-10 上 20-layer（黄）与 56-layer（红），左边是 training error、右边是 test error，**56 层两条都在上面**。图注原文："Training error (left) and test error (right) on CIFAR-10 with 20-layer and 56-layer 'plain' networks. - **【为什么】** 这里最关键的一点老师点到了但容易被漏掉：**退化不是过拟合**。过拟合的标志是"训练误差低、测试误差高"，而 plain-56 是**训练误差就更高**——它连训练集都学不好。这是"优化困难"，不是"泛化困难"，所以加正则、加数据都救不了，只能改结构。
- **【连接】** ⚠ 老师口述"这是 18 层这是 34 层"时指的是**右图**（ImageNet ResNet-18/34），而左边那两张是 **CIFAR-10 的 20/56 层 plain 网络**。转写按顺序读会串，笔记里已按画面还原。

### 24 理论上不该退化：杀鸡用牛刀（01:05:04 – 01:07:25）

> **谢博**：「这个东西要这样子来理解：理论上来说是不可能的。什么意思呢？比如说我的函数假如说是一个二次方的，但你真正的是一个一次方的。我用了一个二次方的、非线性的，逻辑上来说理想情况下我一定可以拟合好你的，跟你用线性的效果是一模一样的……杀鸡用牛刀，只是说成本高一点，但是效果一定是——你说小刀和牛刀，那肯定牛刀。你还说效果干不过小的？那不可能的。」

- **【推导/代码】** 老师在 01:07:25 补了这个论证的数学形式："如果真的是线性模型最好，我用二次的，理想情况下那个 x² 前面的 W 就会变成 0，它就退化成线性了。"
  即：`y = w₂x² + w₁x + b`，只要优化器能把 `w₂` 学成 0，二次模型就等价于线性模型。
- **【直译】** 更深的网络在假设空间上**包含**更浅的网络（多出来的层学成恒等就行）。所以更深的模型的最优解不可能比更浅的差——这是数学事实，不是直觉。
- **【为什么】** 这个论证是本课逻辑链的枢纽：既然理论上不该差，那实际变差就一定是**优化没找到那个解**，而不是**那个解不存在**。问题定位从"表达能力"转到了"可优化性"，这直接指向残差的设计动机（让恒等映射易于表达）。
- **【连接】** 这套"理论上界 vs 实际可达"的思路你在调 BEV 时天天用：模型容量够不够，跟能不能训出来，是两个正交的问题。BEVFusion 你用 mini 数据集训不动，不是模型太小，是数据/迭代不够——同一类判断。

### 25 三个现实因素：时间、算力、优化器（01:07:25 – 01:08:14）

> **谢博**：「但是为什么实际上我们又会遇到这个问题呢？很简单，就是因为我们在训练这个模型的过程中，你从来不会到理想的情况。首先你不会无穷无尽地训练它，时间无限长，不会；第二个你的资源不可能，算力不可能是无限的；第三你的优化器——梯度下降不可能是理想的。基于这三点的现实因素，才限制了我们当把模型增加的时候反而它的效果会出现退化。」

- **【直译】** 三个约束：①训练时间有限；②算力有限；③优化器本身不完美（梯度下降会陷局部极小、会梯度消失）。
- **【推导/代码】** 三条里**第三条才是残差直接对症的**。前两条残差也解决不了（残差网络该训多久还是多久）。而第三条里最要命的就是梯度消失——这正好引出 Part 6 反向传播那一节的 `+1`。
- **【为什么】** 老师这套"理想 vs 现实"的框架很适合迁移。你分析任何一个"论文说好用但我跑不出来"的模块，都可以套：是表达能力不够（理论问题），还是训练条件不够（现实问题）？如果是后者，再问是时间、算力、还是优化器。
- **【连接】** 你的 BEVFusion 训练计划里"无 AMP、只有 mini 数据、实测 0.481s/iter"，正好卡在①②两条上。所以你在 mini 数据上得到的 mAP 低，不能推出"模型不行"——这跟退化问题是同构的误判。

### 26 残差真正的意义：帮你解决"层数选择问题"（01:08:14 – 01:10:37）

> **谢博**：「残差网络核心是要解决什么问题呢？从神经网络的设计角度来讲，核心是要解决层数的选择问题……我们设计神经网络的时候，除了卷积核多少个、核的大小，是不是还涉及到这个网络到底我要构建多少层？有了残差网络之后，这个还是个问题吗？不是个问题了。准确率不够的时候，我就很简单，我就堆……以前我们必须要找到一个非常适中的、balance 的数字：少了欠拟合，多了他退化了。」

- **【直译】** ResNet 对"用网络的人"最实际的价值：**层数从一个需要精心权衡的超参数，变成了一个可以放心往上加的旋钮**。30 层只到 80%、老板要 90%？再堆 30 层。
- **【为什么】** 老师加了限定："当然也不是那么简单，他在逻辑上解决这个问题。" 实际上堆到几百层后收益会饱和，显存和延迟会线性上涨。但"堆深不会更差"这个保证本身极有价值，它把搜索空间从"找最优层数"变成了"在预算内尽量深"。
- **【连接】** 这就是为什么 ResNet 有 18/34/50/101/152 一整个家族，而 VGG 只有 16 和 19 两个——**残差让"同一套设计缩放到不同深度"变成了免费的事**。YOLOv8 的 n/s/m/l/x 五个尺寸也是同一原理（`depth_multiple` 直接乘 block 数量）。

**【小结】** ①ResNet 之前 20 层是天花板，ResNet-152 把 ImageNet top-5 error 从 6.7% 干到 3.57%；②退化不是过拟合——更深的 plain 网络连**训练**误差都更高，是优化问题；③理论上更深不该更差（牛刀能退化成小刀），实际更差是因为时间/算力/优化器三个现实约束；④残差的工程价值是把"层数"从超参数变成了可放心加大的旋钮。

## Part 6 · 残差的两个角度：前向融合 + 反向 +1（01:10:00 – 01:37:04）

**【本段在讲什么】** 本课最有方法论价值的一段。谢博先给出一个**可复用的分析模板**：任何一个算法/模块，都从前向传播和反向传播两个角度各问一遍。然后分别执行：前向角度得到"低级特征 + 高级特征的融合"，反向角度得到那个著名的 `+1`。中间他还顺手给了一个更大的模板——"前向传播的所有改进，最终都可以归结为更好地提取特征，而更好地提取特征的核心是特征融合"。最后落到代码：残差怎么写、为什么 block 里全是 3×3/s=1/p=1、add 和 cat 的门槛差别。

### 27 分析模板：任何模块都从前向/反向两个角度问（01:10:37 – 01:11:27）

> **谢博**：「他为什么能解决这个退化的问题呢？分析这种算法里面的问题，都可以从两个角度去分析：一个前向传播，一个反向传播。」

- **【直译】** 一句话的方法论，但值千金。**前向问"它让特征变得更好了吗"，反向问"它让梯度更容易流动了吗"。**
- **【为什么】** 这两个角度是正交且互补的。老师在 01:23:25 明确说了："这两者缺一不可。你前向传播确实能提取更好的特征，但如果从反向传播来讲，你这个网络梯度消失风险增大了，你这个网络也很难堆叠到很深的层数。" 换句话说，一个模块只有**两边都不亏**，才能真正被采用。
- **【连接】** 拿这个模板过一遍已知的东西：**BN**（前向分布更易学 / 反向落在大梯度区，两边都赚）；**膨胀卷积**（前向增大感受野 / 反向不改链长，前向赚、反向中性）；**残差**（前向融合浅深 / 反向 +1，两边都赚）；**单纯加深网络**（前向表达力增强 / 反向链长增加、梯度消失风险上升，**前向赚、反向亏**）——所以才需要残差来对冲。

### 28 浅层是低级特征，深层是高级特征（01:11:27 – 01:14:04）

> **谢博**：「特征有哪些特征呢？总体来说我们可以分为浅层特征和深层特征。一个网络前面的浅层的这些模块提取的是低级特征，越到后面越是高级特征。低级特征是什么呢？轮廓啦、纹理啦、颜色啦、明暗啦。高级特征也叫抽象特征、语义特征，比较抽象。比如说这上面这张图片上这个东西有两只耳朵——耳朵就是一个抽象的概念。你不能说椭圆形的那玩意，椭圆形的那玩意这叫低级特征、几何特征。」

- **【推导/代码】** 对照表：**浅层/低级 = 几何特征**（轮廓、纹理、颜色、明暗；"一个 H 只有 10 像素的矩形"）；**深层/高级 = 抽象特征、语义特征**（"有两只耳朵"、"腿很短"）。
- **【为什么】** 判据是"**越贴近人类的认知，越是高级特征**"。这个判据比"层数深浅"更本质，因为它解释了为什么高级特征不能靠单层算出来——"腿短"这个概念，必须先有"腿"（中级），再有"腿相对身体的比例"（更高级）。
- **【连接】**【画面】01:13:36 老师在 ResNet18 结构图旁写了"低级"（靠近 image 那一端）和"高级"（靠近 fc 那一端）。这跟你在 YOLO 里的 P2/P3/P4/P5 完全对应：P2（浅、高分辨率、低级）擅长小目标定位，P5（深、低分辨率、高级）擅长大目标分类。你之前研究过的**加 P2 检测头提升小目标**，理论依据就在这张表里。

### 29 判断是猫，低级和高级特征都要；你画我猜的传递损失（01:14:04 – 01:19:27）

> **谢博**：「理想的情况来说，我们要综合判断这个图片上是一只猫，我们不仅需要高级特征，也需要低级特征。那如果我们没有这个残差边，这个低级特征就传不过来。为什么？因为每个特征往前面传的过程都要被加工一次……你有没有记得有一个综艺游戏，我画你猜，然后传递，结果本来是一只包，到了他那里变成一只火箭了。他每次一传递特征就会出现损失，最后出现偏差。」

- **【直译】** 两层意思：①**分类需要多尺度证据**——"有两只眼睛、有嘴巴、四条腿很短"里，"很短"是高级的，"矩形高 10 像素"是低级的，缺一不可；②**没有直连边，低级特征传不到深层**，因为每经过一层卷积就被重新加工一次，加工 30 次之后原始信息已经面目全非。
- **【为什么】** "你画我猜"这个类比精确得惊人：每个玩家 = 一层网络，画 = 特征提取，传递 = 前向传播，最后变成火箭 = 特征漂移。而残差边就是**允许你直接看第一个人的原图**。老师还给了一个自己的例子（01:15:32）："同学转述我的话，一加工就偏了，所以我说'不要这样说，我用什么词你就用什么词'——这就是让他走这条直连边。"
- **【连接】** 老师在 01:19:27 顺手升华了一下："**你们学习也要建立残差边**，学完今天的，上周的也拿过来融合一下。不能没有残差边，一直按部就班往前走，走到最后前面学的梯度下降都忘记了。" 这句可以直接当你的复习方法论——本笔记的【连接】板块干的就是这件事。

### 30 通用模板：前向传播的改进都归结为特征融合（01:19:27 – 01:22:39）

> **谢博**：「这里面再给你个通用的模板：任何问题从前向传播来讲，都是为了更好地提取特征。更好地提取特征，核心是什么呢？核心就是特征融合。那特征融合又会有很多维度：比如说浅层加深层；还有什么呢？还有尺度、多尺度……比如说 GoogLeNet 他就是多尺度，我用个 5 的核和 3 的核，提取的特征融合。我范围大一点看看这张图片，范围小一点看看这张图片，感受一下颗粒度不一样……而且这个特征融合可以在模块内部，也可以在网络架构。」

- **【推导/代码】** 老师给的完整分类：
  - **融合什么**：浅层↔深层（= 低级↔高级）；多尺度（不同大小的核 / 不同分辨率的特征图）
  - **在哪融合**：module 内部（Inception、BasicBlock）／ architecture 层面（FPN、DenseNet、U-Net）
  - **融合怎么做**：add（残差）／ concat（Inception、DenseNet）
- **【为什么】** 这个模板的价值在于**它能让你面对任何没见过的新模块都有话说**。老师自己说："任何一个网络、任何一个模块，他提出来的理由都是为了更好地提取特征……这就活了，你要善于发挥，那你就可以胡说八道了，为什么？方向没错。"
- **【连接】** 拿这个模板套你熟悉的东西，一个不漏：**BiFPN** = 多尺度融合 + architecture 层；**CA 注意力** = 通道×空间两个维度的特征重加权（也是一种融合）；**SPPF** = 同一张图上多个池化核的多尺度融合；**BEVFusion 的核心融合模块** = 相机 BEV 特征 + LiDAR BEV 特征的跨模态融合，本质仍是"两个 team 中期同步"。老师后面还补了细分维度（01:21:52）：小目标要提取哪些特征、密集目标、遮挡目标——这就是你做 BEV 检测时的实际难点分类。

### 31 反向角度：∂L/∂x = ∂L/∂h · (∂h/∂x + 1)（01:22:39 – 01:26:34）

> **谢博**：「第二个是反向传播。反向传播理由就是什么？所有优化他核心理由就一个：降低梯度消失的风险……我们是不是这样说的呀，h(x) = F(x) + x。那梯度传递到这里来的时候，假如说没有这个残差边，因为输入是 x 嘛，所以 ∂L/∂x 应该等于 ∂L/∂h 乘以 ∂h/∂x。这些他都是一个很小的数……如果这里一百层就一百项相乘。但是有了这个残差边之后，一切就变得不一样了：∂L/∂x 就变成 ∂L/∂h 乘以（∂h/∂x 加 1）。」

- **【推导/代码】【画面】** 老师在 ResNet18 幻灯片右侧手写的完整推导（01:26:15 帧）：
  ```
  h(x) = F(x) + X
  无残差：  ∂L/∂x = ∂L/∂h × ∂h/∂x
  有残差：  ∂L/∂x = ∂L/∂h × ( ∂h/∂x + 1 )
  ```
  数学上：`h = F(x) + x ⇒ ∂h/∂x = ∂F/∂x + 1`，代入链式法则即得。**那个 1 就是直连边贡献的常数导数**（`d(x)/dx = 1`）。
- **【为什么】** 这是全课最该背下来的一个式子。它解释了为什么残差是"结构上几乎免费、效果上决定性"的：加法在反向传播时**把梯度原样复制到两条支路**，所以直连边这条路上梯度永远是 1 倍，不衰减。
- **【连接】** ⚠ 转写里"梯度"被听成 **T度 / 剃度 / 贴度 / T2消失 / 推销的风险**，全篇 20+ 处。面试时这条式子是硬通货：被问"残差为什么防梯度消失"，写出这两行、指着那个 +1，比说一百句"缓解梯度消失"都有说服力。

### 32 10⁻⁶ 加个 1：把"必然"降成"概率"（01:26:34 – 01:28:55）

> **谢博**：「假如说他原来是 10 的负 6 次方，已经是个很小的数了，现在一加 1，那这一项是不是就又大起来了呀？意味着他是不是就有概率传得更远了？……原来 ∂L/∂x 是很多项相乘，可能有 100 项，这里面每个项，如果是 10 的负 3 次方，万一中间有三个这样的数，他不就变 10 的负 9 次方了吗？但是我们现在不一样了，好多项里面有加 1……这样子的话就可以——不是说一定会防，一定不会，是降低概率。」

- **【推导/代码】** 数量级演算：`10⁻³ × 10⁻³ × 10⁻³ = 10⁻⁹`（三项就崩了）；而 `(10⁻⁶ + 1) ≈ 1`，连乘 100 项仍然是 1 量级。
- **【直译】** 关键在老师最后那句限定：**"不是一定会防止，是降低概率"**。残差不能保证梯度不消失（如果 ∂h/∂x 是负数且接近 −1，反而会抵消），它只是让每一项从"必然远小于 1"变成"大概率接近 1"。
- **【为什么】** 这个分寸感是专业与半吊子的分界线。很多人背成"残差解决了梯度消失"，一被追问"那为什么还需要 BN、还需要好的初始化"就答不上来。正确表述是"**显著降低梯度消失的概率**"。
- **【连接】** 老师在 01:28:11 总结："残差网络你要理解三个问题：第一个他怎么做的（严格意义与广义）；第二个为什么他能解决网络退化的问题；第三个从神经网络设计的角度来讲他给我们的启示是什么——就是层数。"**这三问就是本课 ResNet 部分的考纲**，背这三条即可。

### 33 残差的代码写法：x = x + C2(C1(x))（01:28:55 – 01:30:28）

> **谢博**：「残差网络代码怎么写呢？你比如这个叫 C1，这叫 C2，你的 forward 里面要这样写：x1 = C1(x)，然后 x2 = C2(x1)，然后 x 要等于什么呢？x 加上 x2。」

- **【画面】** 老师在 `ResNet实战.pdf` 第 2 页 "Res Block" 幻灯片旁手写：
  ```
  x₁ = C₁(x)
  x₂ = C₂(x₁)
  x  = x + x₂
  ```
  幻灯片上是三个串联的残差块，每个块 `x → Convolution layer → ReLU → Convolution layer → F(x) → ⊕`，旁路标 `x: Identity`。
- **【推导/代码】** 完整的 PyTorch 版本（注意第二个 ReLU 在相加之后）：
  ```python
  def forward(self, x):
      out = self.relu(self.bn1(self.c1(x)))   # c1/c2 都是 Conv2d(c, c, 3, 1, 1)
      out = self.bn2(self.c2(out))
      return self.relu(out + x)               # ← add 之后再 ReLU
  ```
- **【连接】** 呼应第 10 张卡那条纪律：**原始 `x` 必须保住不能被覆盖**。这也是为什么大家习惯用 `out` 这个变量名——`x` 全程留给直连边。你在 mmdet3d 的 `SECOND` 源码里看到的 `identity = x` 是同一个动机。

### 34 add 要求形状全等：为什么 block 里全是 3×3 / s=1 / p=1（01:30:28 – 01:33:00）

> **谢博**：「这个 x 和这个 F(x) 结果是要加起来，加起来就意味着两个 tensor 要相加，这两个形状要一样才好加。形状不一样那一加就错了。比如说他是 3×5×6，然后他是 4×7×8，能加吗？不行……所以在设计残差模块的时候，要尽量保证他出来的形状不变。怎么样做到不变？最简单的常规操作就是 3×3 的卷积、stride 1、padding 1。核的数量好配吗？通道数好配吗？这就是为什么你看到这个网络里面都是 3×3。」

- **【推导/代码】【画面】** 老师在 Basic Block 幻灯片旁手写：`x₁ + x₂`，下面写 `3×5×6` 和 `4×7×8` 打叉，再写 `1×5×1`。核心结论：
  - `Conv2d(c, c, 3, stride=1, padding=1)` → 尺寸公式 `(H + 2·1 − 3)/1 + 1 = H`，**H、W 不变**
  - `out_channels = in_channels` → **C 不变**
  - 三个维度全不变 ⇒ 可以 add
- **【为什么】** 这一条把"所有 ResNet 都是 3×3"这个观察从"经验"上升成了"必然"。3×3+s1+p1 是**唯一同时满足"有感受野增长 + 尺寸不变 + 参数量可控"的最小配置**（1×1 没有空间感受野，5×5+p2 参数量翻倍多）。
- **【连接】** ⚠ 老师随后自己打了个补丁（01:32:57）："你不要一回又拿我的话来说，卷积不改变 size 就看情况，我只是说通用的原则。你如果完全这样，那你就属于过拟合了。" ——**当 block 需要下采样时（stride=2、通道翻倍），直连边上必须插一个 `1×1 Conv(stride=2)` 来对齐形状**。【画面】ResNet18 图上那些**虚线箭头**就是这种 projection shortcut，实线才是纯 identity。这是你读 `SECOND` 源码时 `downsample is not None` 那个分支的由来。

### 35 add / cat / 矩阵乘的门槛排序；DenseNet 与 CBR 顺序（01:33:00 – 01:37:12）

> **谢博**：「现在有两个 tensor，x1、x2 要做 cat 操作，有什么要求？这个要求比 add 高还是低？低。这个操作只要求 x1、x2 它的 H、W 一样就可以了。当然 cat 也可以指定哪个维度去 cat，一般我们是从 C 这个维度去 cat。所以加的要求是最高的，cat 的要求又低了一点，然后矩阵相乘要求又很高……最高的是矩阵乘，然后是加。」

- **【推导/代码】** 三种融合的门槛（从高到低）：**矩阵乘** `A@B` 要求 `A.shape[-1]==B.shape[-2]` 且 batch 维可广播、输出形状变；**add** `x1+x2` 要求 N、C、H、W **全部相同**、输出形状不变；**cat** `torch.cat([x1,x2],1)` 只要求除拼接维外全相同（即 **N、H、W 相同**）、输出 C 相加。
- **【为什么】** 这个排序是实用的调试速查表。遇到 shape mismatch 时，先看是哪种操作，就知道要对齐哪些维度。
- **【连接】** 01:34:35 起老师引出 **DenseNet**：「dense 就是很密的意思」，【画面】幻灯片上一串彩色特征图，每一层都有弧线连到后面所有层，标注 "Element-wise addition" 和 "Channel-wise concatenation"——**DenseNet 用的是 cat 不是 add**，正因为 cat 门槛低（不要求通道数相同），才能让"每层连所有后续层"变得可行。紧接着 01:36:09 他问了个选择题：`Conv → ReLU → BN` 还是 `Conv → BN → ReLU`？**答案是后者，所以叫 CBR**——先做线性变换，再做 Normalize，最后过激活函数。这个顺序是下一 Part 的引子：**BN 必须在激活函数之前，因为它的作用就是把数压到激活函数梯度大的区域**。

**【小结】** ①分析模板：任何模块都从前向（特征融合）与反向（梯度消失）两个角度问一遍，两边都不亏才值得用；②前向上残差让低级特征绕过层层加工直达深层；③反向上 `∂L/∂x = ∂L/∂h·(∂h/∂x + 1)`，那个 +1 把梯度消失从必然降成概率；④add 要求形状全等，所以 block 里全是 3×3/s1/p1，需要下采样时直连边上加 1×1 卷积；⑤门槛排序：矩阵乘 > add > cat。

## Part 7 · Normalize：为什么做、怎么做（01:37:04 – 02:04:00）

**【本段在讲什么】** 承接 CBR 的顺序问题，谢博用同一个模板拆 Normalize：**反向角度**是把数压回 0 附近，让激活函数还有像样的梯度；**前向角度**是"神经网络本质上是从一个分布映射到另一个分布"，归一化后的分布更容易被抓住规律。后半段是具体操作：两步（算 μ、算 σ）+ 一步规范化 + 一个可选的缩放平移。【画面】PPT 上有完整公式和一组具体数字（6/1/8 → μ=5, σ=3），转写里老师念得很跳。

### 36 反向角度：压回 0 附近，激活函数才有梯度（01:37:12 – 01:39:48）

> **谢博**：「为什么要这样做呢？防止梯度消失。如果我把这个 ReLU 换成 Sigmoid 你就好理解了。Sigmoid 是不是把一堆数映射压缩到 0 附近呢？……就是因为在这个位置——你比如说拿 Sigmoid 函数就很好理解，激活函数我们保证的是 0 附近左右的梯度，你无法去保证在整个实数域它都有好的梯度，这种函数不好找。所以它要在做完线性变换之后压缩，因为你做完线性变换这个数据的取值范围是负无穷到正无穷。然后你把它压缩到 0 附近，再去进激活函数，这个时候对激活函数求导数的时候，它才能够求出一个比较大的值。」

- **【推导/代码】** Sigmoid 的导数 `σ'(z) = σ(z)(1−σ(z))`，在 z=0 处取最大值 0.25，`|z|>4` 时已经小于 0.018。所以**输入落在哪个区间，直接决定了这一层能回传多少梯度**。
- **【直译】** 逻辑链：线性变换（Conv/FC）的输出范围是 (−∞, +∞) → 直接喂给激活函数，大概率落在饱和区 → 导数≈0 → 梯度消失。**Normalize 就是插在中间，把数搬回 0 附近的操作**。
- **【为什么】** 这就是 CBR 顺序的根本原因：BN 必须在 Conv 之后、激活之前，因为它服务的对象是激活函数。放到激活之后就完全失去了意义。
- **【连接】** ⚠ 转写里 Normalize 被听成 **novalize / 罗姆纳一支 / 罗布那一只 / 浪漫那一只 / norm内子 / loin**，Sigmoid 被听成 **SSIGMOD**，是本课后半段的主要噪声源。

> **谢博**：「这个图就是告诉你 Normalize 要解决什么问题。vanish，消失的意思……这个叫激活函数的 activation inputs，本来是这样子的。这一堆数通过 Normalize 之后压缩到以 0 为中心，然后 −1 到 1。Normal 是什么意思？归一化。Normal 其实叫正态分布——正态分布就是最正常的呀、最常见的呀。所以他用 Normal 这个词来形容正态分布，当然也叫高斯分布。」

- **【画面】** PPT 第 11 页（共 11 页）的完整内容，转写只念了一半：

### 38 前向角度：神经网络是"分布 → 分布"的映射（01:45:00 – 01:50:33）

> **谢博**：「我们要知道整个神经网络，比如说这里有个 x，这里出来 y。你熟悉数字识别，是不是 10 个数？里面是概率，加起来等于 1。那如果画成直方图呢？这 10 个数是不是就变成一个分布了呀……我们常规的理解是说从一个数映射到另外一个数，但实际上你不能这么简单地理解，他应该是——神经网络是从一个分布映射到另外一个分布。你要这样理解，你就能理解为什么 Normalize 能够强化前向传播。」

- **【推导/代码】** 老师两头都画了直方图：
  - **输出端**：10 类的概率向量 `[0.1, 0.7, …]`，横轴是类别、纵轴是概率 → 一个分布。判断为"1"只要求**峰值在 1 这个位置**，不要求输出是 `[0,1,0,0,…]`。峰陡说明模型好，峰平说明模型差，但**都属于同一个分布类型**。
  - **输入端**：`1×32×32 = 1024` 个像素值（0~255），横轴是像素值、纵轴是出现个数 → 也是一个分布。
- **【直译】** 所以网络干的事不是"把一个数变成另一个数"，而是"**把输入侧那个 1024 点的分布，加工成输出侧那个 10 点的分布**"。
- **【为什么】** 这个视角一旦建立，很多事情就通了：交叉熵为什么是两个分布之间的距离？为什么同一类图片"它的分布一定是类似的"（01:52:08）？为什么标签平滑有用（把 one-hot 这个极端分布放松一点）？——**都因为网络拟合的对象是分布，不是点**。
- **【连接】** 这条直接接你的 BEV 工作：CenterPoint 头输出的 heatmap 就是一张**空间概率分布**，训练时的 GT 是高斯核铺出来的分布而不是单个点。你之前疑惑"为什么 GT 要画成高斯圆而不是一个像素"，答案就是这一句——网络学的是分布对分布。

### 39 归一化后分布好抓规律 + 为什么每层都要做（01:50:33 – 01:53:53）

> **谢博**：「为什么我们做完 Normalize 之后这个特征提取就会更加简单呢？你做完 Normalize 之后，你这个直方图是不是就 0 到 1 之间了呀？0 到 1 之间它的分布是不是很好画？但如果说你里面的数是负无穷到正无穷，那它的这个分布是不是很凌乱、很不容易看出来？……神经网络它同样很烧大脑的呀，当然它烧的是 GPU。GPU 跑烧掉了他也没发现这个分布是个什么鬼分布，最高点在哪里、有几个最高点、它的趋势是怎么样……为什么每一层都要做？因为每一层你的激活函数都有可能会消失。不是说做一次就够了。」

- **【直译】** 前向侧的收益：把数据压到有限区间后，**分布的形状（峰在哪、有几个峰、趋势如何）变得容易被后续层"看见"**；如果值域是 (−∞,+∞)，同样的形状被拉得极散，网络要花更多参数和迭代才能抓住。
- **【为什么】** 最后那句解释了 BN 为什么要**每层都插**而不是只在输入端做一次：归一化的效果会被后续的线性变换重新破坏（乘上 W 之后值域又散开了），而且每一层都有自己的激活函数、都有自己的饱和风险。这就是 `Conv-BN-ReLU` 作为标准三件套被无脑重复几十次的原因。
- **【连接】** 你的 MNIST 模板里如果在 `transforms` 里写了 `Normalize((0.1307,), (0.3081,))`，那只是**输入端做了一次**。网络内部还需要 `nn.BatchNorm2d`。两者名字像但作用位置完全不同——这是新手最容易混的一对。

### 40 具体操作两步：算均值、算标准差（01:54:45 – 01:59:28）

> **谢博**：「Normalize 是不是个操作？跟卷积、激活函数、矩阵相乘、全连接一样，都是个操作。那这个操作它的对象是什么？对象就是个 tensor，是一堆数。你别说我拿个 1 来 Normalize，有意义吗？……长什么样才叫规范呢？要符合正态分布，均值是 0、标准差是 1。比如说 X 是 6、1、8，这三个数规不规范？不规范。要有正有负才叫规范……先求均值，三个数加起来除以 3；然后再求方差，方差开根号就是标准差。」

- **【推导/代码】【画面】** PPT「第 1 步：求均值，标准差」页：
  ```
  μ = (1/n) Σ Xᵢ = (6 + 1 + 8)/3 = 5
  σ = √[ (1/n) Σ (Xᵢ − μ)² ] = √[ ((6−5)² + (1−5)² + (8−5)²)/3 ] = √(26/3) ≈ 3
  ```
- **【直译】** 两个前提被点破了：①**Normalize 的对象必须是一堆数**（单个数没有均值方差可言）——这一点是后面 BN/LN/IN/GN 区分的基础，因为"哪一堆"就是它们的唯一差别；②规范的标准是"均值 0、标准差 1"，所以原始数据必须**有正有负**。
- **【为什么】** 老师用了一个很生活的方差解释（01:57:54）："贫富不均就叫方差大，方差小就叫共同富裕。比如马云一年 10 个亿，你才 10 万，这方差大不大？然后让他分一半给你，他 5.1 亿你 4.9 亿——这叫方差小。" 记住方差衡量的是"离平均水平的差距有多远"。
- **【连接】** ⚠ 老师口语里多次说"除以方差"，PPT 上写的是**除以标准差 σ**。面试别照搬口误。

### 41 x' = (x−μ)/σ：三个数的实算（01:59:28 – 02:00:22）

> **谢博**：「怎么做规范化呢？x 减去均值除以标准差。假如说你这里有一万个数，那一万个数也这样子：先求均值，再求标准差，然后每个数减去它的均值、除以它的标准差。这就是规范化了。看到没有，是不是有正有负啊？」

- **【推导/代码】【画面】** PPT「第 2 步：规范化」页，公式框里是 `X'ᵢ = (Xᵢ − μ) / σ`，下面三行实算：
  ```
  X'₁ = (6 − 5)/3 =  0.33
  X'₂ = (1 − 5)/3 = −1.33
  X'₃ = (8 − 5)/3 =  1
  ```
- **【直译】** 结果 `{0.33, −1.33, 1}` 果然有正有负，且大致落在 −1~1 区间。原始的 `{6, 1, 8}` 全是正数、集中在 1~8，完全落在 Sigmoid 的饱和区。
- **【为什么】** 注意这个操作是**逐元素**的，且是**可微的**（μ、σ 都是输入的函数），所以能塞进反向传播里。这一点跟"预处理阶段的归一化"根本不同——预处理时 μ、σ 是常数，BN 里 μ、σ 是随每个 batch 变化的量。
- **【连接】** 手算这三个数，是你验证任何 Normalize 实现是否正确的最小测试用例。你以后写 BEV 的自定义 norm 层，拿 `[6,1,8]` 喂进去看输出是不是 `[0.33,−1.33,1]`，五秒钟就能定位问题。

### 42 γ 与 β：不知道该设多少，就当 W 来训练（02:00:22 – 02:04:16）

> **谢博**：「实际上我们也可能会出现——就是 Normalize 但不是标准的 Normalize，这个就是对整个分布进行了缩放和平移。平移就是加了那个偏置项，那个偏置项可能是正可能是负。什么叫伸缩呢？原来是这样子的，把它拉长，但他们之间还是符合这个分布……我们只要保证它符合 normal 的分布，它的均值点和它的方差我们可以不一样，就是非标准的。它只要是 normal 就可以了……这两个参数具体设置多少呢？我们可以把它当作 W 一样去训练。」

- **【推导/代码】【画面】** PPT「缩放和平移」页，副标题："为了好训练，深度学习里面一般会对规范化好的数据再来点小 trick"。公式框：
  ```
  X_i^norm = γ * X'_i + β
  ```
  页脚注释（转写没念）：「γ：缩放因子。β：偏置因子。**这两个参数和神经网络的权重一样，参与训练，由反向传播算法自动更新，并不需要人为指定。**」
- **【直译】** 归一化把所有层的输出都强行按到标准正态，可能反而限制了表达能力。γ、β 让网络**自己决定**这一层最终的分布该有多宽、中心在哪。标准正态是 γ=1、β=0 的特例。
- **【为什么】** 老师在这里点出了一个更普遍的深度学习方法论（02:02:39）："本来这个应该像超参数一样去指定它，像学习率一样。但是如果你不知道指定多少为好的时候，这里就告诉你一个思路——**把它看作 W 一样去训练**。" 这个思路的适用面极广：Swin 的相对位置偏置、可变形卷积的 offset、YOLO 的 anchor-free 分布参数（DFL），全都是"不知道设多少，那就学"。
- **【连接】** 在 PyTorch 里，`nn.BatchNorm2d(16)` 的 `weight`（就是 γ，初始化为全 1）和 `bias`（就是 β，初始化为全 0）会出现在 `model.parameters()` 里，跟着优化器一起更新。⚠ 老师口误说"γ 和 β 都是偏置偏移"，实际 **γ 是缩放、β 才是偏移**。

**【小结】** ①反向角度：Normalize 把数压回 0 附近，激活函数才有像样的梯度，所以顺序必须是 Conv → BN → ReLU；②前向角度：神经网络本质是分布到分布的映射，规整的分布更容易被抓住规律，且每层都要做；③操作三步半：算 μ、算 σ、`x'=(x−μ)/σ`、再可选地 `γ·x'+β`；④γ、β 不用人指定，当 W 一样训练——这是一个可迁移的通用思路。

### 43 代码现场：batch=8 的 (8,16,32,32)（02:06:39 – 02:09:04）

> **谢博**：「我现在以这个为例，这是不是一个很简单的卷积神经网络？现在进来……你训练的时候怎么会用 1 呢？你一次 batch，每一次前向传播比如说你可能是 8 张。那每张图片是什么呢？是 3、32、32。这里 RGB 的那这个就是 3……卷积完之后这个特征图变多大了呀？是 16 了呀。」

  class SimpleCNN(nn.Module):
      def __init__(self):
          super(SimpleCNN, self).__init__()

          return x

### 44 全局 Normalize：131072 个数一起算，且形状不变（02:09:04 – 02:12:58）

> **谢博**：「Normalize 这里面总共有多少个数啊？是不是 8 乘 16 乘 32 乘 32？如果我们做 Normalize 有好几种手段呢，什么 BN、LN、IN——如果不区分这个，那怎么做啊？就是全局 Normalize……先算这么多个数的均值，再算这么多个数的标准差，然后每个数再算自己 Normalize 之后对应的值。现在问你，做完 Normalize 之后它的形状会不会改变？我说原来是 10 个数，现在一 Normalize 完蛋了少了一个数？不会。形状会不会变、位置会不会变？都不会。原来这个位置是什么数，他还在这个位置，只是值不一样了。」

- **【推导/代码】** 全局 Normalize 的数据量：`8 × 16 × 32 × 32 = 131,072` 个数，算出**一个** μ、**一个** σ，然后 131072 个数每个都做 `(x−μ)/σ`。
- **【直译】** 两条结论：①不加任何修饰词的"Normalize"= 所有数一起算；②**Normalize 是一个逐元素的、保形状保位置的操作**——跟 ReLU 一样，只改值不改结构。
- **【为什么】** "形状不变"这一点必须先钉死，因为接下来讲 BN 分组时，学生很容易以为"分成 16 组"会改变张量结构。分组只影响**统计量是跟谁一起算的**，不影响输出张量的排布。
- **【连接】** 这也解释了为什么 BN 可以随便插在网络任何位置而不需要改后面的层——它是 shape-preserving 的。你在 ONNX 导出时看到 BN 被折进前面的 Conv（BN folding），前提也是它逐元素的线性性质：`γ(wx+b−μ)/σ + β` 可以合并成一个新的 `w'x + b'`。

### 45 BN：按 C 切成 16 组（02:12:58 – 02:16:10）

> **谢博**：「我们做的 Normalize 叫 BN。BN 是什么意思？前面是不是加了个修饰词，这个 B 代表 batch，叫 batch normalize。那 batch normalize 是不是说把这个 batch 的数据放在一起 normalize 呢？是也不是……区别在于选的数据不一样，就是你跟谁在一起做 normalize。你看这个图：他把同一通道的数据拿出来放在一起做一次……如果按照 BN 的做法，是不是要把它分成 16 组啊？这个不就开窍了吗？」

- **【画面】** 老师打开 `11-6 BatchNorm.pdf` 第 4 页（共 13 页），标题 "Batch Norm"，四个立方体并排：**Batch Norm / Layer Norm / Instance Norm / Group Norm**。每个立方体三个轴标注：纵轴 `H, W`，左下 `C`，右下 `N`。蓝色高亮部分就是"一起算统计量的那一组"：
  - **Batch Norm**：沿 C 方向取薄薄一片，在 N 和 H,W 方向铺满
  - **Layer Norm**：沿 N 方向取一片，在 C 和 H,W 方向铺满
  - **Instance Norm**：只有一根柱子（固定 N 和 C）
  - **Group Norm**：几个相邻 C 合成一块，固定一个 N
  出处链接：`https://medium.com/syncedreview/facebook-ai-proposes-group-normalization-alternative-to-batch-normalization-fb0699bffae7`
- **【推导/代码】** 对 `(8,16,32,32)`：BN 按 `C=16` 分成 **16 组**，每组含 `8×32×32 = 8192` 个数，算出 **16 对 (μ, σ)**。所以 `nn.BatchNorm2d(16)` 的参数量是 `16(γ) + 16(β) + 16(running_mean) + 16(running_var)`。
- **【连接】** 这就解释了 `nn.BatchNorm2d(num_features)` 里那个 `num_features` 为什么必须等于**通道数**而不是 batch size——它是"组数"，而 BN 是按通道分组的。

### 46 高考按省录取：跟谁一起排名决定你的命运（02:16:10 – 02:18:33）

> **谢博**：「但是你想想，这个跟你一起做 normalize 是不一样啊，为什么？因为他均值不一样啊。我跟比如说小杨是个大富豪，我跟他一起做 normalize，完蛋了，我就变成 0.00 几了。假如说我找一个比我还没钱的，那我一做 normalize 我就变成 1 了呀……就像你高考一样录取。我说高考，我们是不是按省去排名去录取啊？假如说清华去 1000 个人，我全国排名我就完蛋了，那不是西藏啊、贵州啊那不是 100 年出不了一个？我们是每个省给他设定比如说 200 个、300 个——这不就是分组做 normalize 吗？」

- **【直译】** 两个类比说的是同一件事：`(x−μ)/σ` 的结果**完全取决于 μ、σ 是用哪一堆数算的**。同一个 x，跟富人一组变成极小的负数，跟穷人一组变成正数。
- **【为什么】** 这精确击中了 BN/LN/IN/GN 之争的本质：**分组方式定义了"什么算正常"**。BN 按通道分组 = "同一特征通道内部互相比较"——某个通道整体数值偏大是它的固有量纲，归一化掉不影响判别；而全局一起算会把通道之间的相对强弱抹平。
- **【连接】** 反过来也解释了 BN 的著名缺陷：统计量跨样本，所以 **batch size 太小时 μ、σ 抖得厉害**——这就是显存紧张的 3D 检测任务常改用 GN 或 SyncBN 的原因。你在 BEVFusion 配置里看到的 `norm_cfg=dict(type='BN')`，多卡训练时往往要换成 `SyncBN`，理由就在"跟谁一起算"这五个字。

### 47 一组到底是哪些数：x[:, 0, :, :] 的调试器实证（02:18:33 – 02:22:45）

> **谢博**：「那就分成了 16 组。比如说其中一组变成什么样子的呢？第一个是不是全部取啊？第二个呢是 0，第三个是不是全部取？第四个是全部取。总共多少个数啊？是不是 8×32×32？这么多个数作为一组，他们自己做 normalize……那为什么这个叫 batch normalize 呢？因为这个组里面是不是有 8 个样本呢？这个组里面有第一个样本的数据，也有第二个、第三个样本的数据。就是第一个样本也要派点代表来参加，第二个样本也要派点代表来参加。」

- **【画面】** 02:18:44 帧，PyCharm 的 **Evaluate** 对话框里输入表达式 `x[:,0,:,:]`，Result 展开显示 `result = {Tensor: (8, 32, 32)}`，`data = {Tensor: (8, 32, 32)}`，`T = {Tensor: (32, 32, 8)}`，`grad_fn = <SliceBackward0>`，`is_cpu = True`。**这是本课最硬的一张画面证据**——老师把"一组"这个抽象概念用一行切片打成了具体形状。
- **【推导/代码】** BN 的第 i 组 = `x[:, i, :, :]`，形状 `(8,32,32)`，共 8192 个数。一行验证：`x[:,0,:,:].mean()` 等价于 `x.mean(dim=(0,2,3))[0]`。
- **【为什么】** 老师这里点破了 "Batch" 这个名字的真正来源：**不是"整个 batch 一起算"，而是"每组里都包含了 batch 中所有样本的一部分数据"**（每个样本派它的第 i 个通道来参加）。这个区分他强调了三遍——"不是所有数据，如果是所有数据不就又变成全局了吗"。
- **【连接】** 这就是 BN 在**推理时必须特殊处理**的根本原因：一组里混了不同样本的数据，意味着**样本 A 的归一化结果依赖样本 B**。训练时这是正则化的来源（噪声），推理时这是不可接受的（结果不该随同 batch 的其他图变化）。

### 48 LN 按 N 分 8 组；IN / GN 只是换个切法（02:22:45 – 02:25:22）

> **谢博**：「那我问你这个 LN 明白了吗？LN 是不是按 N 来分呢？N 来分，那他就分成 8 组嘛。那组 1 里面的数据只有来自哪个样本的啊？只有第 1 个样本的。那就是样本和样本之间他的数据是不会相互影响啊，但是 BN 是不是就有相互影响？所以他叫 batch normalize。所以 layer 他是这个样本内部自己做 normalize……那 instance 是不是就不用说了呀？group normal 还要说吗？如果你需要我说，那就说明你连这个 Python 最基本的切片都没学好。」

- **【推导/代码】** 对 `(8,16,32,32)` 的四种切法，用 PyTorch 切片一次说清：
  | 方法 | 组数 | 一组是 | 每组元素数 | 统计量个数 |
  |---|---|---|---|---|
  | 全局 | 1 | `x[:,:,:,:]` | 131072 | 1 |
  | **BN** | 16 | `x[:, i, :, :]` | 8×32×32 = 8192 | 16 |
  | **LN** | 8 | `x[n, :, :, :]` | 16×32×32 = 16384 | 8 |
  | **IN** | 8×16=128 | `x[n, i, :, :]` | 32×32 = 1024 | 128 |
  | **GN**（g=4） | 8×4=32 | `x[n, 4i:4i+4, :, :]` | 4×32×32 = 4096 | 32 |
- **【为什么】** 老师这个"用切片统一四种 Norm"的讲法极其高效——**记忆负担从"记四个定义"降到了"记一个切片模板 + 哪些维度被固定"**。核心口诀：**被固定的维度就是分组维度，被 `:` 铺满的维度就是一起算统计量的维度。**
- **【连接】** LN 的关键性质是"样本之间不相互影响"，这正是它在 NLP/Transformer 里通吃的原因（句子长度不同、batch 内样本差异大）。你以后做 BEV 的 Transformer（BEVFormer 那一路），里面全是 LayerNorm 而不是 BatchNorm，理由就在这句话。

### 49 推理时 batch=1 怎么办（02:25:22 – 02:28:00）

> **谢博**：「推理的时候方差怎么是一个数呢？推理走到这里是一样的……就是推理的时候这里不是 8 吗？训练的时候这里是 8，推理的时候是 1，没关系啊，该怎么做怎么做。如果你是 1 的话，到这里是不是 1、16、32、32？那同样干嘛？跟刚刚那一样的逻辑，分 16 组啊。你做 normalize 还是这样子的，按规则来——这是第一组，就这么多数一起做 normalize。你们按照这个思路去推一下，自己就明白了。」

- **【直译】** 老师的口径是"按规则来"：batch=1 时张量是 `(1,16,32,32)`，照样按 C 分 16 组，每组 `1×32×32 = 1024` 个数，照样能算 μ、σ。
- **【为什么】** ⚠ **这里要打一个重要的补丁：老师讲的是"分组规则不变"，但 PyTorch 实际推理时不是这么做的。** `nn.BatchNorm2d` 在 `model.eval()` 模式下**不重新计算 batch 统计量**，而是用训练期间用动量累积下来的 `running_mean` / `running_var`：
  ```python
  # 训练时（model.train()）
  running_mean = (1 - momentum) * running_mean + momentum * batch_mean
  # 推理时（model.eval()）
  y = γ * (x - running_mean) / sqrt(running_var + eps) + β   # 与 batch 内其他样本无关
  ```
  原因正是第 47 张卡说的：一组里混了多个样本，如果推理时现算，同一张图跟不同的图组 batch 会得到不同的结果——这是不可接受的。老师说的"分 16 组"在**分组语义**上是对的，但**统计量来源**上要按 running stats 理解。
- **【连接】** 这条对你做 BEV 部署是直接的坑：①导出 ONNX 前**必须 `model.eval()`**，否则 BN 会被导成训练模式，推理结果乱跳；②TensorRT 做 BN folding 时折进去的就是 `running_mean/running_var`；③如果你用 mini 数据集训练、迭代次数太少，`running_var` 还没收敛，会出现"训练 loss 很好但 eval 崩掉"的现象——先检查 BN 的 running stats，这是高频故障点。
- **【连接·收尾】** 转写在 02:28:24 之后是 Whisper 幻觉（"我看不下"×19 + 一句无关的频道广告），⚠ 非课程内容，已折叠。

**【小结】** ①不加修饰词的 Normalize = 所有数一起算，`(8,16,32,32)` 就是 131072 个数一个 μ 一个 σ；②Normalize 保形状保位置，只改值；③BN/LN/IN/GN 的唯一区别是"哪些数放一起算"，用 PyTorch 切片就能统一描述；④BN 叫 Batch 是因为每组里都有 batch 中所有样本派来的"代表"，这既是它的正则化来源，也是它推理时必须改用 running stats 的原因。

### 复习最小集（三句话，背下来就够）

1. **残差 = `H(x)=F(x)+x`，等价于让卷积分支只学差额 `F(x)=H(x)−x`。** 前向上它让浅层低级特征绕过层层加工直达深层（特征融合）；反向上它把 `∂L/∂x = ∂L/∂h · ∂h/∂x` 变成 `∂L/∂h · (∂h/∂x + 1)`，那个 **+1** 把梯度消失从"必然"降成"概率"。所以层数不再是需要纠结的超参数。
2. **残差块里全是 3×3 / stride=1 / padding=1，不是习惯是必然**——因为 `add` 要求两个 tensor 的 N、C、H、W **完全相同**；需要下采样时，直连边上要加一个 `1×1 Conv(stride=2)` 来对齐（projection shortcut）。门槛排序：矩阵乘 > add > cat（cat 只要 H、W 一致）。
3. **Normalize 就四步：算 μ、算 σ、`x'=(x−μ)/σ`、`x^norm = γ·x' + β`（γ、β 当 W 一样训练）。** BN/LN/IN/GN 的唯一区别是"选哪些数一起算 μ、σ"：对 `(N,C,H,W)`，**BN 固定 C**（`x[:,i,:,:]`，共 C 组）、**LN 固定 N**（`x[n,:,:,:]`，共 N 组）、**IN 固定 N 和 C**、**GN 固定 N 和一组相邻 C**。它们都不改变张量的形状和位置，只改值。
