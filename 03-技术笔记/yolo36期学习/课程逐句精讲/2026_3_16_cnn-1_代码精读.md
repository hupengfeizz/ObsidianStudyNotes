### 1 · 池化的反向传播（01:06:01 – 01:14:00）【画面 01_12_21】

**你将会写**：用 autograd 把这道面试题当场跑给面试官看。

**知识**：PPT 第 27 页原文（转写完全丢失）：
`最大池化：[[3,2],[1,0]] → 3；反向 3 → [[3,0],[0,0]]`
`平均池化：[[1,1],[0,2]] → 1；反向 1 → [[0.25,0.25],[0.25,0.25]]`

```python
a = torch.tensor([[[[1.,1],[0,2]]]], requires_grad=True)
F.avg_pool2d(a,2).backward();  print(a.grad)   # [[0.25,0.25],[0.25,0.25]]
b = torch.tensor([[[[3.,2],[1,0]]]], requires_grad=True)
F.max_pool2d(b,2).backward();  print(b.grad)   # [[1.,0.],[0.,0.]]
# 想拿到 argmax 路由本身：
y, idx = F.max_pool2d(b.detach(), 2, return_indices=True)
print(F.max_unpool2d(y, idx, 2))               # [[3.,0.],[0.,0.]]
```

**关键数字 / 坑**：avg 2×2 → `1/4 = 0.25`，3×3 → `1/9`，k×k → `1/k²`。
⚠ 老师说的「**W = 1**」是错的——**池化层没有 W**，只有梯度路由/均分，不产生权重更新，面试别照搬。
max 池化 2×2 意味着 **75% 的位置梯度为 0**（上面 `b.grad` 就是证据）。

### 2 · 用 stride=2 卷积代替池化（01:13:00 – 01:14:00）

**你将会写**：一眼看出一个网络的"年代"，并知道自己该怎么写下采样。

```python
# 老式：Conv + MaxPool
nn.Conv2d(64,128,3,stride=1,padding=1)   # 3*3*64*128 = 73728 参数
nn.MaxPool2d(2)                          # 0 参数，硬丢 75% 信息，梯度稀疏
# 现代：一步到位
nn.Conv2d(64,128,3,stride=2,padding=1)   # 还是 73728，下采样变成可学习的
```

**关键数字 / 坑**：**参数量一模一样**，但下采样从"硬规则"变成"可学习"。

**接到你的项目**：YOLOv5 backbone 里**一个 MaxPool 都没有**（SPPF 内部那几个是做多尺度感受野，不是下采样），
全靠 `Conv(k=3,s=2)`；BEVFusion 的 SECOND 从 (64,512,512) 到 (384,128,128) 全是 `SparseConv3d(stride=2)`。
看到 Conv+MaxPool 堆叠，基本可以判定是 2015 年前的网络。

### 3 · 参数量公式（01:29:00 – 01:33:02）【画面 01_31_12】

**你将会写**：不打开代码就报出任意一层的参数量，并用一行代码自查。

**知识**：手写板蓝笔原文 `W_count = (3×3×128×256)`，下面标注 `K_h × K_w × input_C × output_C`。
老师同时在红笔写了**网络优化四方向**：① params 要少 ② 特征要强 ③ FLOPs 要减小 ④ 网络要深（**小目标不深**）。

```python
import torch.nn as nn
conv = nn.Conv2d(128, 256, 3, bias=False)
print(conv.weight.shape, conv.weight.numel())   # [256,128,3,3]  294912
# 加 bias 要 +out_C：294912 + 256 = 295168
```
 
**关键数字 / 坑**：294,912。老师在 01:59:00 明确「**偏置不考虑 bias**」——本节所有数字都是 `bias=False` 口径。
`conv.weight` 第 0 维是 **out_C**，后三维才是「一个核」的形状：**输入通道被吃掉，输出通道靠核数**。

**接到你的项目**：`yolov5n` 第一层 `Conv(3,16,6,2,2)` → `6*6*3*16 = 1728`；
BEVFusion 里 `SparseConv3d(64→128,k=3)` 多一个 K 维 → `3*3*3*64*128 = 221184`。同一把尺子。

### 4 · 参数量与输入尺寸无关（01:32:02 – 01:34:00）

**你将会写**：向面试官/同事证明"改 imgsz 不用改网络"。

```python
c = nn.Conv2d(128, 256, 3)
print(c(torch.randn(1,128,3,3)).shape)      # [1,256,1,1]
print(c(torch.randn(1,128,300,300)).shape)  # [1,256,298,298]
print(c.weight.numel())                     # 294912  ← 同一个 c，一个参数没变
```

**关键数字 / 坑**：这就是**权重共享**的代码级证明，也是 CNN 能吃任意尺寸输入的根因（**前提：网络里没有 FC**）。
推论很重要：既然与 H、W 无关，**减参数就只能动 K、Cin、Cout 这三项**——后面 1×1 / 分组 / DW 全在这个框里。

### 5 · FLOPs 与那个 ×2（01:34:00 – 01:41:01）【画面 01_36_28 / 01_37_18】

**你将会写**：手算一层的 FLOPs，并看懂论文里 FLOPs 和 MACs 差一倍的原因。

**知识**：DeepSeek 网页上完整的数字链（老师照着念）：

```
128 × 3 × 3 = 1152            ← 每个输出点的 MACs（乘加次数）
256 × 30 × 30 = 230400        ← 输出位置总数
230400 × 1152 = 265420800     ← 总 MACs
× 2 = 530841600               ← FLOPs（乘、加各算一次）
```
页面上方还有个被 DeepSeek 自己标注「（这个数太大）」的错误中间量 `132710400 × 256 = 33973862400`，
老师也念了一遍——**别抄那个数**。

```python
def conv_flops(Ho, Wo, Cin, Cout, Kh, Kw):
    macs = Ho*Wo*Cout*(Cin*Kh*Kw)
    return macs, macs*2
print(conv_flops(30,30,128,256,3,3))   # (265420800, 530841600)
```

**关键数字 / 坑**：**一层**卷积参数只有 0.29 M，FLOPs 却是 5.3 亿——**Params 和 FLOPs 是两个独立指标**。
`thop.profile` / `ptflops` / ultralytics 的 `model.info()` 打印的 GFLOPs **实际是 MACs 口径**，
看到别人的数字是你的一半，先问口径再吵架。

### 7 · im2col：卷积在底层是矩阵乘（01:45:01 – 01:50:04）【画面 01_49_39】

**你将会写**：用 `F.unfold` 手写一个卷积，验证它和 `F.conv2d` 完全相等。

**知识**：PPT 第 54 页的完整数值链（转写完全丢失）：
输入 4×4 = `[[1,2,3,0],[4,5,6,0],[7,8,9,0],[0,0,0,0]]`，核 2×2 = `[[1,2],[4,5]]`，**s=2**。
画面标注：「卷积核 K 摊平为 **4×16**」@「输入 X 摊平为 **16×1**」= `4×1` → reshape `2×2`，
旁边红字「**卷积计算多对 1**」。

```python
x = torch.tensor([[1.,2,3,0],[4,5,6,0],[7,8,9,0],[0,0,0,0]]).view(1,1,4,4)
cols = F.unfold(x, kernel_size=2, stride=2)      # [1, 4, 4]：每列是一个感受野
k    = torch.tensor([1.,2,4,5]).view(1,4)
print((k @ cols[0]).view(2,2))                   # [[46,27],[23,9]]
print(F.conv2d(x, k.view(1,1,2,2), stride=2))    # 同上，逐元素相等
```

**关键数字 / 坑**：`1×1+2×2+4×4+5×5 = 46` ✓。
PPT 的摊平方向（核摊成 4×16 的**稀疏大矩阵**）和 PyTorch 的（核 1×4 × 输入 4×4）是两种等价写法：
前者暴露稀疏性，后者省内存。GPU 快的原因就在这里——它做的是 **GEMM**，不是 for 循环滑窗。

### 8 · 稀疏连接 + 权重共享，用数字说（01:50:04 – 01:54:00 / 03:29:00）【画面 03_29_45】

**你将会写**：把"CNN 是稀疏全连接"这句话变成一个能跑的等价矩阵。

**知识**：课末那张图给了最干净的证据：输入层 **240** 个神经元（= 10×8×3 摊平），
第一个隐藏节点的公式在图上写全了——
`x_1·w_1 + x_2·w_2 + x_11·w_3 + x_12·w_4 + x_81·w_5 + x_82·w_6 + x_91·w_7 + x_92·w_8 + x_161·w_9 + x_162·w_10 + x_171·w_11 + x_172·w_12 = −23`。
**240 个输入里只有 12 个参与**，且这 12 个 W 会被 63 个节点（9×7）**共用**。

```python
# 把一层卷积显式展开成等价的稀疏全连接矩阵
x = torch.randn(1,3,8,10); w = torch.randn(1,3,2,2)
cols = F.unfold(x, 2)                    # [1, 12, 63]  ← 12 = 2*2*3，63 = 9*7
W_eq = torch.zeros(63, 240)
idx  = F.unfold(torch.arange(240.).view(1,3,8,10), 2).long()   # 每列的原始下标
for j in range(63):
    W_eq[j, idx[0,:,j]] = w.flatten()    # 只有 12 个位置非 0
print(W_eq.count_nonzero().item(), W_eq.numel())      # 756  15120  → 稀疏度 95%
print(torch.allclose(W_eq @ x.flatten(), F.conv2d(x,w).flatten(), atol=1e-5))  # True
```

**关键数字 / 坑**：等价全连接矩阵 63×240 = 15,120 个位置，**非零只有 756 个（5%）**，
而**独立参数只有 12 个**。老师说这题「十个有九个答不上来」。
面试答法：「稀疏连接 + 权重共享 + 平移等变性」——最后一项他没说，是你的加分项。

### 9 · 2 个 3×3 = 1 个 5×5（02:09:01 – 02:14:01）【画面 02_04_00】

**你将会写**：现场算出堆叠 3×3 到底省多少参数。

**知识**：PPT 原文（来源 `zhuanlan.zhihu.com/p/54011524`）：
`28×28` 用 5×5：`(28-5)/1+1 = 24`；用两层 3×3：`(28-3)/1+1 = 26`，`(26-3)/1+1 = 24`。

```python
x = torch.randn(1,1,28,28)
print(nn.Conv2d(1,1,5)(x).shape)                                    # [1,1,24,24]
print(nn.Sequential(nn.Conv2d(1,1,3), nn.Conv2d(1,1,3))(x).shape)   # [1,1,24,24]
print(2*3*3, 5*5, 18/25)      # 18 25 0.72   → 省 28%
print(3*3*3, 7*7, 27/49)      # 27 49 0.55   → 省 45%
```

**关键数字 / 坑**：PPT 写"约 30%"，精确值是 **28%**。
三条好处**缺一不可**：① 参数少 ② 网络更深 ③ **多了一次非线性**（两个 3×3 中间夹 ReLU，5×5 只有一次）——
第三条最容易漏答。⚠ 老师中途说过"感受野不同"随即自我更正，**感受野是一样的**。

### 10 · 输出尺寸公式与两个特例（02:15:02 – 02:17:00）

**你将会写**：不查文档就把 `padding` 填对。

```python
# H_out = floor((H + 2p − d(k−1) − 1)/s) + 1
x = torch.randn(1,8,32,32)
print(nn.Conv2d(8,8,3,stride=1,padding=1)(x).shape)   # [1,8,32,32] ← same
print(nn.Conv2d(8,8,3,stride=2,padding=1)(x).shape)   # [1,8,16,16] ← 减半
```

**关键数字 / 坑**：`p = (k−1)/2 且 s=1` → 尺寸不变；`k=3,s=2,p=1` → 尺寸减半。
**这两个特例覆盖 95% 的实际代码**。老师原话：「算那玩意儿没必要，也没有人考你」——

### 11 · 1×1 卷积六大作用（02:17:00 – 02:19:00、02:36:02）【画面 02_35_16】

**你将会写**：读懂 `C3` / `Bottleneck` / `Detect` 里那些 `k=1` 到底在干嘛。

**知识**：PPT 原文六条（老师明确：**第 2、3 条答不上来直接挂**）：
1. 不改变特征图的 h、w
2. 可以改变特征图的**数量**（大家叫升维/降维，但 h、w、dim 都没变，改的是 **shape**）
3. 输出 channel 变少时，**参数量和计算量同时下降**
4. 增加非线性，增加表达能力
5. 空间信息的沟通和融合
6. 能够起到全连接的作用

画面 `02_43_21` 还给了最小算例：`[[1,2,3],[4,5,6],[7,8,9]] × [2] = [[2,4,6],[8,10,12],[14,16,18]]`。

```python
x = torch.randn(1,64,20,20)
print(nn.Conv2d(64,16,1)(x).shape)   # [1,16,20,20]  h/w 不动，只动 channel
print(nn.Conv2d(64,16,1,bias=False).weight.numel())   # 1024 = 1*1*64*16
```

**关键数字 / 坑**：1×1 的参数量 = `Cin × Cout`，**没有 K² 这一项**，所以它是"零空间代价的通道旋钮"。

### 12 · 压缩-还原：73,728 → 19,456（02:19:00 – 02:24:01）【画面 02_20_20】

**你将会写**：手搓一个 ResNet Bottleneck 并算清它省了多少。

**知识**：PPT 图 4-31 原文（红笔圈出两个数）：

```
A（直接 3×3）    ：A计算量 = 3*3*64*(3*3*128) = 663552 ； A参数量 = 3*3*128*64      = 73728
B（1×1压缩到16 + 3×3）：B计算量 = 3*3*64*(1*1*16)+3*3*16*3*3*128 = 175104 ； B参数量 = 1*1*16*64+3*3*128*16 = 19456
```

```python
A = nn.Conv2d(64,128,3,padding=1,bias=False)
B = nn.Sequential(nn.Conv2d(64,16,1,bias=False), nn.Conv2d(16,128,3,padding=1,bias=False))
print(sum(p.numel() for p in A.parameters()))   # 73728
print(sum(p.numel() for p in B.parameters()))   # 19456   → 26.4%
# 压缩比不够狠会反噬：中间设 64（= 不压缩）
print(1*1*64*64 + 3*3*128*64)                   # 77824 > 73728  ← 反而更多
```

**关键数字 / 坑**：⚠ 老师口头说"少接近三分之一"，**画面数字是 19456/73728 = 26.4%，即降到约 1/4、省 73.6%**。面试报数按 1/4 说。
中间通道是**超参**（这里 16），但老师那句"如果不是 16，你有可能变多"是精确的：**压缩比必须够狠才划算**，行业惯例压到 1/4。

**接到你的项目**：YOLOv5 `Bottleneck` 就是这个结构，`c_ = int(c2 * e)`，`e=0.5`——
你以前看不懂的那个 `c_`，就是这里的 16。

### 15 · 分组卷积：`groups=G`（02:41:07 – 02:47:00）【画面 02_43_21】

**你将会写**：正确使用 `groups`，并知道它什么时候直接报错。

**知识**：PPT 公式原文：
`Parameters_conv = (K × K × Channel_in) × Channel_out` （4-5）
`Parameters_group_conv = (K × K × Channel_in/G) × (Channel_out/G) × G` → **1/G**
数值例：Cin=4、k=3、Cout=4 → 普通 `4×(3×3×4) = 144`；分 2 组 → 每组 `2×(3×3×2)=36`，共 **72** = 1/2。

```python
print(nn.Conv2d(4,4,3,bias=False).weight.numel())            # 144
print(nn.Conv2d(4,4,3,groups=2,bias=False).weight.numel())   # 72   ← 1/G
print(nn.Conv2d(128,256,3,groups=4,bias=False).weight.numel())  # 73728 = 294912/4
nn.Conv2d(128,256,3,groups=5)   # ValueError: in_channels must be divisible by groups
```

**关键数字 / 坑**：`Cin % G != 0` 或 `Cout % G != 0` 在**构造 `nn.Conv2d` 时就抛 `ValueError`**（不是运行时），这是改网络时最常踩的坑。
缺点老师用紫笔写在画面上：「① 减 W，**1/G** ② **通道信息不沟通**」——第 g 组的输出永远看不到第 g' 组的输入，
「**检出率大大的降**」。看到 `groups>1` 的代码，第一件事是问"它怎么把通道沟通补回来"（答案：channel shuffle 或 PW）。

**判据（老师原话）**：FLOPs 少 ≠ 跑得快。「最快的是标准卷积」——
**看到只报 FLOPs、不报实测 latency 的轻量化论文，直接跳过。**

### 17 · 空洞卷积：`dilation`（02:57:00 – 03:00:00）【画面 02_58_12】

**你将会写**：用 `dilation` 免费换感受野，并知道什么时候会漏采样。

**知识**：PPT 图 4-35 给了可完全复现的算例（7×7 输入，全 1 的 3×3 核）：
`普通：5+6+7+6+7+8+7+8+9 = 63`；`dilation=2：13+5+7+5+7+9+7+9+11 = 73`；`dilation=3：11+4+7+4+7+10+7+10+15 = 75`。

```python
img = torch.tensor([[11,2,3,4,5,6,7],[2,13,4,5,6,7,8],[3,4,5,6,7,8,9],
                    [4,5,6,7,8,9,10],[5,6,7,8,9,10,11],[6,7,8,9,10,11,12],
                    [7,8,9,10,11,12,15]], dtype=torch.float).view(1,1,7,7)
w = torch.ones(1,1,3,3)
print(F.conv2d(img,w,dilation=1)[0,0,2,2].item())   # 63.0  （5×5 输出的中心）
print(F.conv2d(img,w,dilation=2)[0,0,1,1].item())   # 73.0  （3×3 输出的中心）
print(F.conv2d(img,w,dilation=3).item())            # 75.0  （只剩 1 个点）
print(nn.Conv2d(64,64,3,dilation=2,padding=2,bias=False).weight.numel())  # 36864 = 3*3*64*64 不变
```

**关键数字 / 坑**：等效核 `k_eff = d(k−1)+1`（d=2 → 5，d=3 → 7），**参数量一分不涨**；
`padding=d` 才能保尺寸不变。
老师蓝笔两条：「① 参数量不变，感受野变大 ② **空洞卷积不能太多**」——最多 2~3 层、一般 1 层、**放中间层，浅层不能丢**。
学界叫 **gridding 漏采样**，解药是互质 dilation 序列（HDC，如 1-2-5，而不是 2-2-2）。

### 18 · 转置卷积：`nn.ConvTranspose2d`（03:01:04 – 03:09:00）【画面 03_25_32】

**你将会写**：写对上采样层的 `kernel_size / stride / padding`，并预判它的参数开销。

**知识**：PPT 第 54 页给了对称的两条链：
`卷积（下采样）：K摊平 4×16 @ X摊平 16×1 = 4×1 → reshape 2×2`，标注「卷积计算**多对 1**」；
`转置卷积（上采样）：K转置 16×4 @ X 4×1 = 16×1 → reshape 4×4`，标注「转置卷积 **1 对多**」。
即：**转置卷积 = 把卷积的等价矩阵 W 转置后再乘一次**，"转置"是字面意思，不是比喻。

```python
x = torch.randn(1,64,20,20)
up = nn.ConvTranspose2d(64,64,4,stride=2,padding=1,bias=False)
print(up(x).shape, up.weight.numel())     # [1,64,40,40]   65536
# 对比：无参数的插值
print(F.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False).shape)  # [1,64,40,40]  0 参数
```

**关键数字 / 坑**：老师原话「转置的 params、W 比较大——看到了吧，4 乘以 16」：
普通卷积那个核只有 4 个有效参数，转置卷积的等价矩阵占 16×4 = 64 个位置。**上采样天然比下采样贵。**
⚠ **`kernel_size` 必须能被 `stride` 整除**（如 4/2、2/2），否则输出像素被覆盖次数不均匀 → **棋盘伪影**。
`stride=2` 时用 `k=4, padding=1` 是安全默认。

**接到你的项目**：BEVFusion 的 `SECONDFPN` 用的正是 `nn.ConvTranspose2d` 做多尺度对齐——
知道它贵、有伪影，你才知道什么时候该换 `F.interpolate`。

### 19 · 上采样三方法与 API 对应（03:09:00 – 03:12:01、03:22:00）【画面 03_22_28】

**你将会写**：三选一，并说清选择理由。

**知识**：老师明确「上采样**只有三种方法**：最近邻插值、转置卷积、双线性插值」，面试概率约 30%。
API 边界也说清了：「`Upsample` 只能用在最近邻和（双）线性；`ConvTranspose` 只能转置卷积」。
`35-opencv笔记.pptx` 第 10 页给了单线性插值公式：`y = (x−x0)/(x1−x0)·y1 + (x1−x)/(x1−x0)·y0`。

```python
x = torch.randn(1,64,20,20)
F.interpolate(x, scale_factor=2, mode='nearest')                         # 最快，有锯齿，0 参数
F.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)    # 平滑，0 参数（默认首选）
nn.ConvTranspose2d(64,64,4,stride=2,padding=1)(x)                         # 可学习，65536 参数，有伪影
# 单线性插值自己实现一遍（对应 PPT 图 5-57）
lerp = lambda x0,y0,x1,y1,x: (x-x0)/(x1-x0)*y1 + (x1-x)/(x1-x0)*y0
print(lerp(0,10, 2,30, 1))    # 20.0
```

**关键数字 / 坑**：⚠ 老师说「严格应该叫三线性，因为求了三次」——**这是错的**。
bi/tri 指的是**维度数**：bilinear = 2D（图像），trilinear = 3D 体数据。**2D 图像上采样一律 bilinear**。
选择逻辑：**要快 → nearest；要质量且不加参数 → bilinear；要可学习且不怕伪影 → ConvTranspose**。

### 21 · 多通道卷积三条铁律（03:28:09 – 03:30:01）【画面 03_28_30 / 03_28_52】

**你将会写**：拿到任意一张多通道图，直接写出 `nn.Conv2d(...)` 的四个参数并预判输出 shape。

**知识**：课末学员（杨佳奇）的图把三条规则写死了（黄色高亮原文）：
① **特征图的通道数 = 卷积核的个数**；② **卷积核数量多、size 比较小**；③ **卷积核的通道数 = 输入的通道数**。
画面给的算例：`Img (RGB): 10*8*3`，`Kernel-1: 2*2*3`，输出 `Feature Map: 9*7`，
第一个输出值 `(1+4) + (5) + (-33) = -23`。

```python
c1 = torch.tensor([[1.,11],[3,4]])      # 画面 c1 左上 2×2
c2 = torch.tensor([[1.,5],[12,40]])     # 画面 c2
c3 = torch.tensor([[19.,101],[33,14]])  # 画面 c3
x  = torch.stack([c1,c2,c3]).view(1,3,2,2)
k  = torch.tensor([[[1.,0],[0,1]],      # w_1..w_4
                   [[0.,1],[0,0]],      # w_5..w_8
                   [[0.,0],[-1,0]]]).view(1,3,2,2)   # w_9..w_12
print(F.conv2d(x, k).item())            # -23.0  ← 与画面完全一致
# 整图 shape：H=8, W=10, k=2, s=1, p=0
print(F.conv2d(torch.randn(1,3,8,10), torch.randn(1,3,2,2)).shape)  # [1,1,7,9] = 9*7
```

**关键数字 / 坑**：`5 + 5 + (-33) = -23`——**三个通道的结果是相加，不是拼接**。

## 📌 复习最小集

1. **`W_count = Kh × Kw × Cin × Cout`（与输入 H、W 无关）；`FLOPs = Ho × Wo × Cout × (Cin·Kh·Kw) × 2`（与 H、W 强相关）。**
   本节标准算例：`Conv2d(128,256,3)` = 294,912 参数、30×30 输入下 530,841,600 FLOPs（265,420,800 MACs）。
2. **卷积在底层是 im2col + GEMM。** `F.unfold(x,2,stride=2)` 就能复现 `[[46,27],[23,9]]`；
   由此一次答完稀疏连接（等价 FC 矩阵 95% 是 0）+ 权重共享（12 个 W 被 63 个节点复用）。
3. **参数量家族速查（同一个算例，Cin=64/128，k=3）**：
   标准 73,728 → 1×1 压缩-还原 19,456（1/4）→ DW+PW 8,768（1/8.4）；分组卷积 = 1/G；空洞卷积不变。
4. **API 四件套**：`groups=Cin` 是 DW（必配 1×1 PW）；`dilation=d` 免费加感受野（`k_eff=d(k−1)+1`，最多 2~3 层放中间）；
   `ConvTranspose2d` 上采样贵且要求 `k % s == 0` 否则棋盘伪影；`adaptive_avg_pool2d(x,1)` = GAP，0 参数、尺寸无关。
5. **今晚可动手的一件事**：`yolov5n.yaml` 第 30、35 行 `'nearest'` → `'bilinear'`，同 seed 跑一遍对比 mAP。
