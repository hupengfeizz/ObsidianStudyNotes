## 项目一:智能割草机双目感知系统

**项目背景**:面向欧洲家庭花园割草场景,为亚马逊硬件生态厂商开发低成本双目视觉感知系统,对接 SLAM 与控制系统,实现自主避障与稳定作业。

**主要职责**:
- 数据与标注规范:检测数据集 14 万张、分割数据集 20 万张;定义"细类到决策类"的多层级标注规范(检测 22 类→5 类、分割 5 类→2 类);建设标签清洗 pipeline 与难样本分析框架
- 2D 算法开发:主导 YOLOv11s(20 类障碍物检测)+ PP-LiteSeg(草地分割)2D 算法链路,调整并提点
- 3D 目标定位:基于 2D 检测框与双目深度图反投影获取障碍物世界坐标 (X,Y,Z),尝试目标级稀疏点云生成,对接控制系统
- 端侧部署:RK3588 INT8 量化、算子迁移、C++ 部署、板端后处理优化

**项目难点**:
1. 低矮小目标(玩具、低矮宠物、躺姿儿童 <20×20 像素)与碎石漏检——"漏检 = 安全或硬件事故"是产品红线
2. 草地在阴影/过曝/泛红/黄草黄土边界/高草等状态下纹理剧变,导致漏割与出界
3. 落叶、细长树枝、光斑被误判为障碍物,触发频繁绕行劣化作业效率
4. 灌木被分为"非草"但实为硬障碍冲撞;长尾未知物体闭集模型无法应对
5. RK3588 5T NPU 需同时跑检测、分割、VSLAM,单算法仅 ~5 FPS 算力预算

**优化方案**:
1. 数据策略:检测端 Mosaic + Copy-Paste + 小目标过采样 + Focal Loss;分割端 Gamma 校正、泥土/黄草手动重标、淡红色草地扩充、关闭强 HSV;数据治理用错例回灌闭环
2. 决策融合:YOLO 框与分割结果空间互验抑制误报;灌木归检测做硬障碍;混入 5%–10% 杂项 + unknown 类,置信度可疑时保守避障
3. 分割双线选型:SegFormer-B0 作精度上限基准(BoundaryLoss with Sobel + TTA 多视角投票),二分类 mIoU 95%;PP-LiteSeg 作部署定型,分阶段损失 CE+Dice → OHEM-CE+Boundary+GDL
4. 量化加速:INT8 量化 pt 12.32MB → rknn 3.2MB(压缩 74%)+ 算子迁移 + 板端后处理融入 NPU 图,检测稳定 5 FPS(峰值 11 FPS)
5. 感知—控制频率联动:开阔区 5 FPS、密集区 15 FPS 自适应,配合控制 0.15–0.55 m/s 速度档位闭环

**项目成果**:
- 精度:安全关键类 Recall>92%,整体误报率 <8%,困难集 mAP@50 达 88.58%;草地分割 mIoU ≥95%,细分类平均 mIoU ≥88%
- 工程:RK3588 端到端感知全链路延时 <250ms,CPU 30% / 内存 0.9%,支撑 0.4 m/s 默认速度稳定作业,已完成软硬件联调与交付

## 项目二:AI 智能人脸跟随、手势识别自拍杆

**项目背景**:为消费电子厂商开发纯视觉智能自拍杆算法系统,"认主人—自动跟随—手势拍照"端到端体验:自动锁定并居中跟随注册用户、识别 11 类自拍手势触发快门,复杂场景下不误跟路人。

**主要职责**:
- 数据集处理:自采自标自拍手势数据集,定义 11 类手势规范与针对性数据增强
- 算法 Pipeline 架构:独立设计"人脸检测→关键点对齐→特征识别→多目标追踪→手势触发"五级级联视觉 Pipeline,封装 C++ 推理引擎,对外仅暴露单一 ProcessFrame 接口
- 2D 算法开发:RetinaFace 人脸检测、PFLD 关键点、MobileFaceNet 人脸识别、FastestDet 手势识别的选型、训练与迭代
- 跨框架端侧部署:4 个异构模型在 NCNN + ONNXRuntime 双框架集成与转换,INT8 量化部署至自拍杆 RV1106 NPU、FP16 移植至 Android,一套算法双端复用

**技术难点**:
1. 自拍专属手势(脸颊比心、托腮等)公开数据集中不存在;可采样本少、来源分布偏、类间视觉相似,易过拟合与混淆
2. 多模型串联对齐:跨框架数值一致性难保证,任一环节微小偏差被指数解码放大十倍以上
3. 框解码有误:NCNN 固化输入导致解码偏移、NMS 失效,凑近或畸变时检测/识别反而失败,多人同框易身份误锁
4. 多人/侧脸/遮挡/弱光下主目标易被更正脸的路人抢走,遮挡后丢失 ID
5. 云台跟随高频抖动,快速移动时跟随滞后
6. RV1106 算力/内存吃紧,NPU 仅支持 INT8 且不支持动态输入,量化易让 ArcFace 认错人

**优化方案**:
1. 自采自标 11 类手势 + FastestDet 微调 + 数据增强,mAP@0.5 约 90%
2. 检测根因攻坚:修复 PriorBox 多算 sqrt 致 anchor 偏差 16 倍的 bug + 迁移 ONNXRuntime,检出率提升至约 97%
3. 数值验证体系:自建诊断工具链,定位修复 3 个跨框架数值 bug,端侧输出与 PyTorch 完全一致
4. 复杂场景鲁棒追踪:多角度底库 + 运动维持 + 滞回切换,不误跟路人、遮挡 1 秒内重捕,ID 锁定率约 95%
5. 跟随防抖:中心死区 + 卡尔曼滤波 + GMC 补偿
6. 端侧量化:混合量化(敏感层保精度)+ 自采校准集,INT8 落地 RV1106

**项目成果**:
- 人脸检测检出率约 97%;身份验证准确率约 98%;主目标 ID 锁定率约 95%;11 类手势 mAP@0.5 约 90%;模型总参 2.6M、INT8 体积约 5MB
- 部署:RV1106 NPU 单帧 ≤50ms(约 20FPS);SDK 交付包 <10MB、运行内存 ≤50MB;同一套 C++ SDK 经 NCNN FP16 复用至 Android

## 项目三:围棋对弈机器人 2D 视觉感知系统

**项目描述**:面向青少年益智人机围棋对弈场景,为消费级围棋机器人厂商开发高精度、低延迟、强鲁棒的端侧视觉感知系统。

**主要职责**:
- 数据治理与任务重构:黑白子 84.7% vs 手 0.6% 的结构性失衡,将检测任务由 4 类重构为 3 类并制定长尾增强策略
- 空间几何与坐标映射:主导相机标定去畸变、单应性透视变换与静态锚点吸附方案,棋盘物理定位在视觉模块内部闭环解决
- 感知网络与损失定制:YOLOv8m 选型,自研 Shape-IoU + Inner-IoU + ATFL 损失,引入 DySample、SCSA 并逐模块消融
- 端侧部署与引擎对接:INT8 量化与 NPU 端侧移植;承接 KataGo 对接与棋力难度分级,定义视觉与引擎的零歧义接口

**项目难点**:
1. 空交叉点占 84.7%、人手仅 0.6%,类别极度失衡;361 点密集检测端侧 NMS 高达 60ms
2. 俯拍大棋盘桶形畸变与透视形变,需像素坐标零误差映射至 361 个交叉点,逐帧重算几何超端侧算力
3. 黑子高光泛白误判为白子、白子边缘融于棋盘漏检
4. 棋子恒为 1:1 圆形的强几何先验未被标准 CIoU 利用,且与人手共用回归策略相互干扰
5. 落子与机械臂震动产生噪声帧,单帧误检穿透下游引擎即触发非法落子且不可逆累积
6. 须 INT8 量化且控制精度损失

**优化方案**:
1. 静态-动态解耦:剥离空交叉点、精简为 3 类,一次性标定 + 静态锚点吸附替代逐帧密集检测,端侧 NMS 60ms → 5ms 以内
2. 几何标定与映射:张正友标定去畸变 + 双策略四角检测 + 单应性透视还原 800×800 正俯视 + KNN 锚点吸附,超阈值即拒绝并告警
3. 域定制损失涨点:Shape-IoU + Inner-IoU + ATFL,配 DySample、SCSA 逐模块消融,mAP@0.5:0.95 由 85.4% 提升至 91.0%
4. 软硬协同消光:高光白斑、HSV 抖动、随机擦除、Mosaic 增强,叠加镜前 CPL 偏振镜物理消光
5. 双级工程兜底:防抖状态机按帧间差分运动能量门控视觉输出,围棋算气规则引擎做落子合法性与提子校验
6. 端侧量化:INT8 + 敏感层回退 FP16 混合精度 + 极端光照校准集压低 KL 散度,端到端 85ms → 12ms、掉点 <1%

**项目成果**:
- 黑/白子 AP@0.5 各 99.5%、手部 98.7%,整体 mAP@0.5 99.2%、mAP@0.5:0.95 91.0%
- RK3588 NPU 端侧实时,单帧端到端 85ms → 12ms,精度损失 <1%

## 项目四:足球比赛智能分析系统(球检测与追踪)

**项目背景**:面向多相机实拍足球比赛场景,为赛事 AI 分析系统提供"球"目标的检测、追踪与三维定位,支撑射门、进球、传球路线、越位等事件分析。

**负责内容**:
- 数据集处理:半自动标注(模型预标 + 人工复核),约 4k 帧种子集经 2 轮扩充至约 8 万帧 / 7 万+球框,配套数据版本治理与可追溯
- 检测与追踪:独立负责"球"的检测、追踪与多相机融合全链路(球员追踪由他人负责),改进版 YOLOv8s-Ball 检测器与免 IoU 的 DFRKF 追踪器
- 三维数据交付:多相机标定 + 三角化,交付检测框、跨相机全局轨迹 ID、俯视图位置与三维轨迹/速度
- 性能调优:TensorRT FP16 量化与推理加速、多路并发调度

**技术难点**:
1. 小目标 1080p 下仅约 10 像素,常规检测头下采样即丢失像素
2. 盘带、抽射球剧烈移动致前后帧 IoU 常为 0,主流 IoU 追踪器结构性失效
3. 四路相机各自追踪,须保证同一球全局轨迹 ID 唯一、三维位置一致
4. 标注量少且球漏检率高,预标结果直接回灌会让漏检变成负样本污染训练集
5. 四路 1080p 并发需单台服务器同时满足 25fps 实时与三维定位精度

**优化方案**:
1. 小目标增强:SPD-Conv + CARAFE + P2 检测头 + SAHI 切片推理,召回较基线累计提升约 7 个点
2. 免 IoU 追踪:自研 DFRKF(中心距 + 长宽比关联)配合双阈值、方向一致性惩罚、丢失轨迹池
3. 多相机三角化:PnP 标定 + 多视角三角化 + 三维卡尔曼维护 ID,跨相机 ID 天然一致
4. 半自动标注守门:置信度分桶复核,空帧强制人工确认杜绝漏检回灌
5. 实时调度:FP16 量化 + 多路 CUDA 流并发 + SAHI 自适应启停 + 轨迹分级补帧

**项目成果**:
- 球检测 AP@0.5 94%、小目标召回率 92%;多相机融合后全局轨迹完整率 >99%、全场 ID 切换 0~3 次;地面定位精度 5~15cm、进球时刻位置误差 <0.5m
- RTX4090 单卡 + TensorRT FP16,端到端单路 30~40ms 达 25fps,单服务器并发 4 路 1080p;预留 Jetson 边缘端平移

## 项目五:航空航天结构件焊缝表面缺陷视觉检测系统

**项目背景**:面向航空航天结构件焊接后质量管控场景,针对气孔、裂纹、焊渣、划伤等表面缺陷人工目视漏检率高的问题,基于 2D 工业相机正面成像,构建"ROI 分割 → 切图 → ISP 增强 → YOLO 检测"端到端视觉流水线,实现产线级自动缺陷检测。

**负责内容**:
- 数据集处理:构建焊缝缺陷数据集与 teacher-student 半自动标注流水线,定义标注规范,应对 NG:背景约 1:7 的严重失衡
- 2D 算法开发:主导 ROI 提取分割网络与 YOLO 缺陷检测模型的选型、训练与迭代,攻克大图小目标、高相似背景、复合光照
- 端侧部署与性能调优:搭建落地前处理流水线并完成工控机部署优化

**技术难点**:
1. 大图小目标:5K×3K 原图、缺陷有效像素占比 <1%,下采样后小目标几乎无法检出
2. 周边误检:相邻焊缝、工艺孔、构件棱边及非焊缝区带入视野
3. 高相似背景:焊缝鱼鳞纹、焊渣飞溅与缺陷/气孔高度相似,叠加 NG:背景约 1:7 失衡
4. 复合光照:母材偏暗、焊缝余高反光过曝、孔洞偏黑三重失衡,过曝区误检集中
5. 数据稀缺与极端尺度:缺陷少、正负失衡,氧化变色场景无样本,超长裂纹/未焊透致 anchor 失配
6. 标注成本与伪标污染:逐像素精标成本高;教师"零预测"若当无缺陷并入训练,模型会学会忽略缺陷

**优化方案**:
- 象限切图放大:整图按象限 4 分割(优于 9 分割),目标相对尺寸提升约 4 倍
- ROI 精准提取:YOLOv5-n 分割提取焊缝 ROI + 非焊缝间隙图空标注负样本,Precision +2%
- 半自动标注扩样:teacher-student bootstrap(教师预标→优先级复核→review_status 守门合并→版本冻结/双轨注册),标注规模 240→670(2.8×);严格隔离教师零预测样本
- 难负样本与损失攻关:Other 类难负样本挖掘 + 分阶段训练 + 类内 NMS(Precision +10%);Focal Loss 在高置信预训练模型上梯度消失失效,改用 BCE² 抑制硬 FP,monkey-patch 零侵入不改源码
- ISP 光照补偿:IAT-high 曝光补偿前处理,P、R 双升
- 数据合成与增强:泊松融合 CopyPaste、MixUp 合成氧化色样本、超长缺陷拆密集小框,配合 CLAHE/模糊/蒙版切图/径向畸变抖动

**项目成果**:
- 缺陷检出率(召回)99.7%、精确率 97.6%
- 高性能工控机(Ubuntu + CUDA/TensorRT + 量化 + 多相机适配)多模块并行,单件焊缝检测约 2.5 秒,效率较人工提升 10 倍以上

## 项目六:智能物流跟踪检测系统(传送带货物计数 + 暴力操作检测)

**项目背景**:面向仓储出库环节,统计传送带货物出库数量以研判高峰、调配人力运力,并识别抛、扔等违规拣货行为以减少货损。

- 数据集处理:多源数据集(6083 张图 + 5 段视频),定义 5 类标注规范,扩充至 15360 组
- 检测与追踪:YOLOv5 检测模型搭建与训练,集成 DeepSORT 多类多目标追踪与去重计数
- 行为识别策略:「持货工人—传送带最短距离阈值」违规拣货判定
- 部署:TensorRT C++ API 重写推理流水线,Qt(C++) 多路实时监控后台

**项目难点**:
1. 现场明暗背景约 5:1,弱光场景货物/工人易漏检
2. YOLOv5 逐帧检测无目标身份,连续帧同一货物重复计数
3. 货物与工人多类目标同时追踪,DeepSORT 单类跟踪易 ID 串类
4. 抛/扔违规是动态行为,难以用目标检测直接当类别学习

**优化方案**:
- 光照增强与均衡:暗样本亮度对比度扩增(5:1→5:3)+ 直方图均衡化
- 追踪去重计数:DeepSORT(卡尔曼滤波 + 匈牙利匹配)稳定轨迹 ID,跨帧去重
- 多类分流追踪:货物与工人各跑一套 DeepSORT,避免 ID 串类
- 距离阈值判定:实时计算持货工人与传送带最短距离,超阈值判违规

**项目成果**:
- mAP@0.5 由 86.1% 提升至 92.8%,召回率 84.3% → 91.5%,MOTA 89%,计数准确率约 98%
- TensorRT C++ API + INT8 量化,单路端到端 22 → 68FPS(≈3×,量化 mAP 损失 <1%),模型 28MB → 7MB;Qt 多线程单卡 4 路实时

## 项目七:多模态大模型智能家居自主决策系统

**项目背景**:独立构建以多模态大模型为决策核心的家居中枢系统,融合摄像头视觉、传感器与家庭日程实现无显式指令的自主决策,私有化部署保障隐私。

**技术方案**:摄像头视觉 + 环境传感器 + 家庭日程多模态输入 → 轻量 VLM(CLIP 视觉编码 + LLM)理解场景 → BERT 意图识别分类 → LLM(Qwen 蒸馏版 3B,LoRA 微调)结合上下文推理决策、生成控制指令 → Home Assistant 多协议统一下发。私有化部署:vLLM/Ollama,INT4 量化,端云协同,数据不出户。

**优化方案**:VLM 多帧时序推理 + LLM 上下文决策实现"感知状态→推断意图";光照补偿 + ROI 聚焦提升真实家居视觉稳定性;3B 量化 + 端云协同 + 多信号交叉验证防误触发。

**项目成果**:意图识别准确率约 95%、LLM 决策正确率约 92%、误触发率 <1%;3B 模型部署于家用主机,决策秒级响应,Home Assistant 控制成功率 ≥99%。
