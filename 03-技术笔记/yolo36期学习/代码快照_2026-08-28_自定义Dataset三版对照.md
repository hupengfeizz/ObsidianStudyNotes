# 代码快照：自定义 Dataset 三版对照（pytorch-3 配套）

三版是同一知识点的三个形态：老师课堂原型 → 干净复刻实验 → 用户默写模板。

| 差异点 | ① day6.py 老师原型 | ② 36号复刻脚本 | ③ 用户默写模板 |
|---|---|---|---|
| 标签来源 | 文件名前缀 split('_') | 同左 | 子文件夹名 class_to_idx（ImageFolder 范式）|
| 读图 | cv2 灰度 + 手工/255 + from_numpy | 同左 | PIL + transforms.Compose(ToTensor 一站式) |
| 划分 | Dataset 内部切 8:2（先划分再打乱防泄露★） | 同左 + sorted | 目录 train/test 已分好 |
| 验证规范 | 无 model.eval()/no_grad | （无训练环节） | eval/train 成对 + no_grad ✅ |
| to(device) | 在 __getitem__ 里 | 不进设备 | 训练循环里统一 to（工程标准做法）|

**两个讨论点（疑似 bug，可与用户展开）**：
1. day6 的 `if h != 32 and w != 32` 应为 **or**——32×64 的图不会触发 resize，喂进网络炸 shape；②号改为 `shape[:2] != (32,32)` 正确
2. day6 的 `os.listdir` 无 sorted——文件顺序跨机器不保证，8:2 划分内容会飘；②③号均已补 sorted

"""
==========================================================
最简训练闭环 —— 标准默写版(自己手写 Dataset,不用 ImageFolder)
==========================================================
和 Mnist_train_standard.py 的唯一区别:
    ImageFolder  ->  MyImageFolder(自己继承 Dataset 写的)
训练脚本其余部分【一行都没改】—— 这就是统一接口的意义。

为什么要手写一遍:
  ImageFolder 只覆盖了「一个类别一个子文件夹 + 单标签分类」这一种格式。
  真实项目里(尤其是 3D 感知 / BEV)一个样本 = 多路相机 + 点云 + 标定 + 3D 框,
  标注在 json 里而不在文件夹名里,ImageFolder 完全用不上,只能自己写 Dataset。
  先把 ImageFolder 手写出来,以后写 nuScenes 那种就只是「换个解析逻辑」而已。

要求的目录结构(和 ImageFolder 一样的规矩):

    .../mnist_png/
        train/
            0/  xxx.png  xxx.png ...
            1/  ...
            ...
            9/  ...
        test/
            0/  ...
            ...
            9/  ...

★ 子文件夹名 = 类别名,按【字符串排序】自动编号:
  '0'->0, '1'->1, ... '9'->9。正好对上数字本身,很巧,但别当成理所当然。
  真实项目里类别名是 'cat'/'dog' 时,编号顺序就是字母序,一定要打印确认。
"""

'''
第一步,数据侧。 先定义 transform,训练和验证两套,训练那套可以带随机增强,验证那套只做必要规整,两套结尾都是 ToTensor。然后实例化 Dataset,把 transform 传进去。再用 DataLoader 包一层,训练集 shuffle 打开,验证集关掉。

第二步,模型。 继承 nn.Module,__init__ 里先调 super,然后把带参数的层实例化成属性——Flatten、三个 Linear。forward 里按顺序串起来:先拍平,再全连接加激活,最后一层直接吐 logits,不加激活也不加 softmax。

第三步,损失。 一行,CrossEntropyLoss。它内部自带 log softmax,所以模型最后一层才不能再加。

第四步,优化器。 一行,Adam 或者 SGD,第一个参数是 model.parameters(),把学习率传进去。这一步之前必须先把模型 to device,否则优化器拿到的是 CPU 上那份参数的引用。

然后是循环。 外层大循环按 epoch 转,内层小循环按 batch 转。

小循环里五步:数据 to device;zero grad 清梯度;前向拿预测;算损失;backward 加 step。累加 loss 的时候记得加 item,不然计算图会攒着不放。

每个 epoch 结束做验证。 切 model eval,套 with no grad,跑一遍验证集算准确率,算完切回 model train。

最后保存。 torch save 存 state dict,不要存整个模型对象。
'''


import os

import torch
import torch.nn as nn
from PIL import Image
from torch.optim import Adam
from torch.utils.data import DataLoader, Dataset   # ★ 这次要 import Dataset 了
from torchvision import transforms

# ==========================================================
# ★ 只改这两行
# ==========================================================
TRAIN_DIR = r"/home/hpf/project/36_PROJECT/mnist_lab/mnist_lab/data/mnist_png/train"
VALID_DIR = r"/home/hpf/project/36_PROJECT/mnist_lab/mnist_lab/data/mnist_png/test"


# ==========================================================
# ① Dataset —— 提供【单个】样本
#    三件套:__init__ 建索引 / __len__ 报总数 / __getitem__ 取一条
# ==========================================================
IMG_EXTENSIONS = (".png", ".jpg", ".jpeg", ".bmp", ".tif", ".tiff", ".webp")


class MyImageFolder(Dataset):
    """手写版 torchvision.datasets.ImageFolder(功能等价的最小实现)"""

    def __init__(self, root, transform=None):
        self.root = root
        self.transform = transform

        # --- 1) 扫类别:子文件夹名排序后编号 -------------------------
        # ★ 必须 sorted,否则不同机器上 os.scandir 的顺序不一样,
        #   类别编号会飘,训练好的权重换台机器就对不上了
        classes = sorted(d.name for d in os.scandir(root) if d.is_dir())
        if not classes:
            raise RuntimeError(f"{root} 下没有找到任何类别子文件夹")
        self.classes = classes
        self.class_to_idx = {c: i for i, c in enumerate(classes)}

        # --- 2) 收样本:把 (图片路径, 类别号) 全部存进列表 ------------
        # ★ 这一步只存【路径】,不读图片。
        #   几十万张图全读进内存会直接爆,真正读图是在 __getitem__ 里按需做的。
        self.samples = []
        for c in classes:
            cls_dir = os.path.join(root, c)
            for fname in sorted(os.listdir(cls_dir)):
                # ★ 必须过滤后缀:macOS 会到处塞 .DS_Store,
                #   Windows 有 Thumbs.db,不过滤 Image.open 直接崩
                if fname.lower().endswith(IMG_EXTENSIONS):
                    self.samples.append((os.path.join(cls_dir, fname),
                                         self.class_to_idx[c]))
        if not self.samples:
            raise RuntimeError(f"{root} 下没有找到任何图片")

    def __len__(self):
        # ★ 样本总数。DataLoader 靠它算一个 epoch 有多少个 batch
        return len(self.samples)

    def __getitem__(self, index):
        # ★ 给一个下标,返回【一个】样本。B 维不在这里加,是 DataLoader 加的
        path, label = self.samples[index]

        # ★ convert("RGB"):和 ImageFolder 的 default_loader 保持一致 ——
        #   不管原图几通道一律转 3 通道。所以下面 transform 里的 Grayscale 是【必需】的,
        #   不加就是 (3,32,32) -> Flatten 后 3072,喂不进 fc1(只接 1024),直接 shape 报错。
        #   (也可以这里直接写 convert("L") 出单通道,那 transform 里的 Grayscale 就可以省。
        #    两种写法只能二选一,别两边都省。)
        img = Image.open(path).convert("RGB")

        if self.transform is not None:
            img = self.transform(img)

        return img, label      # ← 这一对,就是训练循环里 for 出来的 x_data, labels


# ==========================================================
# ② 搭模型
# ==========================================================
class MyModel(nn.Module):
    def __init__(self, num_classes: int = 10) -> None:
        super(MyModel, self).__init__()

        # 算子层(有可学习参数 → 必须在 __init__ 里实例化)
        self.flat = nn.Flatten()
        self.fc1 = nn.Linear(32 * 32 * 1, 256)
        self.fc2 = nn.Linear(256, 256)
        self.fc3 = nn.Linear(256, num_classes)

        # 激活层(无参数 → 一个对象可以反复用)
        self.relu = nn.ReLU()

        # ★ 不要 softmax!CrossEntropyLoss 内部自带

    def forward(self, x):
        x = self.flat(x)          # ★ (B,1,32,32) -> (B,1024),进全连接前必须拍平
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.fc3(x)           # ★ 最后一层不加 relu、不加 softmax,直接吐 logits
        return x


if __name__ == '__main__':

    device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
    print("device:", device)

    # ==========================================================
    # ③ transform —— ★ 训练/验证必须分两套
    # ==========================================================
    # 训练集:带随机增强,让模型见到更多变化,防过拟合
    train_tf = transforms.Compose([
        transforms.Grayscale(num_output_channels=1),   # ★ 把 loader 转出来的 3 通道压回 1 通道
        transforms.Resize([32, 32]),
        transforms.RandomRotation(15),                 # ★ 随机 → 只能给训练集
        transforms.GaussianBlur((3, 3)),               # ★ 随机性质的扰动,同上
        transforms.ToTensor(),                         # HWC->CHW + /255.0 + float32
    ])

    # 验证集:只做"必要的规整",不能有任何随机
    # 否则每次验证结果都在抖,根本没法判断模型到底有没有变好
    valid_tf = transforms.Compose([
        transforms.Grayscale(num_output_channels=1),
        transforms.Resize([32, 32]),
        transforms.ToTensor(),
    ])

    # ==========================================================
    # ④ 实例化 Dataset
    # ==========================================================
    train_dataset = MyImageFolder(root=TRAIN_DIR, transform=train_tf)
    valid_dataset = MyImageFolder(root=VALID_DIR, transform=valid_tf)

    print("类别映射:", train_dataset.class_to_idx)   # ★ 养成习惯,一定要看一眼
    print("训练集样本数:", len(train_dataset))
    print("验证集样本数:", len(valid_dataset))

    # ★ 自己写完 Dataset,养成习惯先单独取一条看看形状对不对,
    #   别等进了训练循环再被 shape 错误炸出来
    img0, label0 = train_dataset[0]
    print("单样本 shape:", img0.shape, "| dtype:", img0.dtype,
          "| 取值范围: [%.2f, %.2f]" % (img0.min(), img0.max()),
          "| label:", label0)

    # ==========================================================
    # ⑤ DataLoader —— 把单个样本打包成 batch
    # ==========================================================
    # train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)    # ★ 训练要打乱
    train_loader = DataLoader(train_dataset, batch_size=4, shuffle=True)    # ★ 训练要打乱
    valid_loader = DataLoader(valid_dataset, batch_size=4, shuffle=False)   # ★ 验证不打乱

    # ==========================================================
    # ⑥ 模型 / 损失函数 / 优化器
    # ==========================================================
    model = MyModel().to(device)                                # ★ 模型绑设备
    criterion = nn.CrossEntropyLoss()                           # 内部 = log_softmax + NLLLoss
    optimizer = Adam(model.parameters(), lr=1e-3)               # ★ Adam 常用 1e-3

    epochs = 10

    # ==========================================================
    # ⑦ 训练循环:大 for(epoch) + 小 for(batch)
    # ==========================================================
    for epoch in range(epochs):

        # ---------- 训练 ----------
        model.train()                       # ★ 训练模式(BN 用当前 batch 统计量, Dropout 生效)
        train_loss = 0.0
        for x_data, labels in train_loader:
            x = x_data.to(device)           # ★ 数据绑设备
            y = labels.to(device)

            optimizer.zero_grad()           # ① 梯度清零
            pre_y = model(x)                # ② 前向传播
            loss = criterion(pre_y, y)      # ③ 算损失
            loss.backward()                 # ④ 反向传播(求梯度)
            optimizer.step()                # ⑤ 更新权重

            train_loss += loss.item()       # ★ .item() 取标量,否则会攒着计算图爆显存

        # ---------- 验证 ----------
        model.eval()                        # ★ 验证模式(BN 用running统计量, Dropout 关闭)
        valid_loss, correct, total = 0.0, 0, 0
        with torch.no_grad():               # ★ 不建计算图,省显存、更快
            for x_data, labels in valid_loader:
                x = x_data.to(device)
                y = labels.to(device)

                pre_y = model(x)
                valid_loss += criterion(pre_y, y).item()
                correct += (pre_y.argmax(dim=1) == y).sum().item()
                total += y.size(0)

        print(f"epoch {epoch + 1:2d} | "
              f"train_loss {train_loss / len(train_loader):.4f} | "
              f"valid_loss {valid_loss / len(valid_loader):.4f} | "
              f"valid_acc {correct / total:.2%}")

    # ==========================================================
    # ⑧ 保存权重
    # ==========================================================
    torch.save(model.state_dict(), "model.pth")     # ★ 存 state_dict,不要存整个 model
