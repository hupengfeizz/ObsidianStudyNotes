# BEV / 检测 手写题库 —— 每日一题

## 为什么是这些题

**这些题目就是你简历上的名词。** 每写完一道，简历上对应的那一条就从"听过"变成"手写过"。
既是编程手感训练，也是简历防守——面试官深挖到哪一条，你都能当场画/写出来。

**规则**：
- 空文件开始，不许看参考实现，写完再对答案
- 每题必须自带验证（和 `torchvision.ops` / `scipy` / 开源实现对拍）
- 一天一题，写不完不往下走。慢比跳过强

| A2 | **IoU 矩阵（向量化）** | `(N,4)`, `(M,4)` → `(N,M)` | 和 `torchvision.ops.box_iou` 对拍 | ★ 考 numpy 广播，笔试最爱 |

## B 组：3D / BEV 核心算子（这组写完，"BEV 细节不清楚"基本解决）

| # | 题目 | 输入 → 输出 | 验收方式 | 对应简历 |
|---|---|---|---|---|
| B1 | **3D IoU（轴对齐 AABB）** | 两个 `[x,y,z,dx,dy,dz]` | 蒙特卡洛采样估体积交并，对拍解析解 | 项目三"3D IoU 匹配" |
| B2 | **旋转框 BEV IoU** | `[x,y,dx,dy,yaw]` | 多边形裁剪（Sutherland-Hodgman）；和 `shapely` 对拍 | ★ 项目一/三真实用的就是这个 |
| B3 | **坐标变换全链路** | lidar 点 → ego → camera → 像素 | 用 nuScenes mini 的标定参数，投影点云到图上肉眼验证 | 项目一"多坐标系变换" |
| B4 | **畸变矫正 + 反投影** | 像素 + 深度 → 3D 点 | 正投影再反投影，验证回到原点 | 项目一"针孔/鱼眼、畸变矫正" |
| B5 | **点云 voxelization** | `(N,4)` 点云 → voxel 索引 + 每格点 | 统计非空 voxel 数；和 `spconv` 的 `VoxelGenerator` 对拍 | 项目一 PointPillars |
| B6 | **Pillar 编码** | voxel → `(P, N, 9)` 特征 | 检查 9 维每一维的含义能说出来 | 项目一 |
| B7 | **LSS frustum 生成** | 内外参 + depth bins → `(D,H,W,3)` 视锥点 | 可视化视锥；改 depth bins 看范围变化 | ★ 项目一 LSS |
| B8 | **depth 分布 × 特征（outer product）** | `(B,N,D,H,W)` + `(B,N,C,H,W)` → `(B,N,D,H,W,C)` | 手算一个小 case；理解显存为什么爆 | ★ 项目一 LSS 核心 |
| B9 | **BEV pooling（cumsum trick）** | 视锥点 + 特征 → BEV 网格特征 | 和朴素 scatter_add 版对拍结果一致、测速度差异 | ★ **BEVPoolv2 就是这个**，简历明写了 |
| B10 | **CenterPoint heatmap 生成** | GT 框 → 高斯热图 | 画出来看；理解 gaussian_radius 怎么定 | 项目一 CenterPoint Head |
| B11 | **多帧点云运动补偿** | 多帧点云 + 位姿 → 对齐后聚合 | 叠帧后看静止物体是否重影 | 项目一"深度监督加密" |
| B12 | **匈牙利匹配** | 代价矩阵 → 匹配对 | 和 `scipy.optimize.linear_sum_assignment` 对拍 | 项目三跨帧关联 |
