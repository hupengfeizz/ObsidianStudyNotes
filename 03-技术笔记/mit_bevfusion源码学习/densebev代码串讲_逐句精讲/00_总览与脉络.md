```
【视频未讲】Dataset/DataLoader ──产出──► 点云已voxel化(N×16×10) / lidar已拍平BEV / GT已放heatmap / grid map已生成
【视频未讲】图像backbone(针孔×7 + 鱼眼×4, ×3帧)
      │
      ▼ 00:00
┌─ Ch1  FPN收尾 ──► 取下采样8倍图像特征(128ch, 88×160)
├─ Ch1  DepthNet(仅2个卷积) ──► 深度分布 21×100×88×160（21=3帧×7路，100=深度bin）
├─ Ch2  Depth Loss：GT÷焦距²归一化 → 0~60m 切 100 bin → Focal Loss
├─ Ch3  Lidar backbone：DataLoader已拍平 64×352×224，无参数透传
├─ Ch3/4 Radar backbone：pillar 编码（pad帧索引→mask→Linear+Norm+ReLU→max→scatter）
│         → B×3×64×448×224（后向扩至 83.8m），再切出前向352 与 后向远距96 两块
├─ Ch5  RL融合：radar补齐lidar后向盲区 → 逐元素加 → UNet → 48×224 融合特征
├─ Ch6/7 LSS投影：图像特征×深度分布 外积 → 沿高度拍平 → grid_sample 到自车BEV
│         （逐路相机拆算省显存；在 224×112 半分辨率投影省时延）
├─ Ch8  三重融合Ⅰ/Ⅱ：针孔+鱼眼(pad对齐→通道合并) → 反卷积上采样448×224 → +radar逐元素加 → +RL concat
├─ Ch9  三重融合Ⅲ(时序)：MemoryManager(10Hz缓存历史帧) → rot/trans 算 warp grid →
│         历史两帧 warp 到当前 → 三帧 concat(192→64)
├─ Ch10 BEV UNet backbone（留 112×56 / 224×112 两尺度给端到端）
├─ Ch10 CenterPoint 检测头：10 个分支
│         reg/height/dim/rot/vel/dir_cls/movement/rot_lidar/close_heatmap/heatmap
├─ Ch11 Loss：heatmap Focal(car×3、VRU加权) + BEV上的dense属性Loss(角度分权/速度分权)
│         + 目标级回归(indices→gather_feat→256×10→L1) + 近距离加强 + 单帧RL增强yaw
└─ Ch12 Box解码：sigmoid → 双重topk(每类256→总256) → 偏移还原xy → exp还原lwh
          → atan2还原yaw → ×0.4m+区间偏移转自车系 → 越界过滤 → 15维输出
```

关键常量表（全篇反复出现，先背下）：

| 量 | 值 | 含义 |
|---|---|---|
| 相机 | 7 针孔 + 4 鱼眼 | ×3 帧时序 → 21 / 12 |
| BEV 范围 | 前 95.4 / 后 83.8 / 左右 ±44.8 m | lidar 原生只有后 45.4，后向远距靠 radar 补 |
| BEV 网格 | 448×224 @0.4m | 投影/时序在 224×112 @0.8m 做（省显存时延） |
| 深度 | 0~60m 切 100 bin | GT 除焦距²归一化；bin0 = 无效/超界 |
| 时序 | 3 帧 | 10Hz 推理用 MemoryManager 缓存，训练直通 |
| 目标 | 每帧统一 256 个槽位 | 5 类（car/truck/bus/VRU 等），box 15 维输出 |

## 🔍 完整性判定（你问的第 4 点：视频漏了什么）

视频从 FPN 尾部直接切入，以下环节**被引用但未讲解**（讲者至少 5 次说"DataLoader 里已经处理好了"）：

| 缺失环节 | 证据（视频中的引用点） | 建议补法 |
|---|---|---|
| ① Dataset/DataLoader 全部 | radar 的 voxel 化（"每个 voxel 最大 16 点是 DataLoader 统一设的"）、lidar 拍平成 BEV、Depth GT 与 mask 的生成与分组、**grid map 的生成**（LSS 的灵魂输入！）、GT 放到 heatmap（"之前优化过，不在网络里做"） | **优先级最高**。正好用你已定的"从零到一六步法"套路自查这套 DataLoader；grid map 生成是最值得向导师追问的一块 |
| ② 图像 backbone | 开场即"针孔的 backbone 和鱼眼的 backbone 输入过来的特征" | 大概率是常规 ResNet/RegNet 类，可后续看代码确认 |
| ③ 训练循环/优化器/学习率策略 | 全程未提 | 你在 BEVFusion 实战里已有完整经验，迁移即可 |
| ④ NMS/后处理去重 | 解码只到"topk 256 + 越界过滤"就返回了 | CenterPoint 系通常靠 heatmap 局部极大值(maxpool)替代 NMS——视频没讲这步在哪做，值得追问 |
| ⑤ 端到端(e2e)下游 | 多处"这个尺度是传给端到端要用的" | 属于另一个团队/模块的接口，知道形状契约即可 |
| ⑥ 部署/量化 | 结尾提到"Smart 上的优化可以慢慢回迁" | 远期话题 |

**一句话回答：网络前向 + Loss + 解码是完整的；数据侧（①）整体缺失——而数据侧恰是导师说过"大概率落到你头上"的活，建议作为下一次请教导师的主题清单。**
