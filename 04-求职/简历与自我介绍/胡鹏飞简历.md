**项目一：多传感器融合BEV 3D目标检测量产模型迭代　华为车BU ｜ 2024.06 – 至今**

**技术栈：**PyTorch、BEVFusion、LSS / BEVPoolv2、BEVDepth深度监督、Transformer Cross-Attention、CenterPoint Head、多帧点云运动补偿、Camera / LiDAR / Radar BEV特征级融合

**项目背景：**面向量产的 自动驾驶BEV 3D 感知模型：融合 7 路针孔相机、4 路鱼眼相机及激光 / 毫米波雷达多模态输入，单模型统一输出车辆、行人、骑行人等目标的 3D 检测框、速度估计与动静属性，为下游规控决策提供感知支撑。

**主要职责：**

- 模型训练与优化：负责量产BEV 3D检测模型的训练调优与精度迭代；针对路测高频问题进行推理复现与根因定位，制定并落地专项优化方案。

- 数据闭环建设：负责难例挖掘与数据回流，构造专项训练与评测集，持续提升模型长尾场景泛化能力。

- 评测与交付：基于自建评测防护网体系完成版本自验，承担候选版本的送测准入与回归测试，保障交付质量。

**项目难点：**

> 1、长尾误检：护栏、地库、闸机等高相似纹理难负样本稀缺，行车 / 泊车场景凭空误检易触发误刹。
>
> 2、远距检测精度受限：中远距目标像素占比小、深度线索弱，叠加单帧激光点云稀疏导致远距监督不足，表现为位置漂移大、有效检出距离受限。
>
> 3、类别与距离分布失衡：车辆样本占绝对多数，行人 / 骑行人及中远距样本严重不足，弱势类别与远距目标召回率偏低。
>
> 4、低速速度估计失效：低速跟车时目标帧间位移不足一个BEV网格，速度解算失效，易将运动目标误判为静止。
>
> 5、图像端梯度回传弱：检测损失仅作用于 BEV 空间，回传至图像 Backbone 的梯度衰减严重，图像特征判别力不足，制约整体检测精度。

**优化方案：**

- 误检难例挖掘：以"连续帧突现又突消"时序判据自动挖掘凭空误检难例，回流地库、闸机、静态障碍物等难负样本构造专项训练集回灌，泊车误检率下降约3.7%。

- 视图变换与深度估计升级：针孔支路以BEVPoolv2索引池化替代原Splat实现，省出算力加深DepthNet、接CRF平滑，中远距检出稳定性提升。

- 深度监督加密：多帧点云经运动补偿聚合生成稠密深度真值，强化远距深度监督信号，中远距深度误差下降约15%。

- 类别平衡治理：采用CBGS类别重采样与类别loss加权策略，补齐行人 / 骑行人及中远距目标训练信号，弱势类召回显著提升。

- 速度loss优化：L1 替换为 Smooth L1 改善零点附近收敛性，并与动静属性联合约束，速度动静专题通过率提升约 3.5%。

- PV辅助监督：BEV 3D真值反投至各相机生成2D监督，Image Backbone后接轻量检测头作辅助loss，仅训练期生效、零推理开销。

**项目成果：**

- 对比商发基线：平均检出距离提升至131.5m，动静属性通过率提升3.5%、凭空误检通过率提升5.1%，版本准入回归无恶化项引入，通过系统级测试随量产版本交付。

**项目二：成排锥桶检测与改道意图识别（PV多任务共网子任务） 华为车BU ｜ 2024.06 – 2025.06**

**技术栈：**PyTorch、YOLOv5检测框架、多任务硬参数共享（共享自研轻量Backbone + BiFPN、独立neck与检测头）、GIoU / BCE Loss、属性解耦建模、数据增强（random crop + padding + HSV）、难负样本与空图抑制

**项目背景：**量产前视 PV 多任务共网施工改道感知子任务，检测成排锥桶 / 警示柱 / 防撞桶，输出 2D 框与改道方向，

供下游规控提前发起变道决策。

**主要职责：**负责该子任务的模型迭代与量产维护：主导改道属性头三轮方案迭代，制定标注规范，优化数据增强策略，治理误检问题，承担端到端评测与版本交付。

**项目难点：**

> 1、远距小目标与密集粘连： 远处锥桶像素少、互相遮挡粘连，单锥桶检出不稳，规控的变道触发距离受限。
>
> 2、目标边界不固定： 粘连锥桶随自车接近逐帧分裂，框起止点持续漂移，难以稳定追踪。
>
> 3、改道属性输出不稳： 改道方向用点回归或角度回归都会逐帧跳变，属性逐帧抖动影响下游决策。
>
> 4、误检高频触发：远处反光牌 / 路牌外观相似易误检；上下坡与弯道路面截断处网络过度泛化，易凭空误检。

**优化方案：**

- 整体目标建模：改单锥桶检测为成排整体目标建模，以 "车道内≥3 锥桶" 判定改道类，2D 框与车道线强耦合（不可见侧沿延长线外推），附带改道方向属性，显著提升远距与密集粘连场景的检出稳定性。

- 改道属性头三轮迭代：首尾锥桶坐标点回归（Smooth L1）→ 排列方向角度 sin-cos 回归 → 左右通行性双二分类，逐步消除点漂移与方向跳变。

- 共网任务插拔式接入：复用共享 Backbone 与 BiFPN，仅新增独立 neck 与检测头，插拔式接入共网框架，零额外 Backbone 算力开销。

- 数据增强策略优化：针对长焦视角下目标空间分布高度集中的特性，以 random crop + padding + HSV 定制增强替代通用 Mosaic，保留空间位置先验的同时弥合训推预处理差异，有效提升部署后置信度一致性。

- 误检治理：针对反光牌 / 路牌相似误检与 "路面截断" 过度泛化两类问题，分别采用难负样本回灌与空图负样本抑制策略，有效降低误检率。

**项目成果：**

- IoU 0.4下precision / recall均达 0.7，稳定检出距离由89m提升至114m，支撑规控提前发起变道。

- 改道方向属性准确率提升7.3%，施工专题集凭空误检次数较基线下降约5.4%；全量回归无恶化项，随OTA版本量产上车。

**主要职责：**

- 评测体系：负责场景checker框架与防护网白名单用例集的设计开发，承担候选版本准入回归。

- 数据闭环：负责难例数据挖掘、标注质检与回灌迭代。

**技术难点：**

> 1、判定规则异构：误检 / 漏检 / 3D不稳 / 动静 / 检出时延 / 检出距离 / AEB误漏触发等问题判定标准各不相同，且同一checker在不同用例下阈值不同，难以统一实现与维护。
>
> 2、匹配易错配：车辆类依赖3D IoU、行人小目标IoU失效，TRUCK / TRAM、CYCLIST / TRICYCLE等跨类混淆造成错配；预测与真值时间戳异步、偶发缺帧，对齐不当直接产生误判。
>
> 3、时序问题难表达：检出不稳、鬼探头时延、动静跳变需跨帧关联目标做生命周期统计，单帧指标无法覆盖。
>
> 4、长尾数据与错标：闸机、地库、尾气等问题场景在数据湖中无现成标签捞不出来；训练集存在错标漏标，人工清查不现实。

**优化方案：**

- checker框架：统一基类抽象"匹配 → 判定 → 统计"流程，各问题以独立接口实现（check_fp / check_fn / check_unstable等），用例级配置IoU阈值、容忍失败帧数与中心 / 朝向 / 尺寸 / 速度误差阈值。

- 分类别匹配：时间戳最近邻对齐、缺帧单独统计；车辆类按3D框IoU匹配并设跨类等价集（TRUCK / TRAM等），行人改中心点距离匹配规避小目标IoU失效；按30 / 60 / 90m距离分段统计。

- 时序指标：跨帧目标关联统计连续命中 / 丢失、首帧检出距离、触发时延与动静跳变；自车系区域checker以框-区域交叠判定目标入侵，免标注。

- 数据闭环：组合条件过滤挖掘数据湖长尾难例，送标回灌；用模型推理反查标注，筛偏差最大帧复核，清理错标。

**项目成果：**

- 防护网覆盖10+大类、50+细分专题，自动输出case / 帧通过率与相对基线的优化 / 恶化diff报表，版本准入回归全自动，周期由约2天缩短至半天。

- 难例回灌与错标清理落地后，闸机 / 地库等误检专项通过率提升3+个百分点，误检、速度动静类高频问题逐版本收敛。

**项目四：船用换热器管板密封焊缝智能检测系统　启东惠生海工 ｜ 2023.05 – 2024.03**

**技术栈：**PyTorch、YOLOv8 / YOLOv8-Seg、OpenCV、P2检测头、Bi-FPN、CA Attention、IAT、Focal Loss / 定制BCE、DIoU + NWD、OHEM、Copy-Paste、TensorRT INT8

**项目背景：**船用换热器管板与换热管间的数千条环形密封焊缝须逐孔100%质检（焊缝泄漏将致海水串入滑油系统、主机烧瓦），原靠人工逐孔渗透检测，效率低、漏检率高。基于全局定位 + 机械臂逐孔采图，构建"ROI分割 → 切图 → 曝光增强 → YOLO检测"视觉流水线，实现自动缺陷检测。

**主要职责：**

- 视觉数据集处理：构建管孔焊缝缺陷数据集，定义标注规范，应对NG:背景约1:7的严重失衡。

- 2D算法开发：主导ROI提取分割网络与YOLO缺陷检测模型的选型、训练与迭代，攻克大图小目标、高相似背景、复合光照等难题。

- 端侧部署与性能调优：搭建落地前处理流水线并完成工控机部署优化，平衡速度、资源与精度。

**技术难点：**

> 1、大图小目标：5472×3648原图、孔径仅14mm，缺陷有效像素占比\<1%、最小约15×15px，下采样后小目标几乎无法检出。
>
> 2、高相似背景：碳化物、焊渣与气孔缺陷高度相似，单图真缺陷常仅1处而干扰多达5–8处，叠加NG:背景约1:7失衡。
>
> 3、复合光照：环形光源下孔口焊缝余高反光过曝、孔内壁偏暗，缺陷多在暗区，过曝区误检集中。

**优化方案：**

- 切图放大与小目标结构优化：围绕焊缝环带重叠裁图（重叠250px防截断），目标相对尺寸提升约4倍，固定视角关闭随机缩放；新增P2检测头、Bi-FPN上采样改双线性插值、P3 / P4加入CA注意力，回归损失改用DIoU + NWD组合，mAP50由基线89.7%提升至96%+。

- ROI精准提取：YOLOv8-Seg分割焊缝环带 + 环外填灰、非焊缝间隙图空标注负样本，Precision +2%。

- 难负样本与损失攻关：碳化物 / 焊渣等干扰类难负样本挖掘 + 分阶段训练 + 类内NMS（Precision +10%）；Focal Loss在高置信预训练模型上梯度消失而失效，改用定制BCE抑制硬FP，monkey-patch隔离改动。

- 光照补偿：IAT曝光补偿前处理自适应均衡局部亮度，P、R双升。

**项目成果：**

- 模型：缺陷检出召回96.8%、精确率95.5%，裂纹类致命缺陷零漏检，优于验收标准（检出率≥95%）。

- 部署：参与模型 TensorRT INT8 量化与工控机部署，配合多线程 Pipeline 优化检测流程；系统完成现场验收，单件全检耗时由人工约1天缩短至约2.5小时。
