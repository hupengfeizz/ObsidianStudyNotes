# 项目一 早期版 数据评测与训练支撑

以下是针对简历中四个项目经历分别设计的面试提问。问题涵盖了技术细节、方案选型、难点排查以及工程落地，旨在全面考察项目深度与真实性。

### 项目一：多模态 BEV 3D 目标检测——数据、评测与训练支撑

这个项目涉及大量的数据流转与训练工程，面试官通常会重点考察排障能力、工具链建设以及对多模态数据的理解。  

- 针对鱼眼近距 VRU 误检问题，您提到从全集中筛选了 5000+ 条样本构造专项训练集，请问正负样本的具体构建比例是如何决定的？在可视化归因分析中发现了哪些核心特征？  
- 在鱼眼开车门状态预测任务中，您是如何逐批查验数据标签准确性的？对于停车场这类密集场景，评测集的边界 case 是如何定义的？  
- 多模态多任务训练链路很长，您开发的评测与排障脚本具体是如何解耦数据版本、标定和 DataLoader 问题的？  
- 将 SparseBEV 的 label 生成移入 DataLoader 使单 step 训练耗时由约 3.8s 降至约 3.3s，请问您重构的部分 Loss 代码具体包含哪些优化逻辑？  
- 您在对比验证 DenseBEV 训练提速时，DenseBEV 与 SparseBEV 在特征聚合和计算瓶颈上最大的差异是什么？  
- 对于 CIPV（关键目标）漏检筛选脚本，其核心的自动化判定逻辑和筛选阈值是如何设置的？  
- 在开发全量数据有效性 check 工具时，您主要校验哪些维度的异常数据？  
- 多版本精度对齐脚本是如何保证不同版本模型（如 BEV/GOD 共网分支）评估结果严格一致的？  
- 在 PV2BEV View Transform 模块中，针对 Camera、LiDAR 和 Radar 的多模态融合，系统是如何处理不同传感器时间戳不对齐或部分传感器临时失效问题的？  
- 在难例 case 推理与归因分类（数据 / 标注 / 模型 / 后处理）中，遇到分类歧义时（例如既像模型问题又像标注问题），您是如何推动问题闭环的？  

### 项目二：BEV 目标级二阶段精修（Cutin / 动静 / 大车）

该项目聚焦于检测后处理与属性精修，面试官会重点考察轻量化网络设计、时序信息处理以及复杂目标的 GT 适配。  

- BEV 主网输出在 Cutin 场景为什么会产生中心和朝向抖动？轻微抖动被速度估计放大后，您是如何在修框小网中进行修正的？  
- 针对毫秒级时延预算的轻量小网，您在进行高斯化激光筛子和 ScatterMax 的对比实验时，两者的计算复杂度和修框效果差异如何？  
- 在生成 Cutin 可修条件的 GT 时，您利用边/角点云分布设置监督状态的具体数学逻辑或阈值是什么？  
- 多帧动静小网中使用了 Ego-Wrap 时序输入方案，在对比单帧/多帧双支路时，为什么需要将车辆与 VRU 支路拆分？两者的点云时序特征有何本质不同？  
- 引入多帧信息的同时要保证单帧检出不受影响，您在网络结构或 Loss 设计上做了哪些解耦？  
- 对于两节大车（车头 + 挂车）易出现的拆框和重复框问题，DataLoader 中 TRUCK/HEAD 关联合并的 GT 生成适配具体是如何实现的？  
- 在 TRUCK/HEAD 修置信度 POC 实验中，您采用了什么策略来提升大车位置检出的稳定性并改善漏检？  
- 动静小网将 VRU 可修范围提升至约 20m，限制其进一步提升至更远距离的物理瓶颈或数据瓶颈是什么？  
- 在合入大网二阶段的实验中，验证激光特征 drop 比例对修框能力的具体影响是什么？  
- Smooth L1 和 Heatmap 监督在您的二阶段精修网络中，分别对应解决哪一类误差修正？  

### 项目三：交通灯牌检测与状态识别模型

此项目为典型的 2D 目标检测与多任务时序分析，面试官的考察重点在于长尾数据治理、多任务学习的梯度互扰以及时序模型的稳定性。  

- 交通灯作为远距小目标，在 narrow 和 wide 相机下尺度差异大，您的 CSP Backbone 配合多尺度 FPN/PANet 是如何保证对极端尺度变化的鲁棒性的？  
- 多任务 head 之间存在梯度互扰，您在训练过程中是如何平衡 2D 框、灯色、形状等多属性 loss 权重的？  
- 基于 YOLOv8 结构的 One2Many 分支提升了远距小灯召回，而 One2One 分支实现了端到端匹配去 NMS，请详细描述这两个分支是如何协同工作以降低多灯场景后处理误伤的？  
- 为什么内灯 ROI 状态识别小网选择了 anchor-free 架构？在处理红闪 flicker 场景的兜底时，具体生效机制是什么？  
- 跨帧 ROI 通过 GRU 建模短期亮灭变化时，如何处理本车运动导致的交通灯 ROI 在不同帧之间的偏移问题？  
- 在红闪/黄闪与倒计时时序一致性的实验验证中，GRU 的隐层状态在遇到轨迹中断或遮挡时是如何重置或补偿的？  
- 针对长尾分布的数据，您按灯型/方向/城市/相机/距离进行分桶抽样，具体的分桶比例是如何动态调整的？  
- 配合仿真数据补充夜间和遮挡场景时，您是如何缓解仿真数据与真实数据之间的 Domain Gap 的？  
- 在 70w+ 帧数据的训练中，长尾数据分桶治理策略使远距小灯召回提升了多少个百分点？  
- 外灯框与内灯状态的可视化评测搭建过程中，您是如何定义单帧误判率及连续帧一致性指标的？  

### 项目四：工业结构件焊缝缺陷视觉质检系统

工业视觉项目注重极端数据分布下的工程解法以及硬件部署优化，面试官会考察缺陷定义的模糊性、损失函数调优以及 TensorRT 的量化细节。  

- 针对 5K×3K 原图和有效像素占比 <1% 的问题，您采用的四象限切图（1024×1024、约 250px 重叠），在推理后映射回原图进行二次 NMS 时，如何处理被切片边缘截断的缺陷框？  
- 用 YOLOv8-Seg 提取焊缝 ROI 后，为什么选择非焊缝区填灰并加入空标注负样本，而不是直接裁剪出焊缝区域进行训练？这种策略如何抑制周边误检？  
- 您提到 Focal Loss 在高置信预训练模型下出现梯度失效，其数学本质是什么？自定义的 BCE 损失是如何通过 monkey-patch 零侵入方式抑制硬假阳性的？  
- 难负样本挖掘(OHEM)与类内 NMS 策略带来了约 10% 的精度提升，请问 OHEM 的 loss 阈值或 top-k 比例是如何选定的？  
- 针对小目标，新增 P2 检测头和将 Bi-FPN 上采样替换为双线性插值，这两个改进在保留微小目标特征时的具体作用机制是什么？增加的计算开销占总推理耗时的多少？  
- IAT 暗光增强模块 是作为独立的预处理步骤，还是作为网络的一部分进行端到端联合训练的？  
- 在 teacher-student 半自动标注流水线中，如何准确判定并严格隔离教师模型的"零预测"样本，以防止伪标污染让模型学会忽略缺陷？  
- 使用 Copy-Paste / MixUp 合成长尾缺陷时，如何处理工业图像中复杂的光照过渡，以避免生成违背物理常识的伪影？  
- 超长裂纹拆连续小框的逻辑是什么？在推理阶段，是否需要将这些小框重新合并为完整裂纹进行良率判定？  
- 通过 TensorRT INT8 / FP16 量化并部署至工控机后，单图推理约 200ms，在量化过程中，哪一类极小缺陷的精度损失最大，您是如何进行量化补偿的？
