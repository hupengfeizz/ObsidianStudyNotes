# 项目四面试逐字稿：理论、原理、逻辑保姆版

配套简历版本：《胡鹏飞简历.pdf》项目四
项目：船用换热器管板密封焊缝智能检测系统（启东惠生海工 · 实习）
核心定位：帮助你讲清楚"一个从零到现场验收的工业检测系统怎么搭、大图小目标怎么治、高相似背景怎么压、Focal Loss 为什么会失效"，以及全部追问推导的技术口径文档。

## 0. 使用方式：这份稿子到底怎么用

### 0.1 这个项目的独特价值

这是你唯一一个**从数据采集一直做到现场验收**的项目——四个项目里完整性最高的一个。

面试官从这个项目里想验证的是：

1. 你有没有独立把一个视觉系统从零落地的能力（中小厂最关心的）。
2. 大图小目标这个经典问题你的解法体系。
3. 你踩过的真坑——Focal Loss 失效是全场最有说服力的经历。
4. 你对工业检测和互联网/车载检测差异的理解（漏检 vs 误检的取舍）。
5. 工程感：节拍、部署、现场光照这些论文不写的东西。

所以这份文档的记忆重点是：

- **"层层缩小搜索空间"这条流水线主线**，而不是单点技巧的罗列。
- **Focal Loss 失效的完整因果链**——这是你最值钱的一段经历。
- **漏检和误检在工业质检里的不对等**，以及它如何决定所有阈值取向。
- 边界口径：算法是你主导，硬件（机械臂/光源/相机）是设备工程同事的。

### 0.2 面试中的万能回答结构

> 业务后果是什么 → 问题在流水线哪一段 → 为什么这么解而不是别的 → 代价是什么 → 数字验证

逐字稿：

"这个项目我回答问题习惯从业务后果说起。焊缝质检的所有设计都被一条约束支配——漏检是事故，误检只是多花人工复核。漏一条焊缝，海水串进滑油系统，主机烧瓦，这是船级社定义的关键工序。所以我们的召回红线是致命缺陷零漏检，所有阈值都往高召回偏，误检靠后段人工兜底。先讲清这个取向，再讲每一步怎么做的。"

### 0.3 本项目的一句话主线

逐字稿：

"这个系统的设计主线是层层缩小搜索空间：五千万像素的原图直接检 15 像素的缺陷等于大海捞针，所以先用分割网络把焊缝环带抠出来、环外填灰，再围绕环带重叠切图把目标相对尺寸放大四倍，再做光照补偿把明暗拉平，最后才让 YOLO 在一个干净、放大、均衡的小图上做检测。每一步都在替检测器排除干扰，这比直接堆一个更大的模型有效得多。"

提示词：

ROI 分割 → 切图放大 → 曝光增强 → YOLO 检测 ｜ 每步都在缩小搜索空间

## 1. 项目总览逐字稿

### 1.1 30 秒版：自我介绍里带过

逐字稿：

"实习期间在船厂做了一个焊缝缺陷检测的落地项目。船用换热器的管板上有几千个管孔焊缝，原来靠人工渗透检测逐孔看，一件要一天。我做的是用视觉自动化这件事：从数据集构建、标注规范，到 YOLO 模型的结构改造和训练调优，再到 TensorRT 量化和工控机部署，最后通过了现场验收，单件检测从一天缩到两个半小时。"

提示词：

几千孔逐孔检 → 数据到部署全链路 → 现场验收 → 1 天变 2.5 小时

### 1.2 2 分钟版：面试官说"介绍一下这个项目"

逐字稿：

"先说背景。船用换热器是几千根换热管插在一块厚管板上，每根管子和管板之间有一圈环形密封焊缝。这些焊缝必须百分之百逐孔质检，因为一旦泄漏，海水会串进滑油系统，主机烧瓦——这是船级社定义的关键工序，验收标准是检出率不低于 95%，裂纹类致命缺陷零漏检。原来是人工渗透检测，一个人拿着放大镜逐孔看，一件产品一整天，人眼疲劳后漏检率还高。

系统方案是全局定位加机械臂逐孔采图：先在全局视图里定位管孔阵列，机械臂按路径走到每个孔近距离拍照，然后走一条视觉流水线——ROI 分割、切图、曝光增强、YOLO 检测。

技术上三个难点。一是大图小目标：原图五千多万像素，缺陷有效像素占比不到百分之一，最小只有 15×15 像素，直接下采样特征就没了。解法是先用 YOLOv8-Seg 把焊缝环带分割出来、环外填灰，再围绕环带做重叠切图，重叠 250 像素防止缺陷被切断，目标相对尺寸放大约四倍；网络侧加 P2 检测头、BiFPN 上采样改双线性、P3 P4 加 CA 注意力，回归损失用 DIoU 加 NWD，mAP50 从基线 89.7% 提到 96% 以上。

二是高相似背景：碳化物、焊渣和真缺陷高度相似，单图真缺陷常常只有一处、干扰却有五到八处，再叠加 NG 比背景约 1 比 7 的失衡。解法是难负样本挖掘加分阶段训练加类内 NMS，精确率提了 10 个点；这里还踩过一个很有价值的坑——本来想用 Focal Loss 压硬负样本，结果它在高置信度预训练模型上梯度失效，训练直接崩，后来改用定制 BCE 针对硬假阳性加权，用 monkey-patch 隔离改动不碰框架源码。

三是复合光照：环形光源下孔口反光过曝、孔内壁偏暗，缺陷多在暗区、误检集中在过曝区。用 IAT 做自适应曝光补偿前处理，精确率召回率双升。

最后是部署：参与了 TensorRT INT8 量化和工控机部署，配合多线程 pipeline 把采图、前处理、推理、后处理并行起来。最终召回 96.8%、精确率 95.5%，裂纹类零漏检，系统通过现场验收，单件全检从一天缩短到两个半小时左右。"

提示词：

背景（烧瓦+船级社）→ 系统（全局定位+机械臂）→ 三难点（大图小目标/高相似/复合光照）→ Focal Loss 坑 → 部署 → 96.8/95.5 验收

### 1.3 5 分钟深讲版：适合项目主问

在 2 分钟版基础上加三块：

**流水线设计哲学**（讲完背景后）：

"整条流水线的设计思想是层层缩小搜索空间。第一层 ROI 分割：检测器最怕的是无关背景里的干扰物，用分割网络把焊缝环带抠出来、环外统一填灰，检测器的世界里就只剩下焊缝。第二层切图：环带在原图里是个大圆环，把它切成带重叠的子图，每张子图里缺陷的相对尺寸放大约四倍，回到了检测器能力的舒适区。第三层光照均衡。到第四层 YOLO 检测时，它面对的已经是一个干净、放大、均衡的问题。如果反过来，指望一个超大模型直接吃五千万像素原图，算力和效果都不现实。"

**Focal Loss 失效的完整版**（讲完难负样本后）：

"这个坑值得展开。Focal Loss 的机制是用 (1−p)^γ 降低易分样本的权重，把梯度集中到难分样本。它有个隐含前提：模型对样本的置信度分布是分散的。但我们是在一个已经收敛的高置信度预训练模型上追加它——绝大部分样本置信度都很高，(1−p)^γ 把它们的权重压到接近零，有效参与训练的样本数急剧萎缩，梯度方差爆炸，训练直接崩掉。

要说清楚的是：Focal Loss 本身没有问题，从头训完全没问题，RetinaNet、CenterNet 都在用。问题出在'在已收敛模型上事后追加、且没有重新调学习率'这个操作上。定位到这一点后，改用定制的 BCE，只针对硬假阳性单独加权，梯度尺度可控。改动用 monkey-patch 打在自己代码里，不动框架源码——一是框架升级不会冲掉，二是随时可以切回原实现做对照。"

**工业检测评价体系**（讲完成果后）：

"最后说一个认知：工业检测的评价体系和车载感知是反的。车载里凭空误检直接触发误刹，误检权重高；工业质检里漏检是事故、误检只是多一次人工复核，所以召回是红线、精确率是成本。我们的置信度阈值是往高召回偏的，裂纹这类致命缺陷还单独用更低的阈值做复核策略——宁可多复核十个，不能漏掉一个。同样是检测任务，部署场景决定评价取向，这个认知我带到了后来做自动驾驶的工作里。"

## 2. 先把系统链路讲透

### 2.1 硬件与采图系统（不是你做的，但必须能讲）

```
全局相机 ─→ 管孔阵列定位（结合 CAD / 机器人坐标映射）
    ↓
机械臂按扫描路径逐孔走位
    ↓
近距离（约 30cm）单孔成像，环形光源
    ↓
单孔高分辨率图像 → 视觉流水线
```

逐字稿：

"采图系统是全局加局部两级。全局相机先拍整块管板，检测管孔阵列的位置，结合 CAD 图纸和机器人坐标系做映射，生成逐孔的扫描路径；然后机械臂带着检测相机按路径走位，到每个孔近距离拍一张高分辨率图。这套硬件——机械臂、光源、相机选型和标定——是设备工程同事做的，我是流水线的算法侧，但两边的接口我很清楚：他们保证'每个孔都有一张对得准的图'，我保证'每张图给出可靠的缺陷判定'。"

高频追问：为什么不用一台相机拍全景直接检？

答：

"分辨率不够。管板几米见方，缺陷只有毫米级，一张图拍全景的话缺陷连一个像素都占不到。必须近距离逐孔拍，才能让缺陷有十几个像素——这也是为什么系统必须有机械臂走位这一环。"

### 2.2 视觉流水线四段

```
① ROI 分割   YOLOv8-Seg 分割焊缝环带 → 环外填灰 → 非焊缝间隙图做空标注负样本
② 切图       围绕环带重叠裁剪（重叠 250px）→ 目标相对尺寸 ×4 → 固定视角关闭随机缩放
③ 曝光增强   IAT 自适应补偿：过曝压下来、暗区提上去
④ YOLO 检测  P2 头 + BiFPN(双线性) + CA 注意力 + DIoU+NWD → 检出结果映射回原图 → 二次 NMS
```

### 2.3 检出结果怎么回到业务

逐字稿：

"检测输出不是终点。子图上的检出框要先做坐标还原——每张子图在单孔图里的偏移是已知的，框加偏移还原回去，重叠区域的重复检出做二次 NMS 合并。单孔的结果再关联到管板坐标，这样每个缺陷都能定位到'哪块板的哪个孔'，支持图像追溯和复查。质检场景里可追溯性是硬要求——验收方要能查到任何一个判定对应的原图。"

## 3. 三大难点：每条都是一个方法体系

### 3.1 难点一：大图小目标

#### 3.1.1 问题定量

逐字稿：

"原图 5472×3648，五千多万像素；孔径只有 14 毫米，缺陷有效像素占比不到百分之一，最小的约 15×15 像素。检测网络输入一般是 640 见方，直接缩放等于把图缩小八九倍，15 像素的缺陷缩完剩一两个像素，特征完全消失。这不是模型不够强的问题，是信息在输入端就被扔掉了。"

#### 3.1.2 解法体系（四层）

**第一层 · ROI 分割**：

"用 YOLOv8-Seg 把焊缝环带分割出来，环带以外统一填灰。两个作用：排除孔壁焊渣、邻孔这些干扰源；把后续切图的范围从全图缩小到环带。另外把非焊缝的间隙图做成空标注负样本加进训练，明确告诉模型'这些区域不该有输出'。这层带来约 2% 的精确率提升。"

**第二层 · 重叠切图**：

"围绕环带裁子图，相邻子图重叠 250 像素。重叠量必须大于最大缺陷尺寸——不然一个骑在切缝上的缺陷会被切成两个残片，两边都检不出。切完目标的相对尺寸提升约四倍。代价是子图变多推理量增加、重叠区有重复检出要在还原后做二次 NMS 去重。"

**第三层 · 关闭随机缩放**：

"机械臂固定距离采图，缺陷的真实尺寸分布是稳定的，这是个强先验。随机缩放增强制造的是推理时不存在的尺度变化，模型把容量花在适应假变化上。关掉之后小目标检出反而更好——这和项目二弃用 mosaic 是同一个原则：增强不能破坏任务的真实分布。"

**第四层 · 网络结构**：

"P2 检测头：默认 P3 是 8 倍下采样，15 像素目标在 P3 上不到两个格子；P2 是 4 倍下采样，分辨率翻倍，小目标能占到更多格子。代价是 P2 特征图大四倍、算力涨，且浅层语义弱易误检——所以只在真需要检小目标时才加。BiFPN 上采样从最近邻改双线性，减少锯齿伪影对小目标边缘的破坏。P3 P4 加 CA 坐标注意力——它把全局池化拆成水平垂直两个方向，保留位置信息，适合我们这种目标位置有规律（分布在环形焊缝上）的任务。回归损失 DIoU 加 NWD：DIoU 管大目标收敛快，NWD 把框建模成高斯分布算 Wasserstein 距离，对小目标的轻微偏移不敏感——15 像素的框偏两三个像素 IoU 就掉一大截，但那点偏移业务上完全无所谓，NWD 就是来解这个的。"

#### 3.1.3 高频追问

**追问：mAP50 从 89.7 到 96+，哪一层贡献最大？**

"切图放大是基础盘——没有它后面全免谈，信息都丢了谈什么结构优化。结构优化里 P2 头贡献最直接，因为它正面解决了'特征图上没格子'的问题。DIoU+NWD 主要改善的是定位质量和训练稳定性。这几层是叠加关系，消融的时候是逐个加上去看的。"

**追问：为什么不用更大分辨率的输入，比如 1280？**

"算了账的。640 到 1280 计算量翻四倍，工控机的算力和节拍吃不下；而且 1280 也就把缩放比从九倍降到四五倍，15 像素目标还是会掉到临界尺寸以下。切图是同样算力下信息保留率最高的方案。"

### 3.2 难点二：高相似背景与样本失衡

#### 3.2.1 问题定量

逐字稿：

"焊缝表面本来就有碳化物、焊渣球、烧蚀点、鱼鳞纹这些正常的工艺残留，它们和气孔这类真缺陷在图像上高度相似——都是暗色小斑点。数量还悬殊：单图真缺陷常常只有一处，干扰物五到八处；整体上 NG 和背景大约 1 比 7 失衡。模型很容易把干扰当缺陷，误检压不下来；而按我们的取舍误检要靠人工复核兜底，误检率高了，'自动化'的价值就没了。"

#### 3.2.2 解法体系（数据 + 训练 + 损失 + 后处理）

"数据侧：把焊渣球、烧蚀点、反光伪孔这些 hard false positive 挖出来构建难负样本库；对稀缺缺陷做 Copy-Paste 合成扩充。

训练侧：分阶段训练——先在全量数据上训个基础模型，再用难负样本做专项微调；配合 OHEM 在线难例挖掘，让损失最大的那部分样本主导梯度。

损失侧：就是 Focal Loss 失效那个故事（见 4.1），最终用定制 BCE 压硬假阳性。

后处理侧：类内 NMS——同一处缺陷容易出多个重叠框，类内合并；不跨类抑制，因为不同类缺陷可能真的挨着。

这一套合起来精确率提升约 10 个点。"

#### 3.2.3 高频追问

**追问：为什么不把干扰物标成一个单独类别让模型学？**

"实际就是这么做的方向之一——把典型干扰物标成 Other 干扰类，让模型显式地学'这是焊渣不是气孔'，比单纯当负样本的信号更强。代价是增加标注量，而且干扰类内部形态差异很大，类内方差高。所以是两条腿：典型的、量大的干扰标成类；长尾的靠难负样本机制压。"

**追问：Copy-Paste 在缺陷检测里怎么做的？**

"把标注好的缺陷区域抠出来，贴到正常焊缝背景上，生成新的正样本。要注意贴的位置必须符合物理——缺陷只出现在焊道上，不能贴到孔壁；边缘要做融合处理，不然贴痕本身成了模型可以走捷径的假特征。"

### 3.3 难点三：复合光照

逐字稿：

"环形光源打在孔口的焊缝余高上会镜面反光、过曝，孔内壁又照不到、偏暗。同一张图动态范围拉得很开，而且两头都是坑：缺陷多在暗区——细节被压得看不清，漏检；误检集中在过曝区——高光斑点长得像缺陷。

解法是 IAT 自适应曝光补偿做前处理：一个轻量网络预测局部亮度变换，过曝压、暗区提。和固定算法（直方图均衡、CLAHE）比，它是学出来的，能适应不同的光照分布，不会在某些场景过度增强噪声。这步让精确率召回率双升——因为它同时治了暗区漏检和过曝误检两个对立的问题。"

高频追问：为什么不从光源侧解决？

答：

"光源侧优化过，但物理上有极限——焊缝余高是镜面反射，环形光怎么打都会有高光角度；孔是深腔，内壁总有照不透的区域。硬件把动态范围压到一个水平之后，剩下的交给算法补偿，这是硬件和算法的合理分工。"

## 4. 核心技术追问：从原理往下推

### 4.1 Focal Loss 失效的完整因果链（本项目最值钱的一段）

**分四步讲：动机 → 现象 → 归因 → 修复。**

逐字稿：

"动机：干扰物那类硬负样本压不下去，想到 Focal Loss——它天生就是给难样本加权的。

现象：加上之后训练不收敛，loss 剧烈震荡，几个 epoch 后指标全面崩掉。

归因：Focal Loss 的 (1−p)^γ 靠置信度区分难易。但我们不是从头训——是在一个已收敛、置信度普遍很高的预训练模型上追加。这时绝大多数样本 (1−p) 都接近零，权重被压没，有效参与训练的样本急剧萎缩，等效于 batch 突然缩小几十倍，梯度方差爆炸。再叠加没有相应调小学习率，训练直接崩。

修复：两条路——要么从头带着 Focal Loss 训（成本太高），要么换成梯度尺度可控的方案。选了后者：定制 BCE，只对硬假阳性单独加权，其他样本权重正常，梯度量级和原来训练是连续的。用 monkey-patch 在运行时替换框架的 loss 函数，不改源码——框架升级不冲突，也能随时切回原实现做对照实验。

这件事的通用教训：一个 loss 有没有效，不只取决于它的设计，还取决于它接入时模型所处的状态。同样的 Focal Loss，从头训是利器，事后追加是毒药。"

### 4.2 NWD 为什么对小目标友好

逐字稿：

"IoU 系损失对小目标有个先天问题：严格度随目标变小而急剧上升。15 像素的框偏 3 像素，IoU 可能从 0.7 掉到 0.4；同样 3 像素偏移在 150 像素的框上 IoU 几乎不动。但业务容忍度不随尺寸变——3 像素偏移对质检完全无所谓。NWD 把框建模成二维高斯，算两个高斯的 Wasserstein 距离再归一化，它是平滑的、对小尺寸不敏感，而且两框不相交时也有梯度。实践上 DIoU 和 NWD 加权组合：大目标靠 DIoU 精确定位，小目标靠 NWD 稳定收敛。"

### 4.3 类内 NMS 为什么不做跨类

逐字稿：

"同一处缺陷模型会出多个重叠框，要合并——这是 NMS 的常规用途。但跨类不能抑制：气孔和裂纹可能真的在空间上挨着甚至部分重叠，跨类 NMS 会把真实存在的另一类缺陷误杀。质检场景漏检是红线，所以 NMS 只在类内做。"

### 4.4 teacher-student 半自动标注（如果被问数据怎么来的）

逐字稿：

"缺陷样本稀缺，标注又需要质检专业知识，纯人工标注贵且慢。用了半自动流程：先人工精标一小批训一个 teacher 模型，让它在未标注数据上预标注，人工只做复核修正而不是从零画框，效率高几倍。关键控制点是防伪标污染——teacher 完全没检出的图不能直接当负样本，要人工确认，因为 teacher 的漏检会变成'假背景'教坏 student。复核通过的数据打版本冻结，保证可追溯。"

### 4.5 INT8 量化掉点怎么办（部署侧被问）

逐字稿：

"INT8 量化靠校准集把浮点激活映射到 8 位整数，选校准集要覆盖真实分布——各种光照、各种缺陷类型都要有。量化后小目标和低对比度缺陷最容易掉点，因为它们的激活值本来就弱，量化误差相对影响大。验证时不能只看 mAP，要单独看致命缺陷类的召回——整体掉一个点可以接受，裂纹召回掉了就不能上。真掉了的手段：换校准集、对敏感层保留 FP16 混合精度。"

### 4.6 多线程 Pipeline 怎么组织

逐字稿：

"单孔的处理链是采图、前处理（含 IAT 和切图）、推理、后处理（坐标还原和 NMS）四段。串行的话 GPU 在等 CPU、CPU 在等相机，都在空转。多线程流水线让第 N 个孔在推理时，第 N+1 个孔已经在前处理，第 N+2 个在采图——各段并行起来，吞吐由最慢的一段决定而不是各段之和。这是单件从一天压到两个半小时里，部署侧的主要贡献。"

## 7. 面试官可能从零基础问到专家：问答库

### 7.1 业务与系统

**Q1：为什么这个质检必须 100%？**
答：密封焊缝泄漏 → 海水串入滑油系统 → 滑油乳化 → 主机烧瓦。船级社定义的关键工序，验收标准检出率 ≥95%、裂纹类零漏检。

**Q2：人工检测的问题是什么？**
答：渗透检测逐孔看，单件一整天；人眼疲劳后漏检率上升；结果无影像记录，不可追溯。

**Q3：系统整体怎么运转？**
答：全局相机定位管孔阵列 + CAD/机器人坐标映射生成扫描路径 → 机械臂逐孔走位近距采图 → ROI 分割 → 切图 → 曝光增强 → YOLO 检测 → 坐标还原与二次 NMS → 结果关联管板坐标支持追溯。

**Q4：为什么漏检比误检严重？这如何影响设计？**
答：漏检是事故，误检只是人工复核成本。所以召回是红线：阈值往高召回偏、致命缺陷单独用低阈值复核策略、NMS 只做类内不跨类、量化验证单独看致命类召回。每个设计点都被这条取向支配。

### 7.2 大图小目标

**Q5：为什么不直接把大图送网络？**（3.1.1 定量）

**Q6：切图为什么重叠 250 像素？**
答：重叠必须大于最大缺陷尺寸，保证任何缺陷至少在一张子图里完整。250 是按缺陷尺寸上限加余量定的。代价是子图变多、重叠区要二次 NMS 去重。

**Q7：切图结果怎么拼回去？**
答：子图偏移已知，框加偏移还原；重叠区重复检出做二次 NMS；靠子图边缘的残缺框，优先保留来自目标更完整那张子图的结果。

**Q8：P2 头的原理和代价？**（3.1.2 第四层）

**Q9：NWD 是什么？为什么小目标需要？**（4.2）

**Q10：CA 注意力和 SE、CBAM 的区别？**
答：SE 只做通道注意力，空间信息全丢；CBAM 串行加了空间注意力但用全局池化，位置感知弱。CA 把池化拆成水平垂直两方向，保留位置编码，输出带方向感知的注意力——适合目标位置有规律的任务，我们的缺陷就分布在环形焊缝上。

**Q11：为什么关掉随机缩放？**
答：固定视角采图，真实尺度分布稳定，缩放增强制造假变化浪费容量。和项目二弃 mosaic 同一原则：增强不能破坏真实分布。

### 7.3 高相似背景与损失

**Q12：Focal Loss 为什么失效？**（4.1 完整因果链——必背）

**Q13：定制 BCE 具体定制了什么？**
答：在标准 BCE 上对硬假阳性（高置信度误检的负样本）单独加权，其余样本权重不变——梯度量级与原训练连续，不会像 Focal Loss 那样把有效样本压没。

**Q14：monkey-patch 是什么？为什么用？**
答：运行时动态替换库函数，不改源码。框架升级不冲突、不影响别人用同一份框架、随时切回原实现做对照。

**Q15：OHEM 和 Focal Loss 的区别？**
答：都是难例加权。OHEM 是硬选择——只取损失 top-k 的样本回传梯度；Focal 是软加权——连续函数降权易分样本。OHEM 不依赖置信度分布的假设，在我们这个已收敛模型的场景下反而稳定。

**Q16：分阶段训练怎么分？**
答：先全量数据训基础模型，再用难负样本专项集微调。一次性混训的话难负样本占比太小，信号被稀释。

### 7.4 部署

**Q17：INT8 量化流程和掉点处理？**（4.5）

**Q18：多线程 pipeline 怎么设计？**（4.6）

**Q19：工控机是什么配置？为什么不用服务器？**
答：产线现场部署，工控机是工业环境标准载体——抗粉尘振动、长时间稳定运行。算力有限所以才需要 INT8 和流水线优化。【具体型号回去核对。】

### 7.5 数据

**Q20：数据集怎么构建的？**
答：产线采图积累 + 标注规范定义（什么算缺陷、边界怎么画、干扰物怎么标）+ teacher-student 半自动标注扩量 + Copy-Paste 合成稀缺缺陷。NG:背景 1:7 的失衡靠采样和难负样本机制治。

**Q21：teacher-student 半自动标注的风险？**（4.4 防伪标污染）

### 7.6 专家刁难题

**Q22：召回 96.8%，剩下 3.2% 漏的是什么？怎么办？**
答：主要是极低对比度的微小缺陷和被反光完全掩盖的区域。系统层面兜底：致命缺陷类用更低阈值单独复核；边界暧昧的判定送人工复核队列——自动化的目标是把人工从几千孔压到几十个可疑孔，不是绝对零人工。

**Q23：换一种工件这套系统还能用吗？**
答：流水线框架（定位 → ROI → 切图 → 增强 → 检测 → 还原）可复用，具体模块要适配：ROI 分割要重训、切图策略按新工件几何重定、缺陷类别重新定义标注。方法论迁移成本远低于从零搭——这正是我后来快速上手其他检测任务的原因。

**Q24：这个项目最大的收获？**
答：两个。一是先定位瓶颈再动手——问题在输入端信息丢失，堆多大的模型都没用，切图放大四倍比换 backbone 有效得多。二是部署场景决定评价取向——工业检测召回是红线、车载感知误检是红线，同样的检测任务取舍完全相反，这个认知让我在两个领域之间切换得很顺。

## 10. 最后一页：只背逻辑，不背数字

### 10.1 项目主线

漏检是事故 → 召回是红线 → 大海捞针不可行 → 层层缩小搜索空间（ROI → 切图 → 增强 → 检测）→ 高相似干扰靠数据+损失+后处理合围 → 部署满足节拍 → 现场验收

### 10.2 五个技术动词

1. **缩小**：五千万像素 → 环带 → 子图，搜索空间层层压缩。
2. **放大**：切图让目标相对尺寸 ×4，信息保住才谈得上检测。
3. **合围**：难负样本 + 分阶段 + 定制 BCE + 类内 NMS，四面压误检。
4. **均衡**：IAT 把过曝和暗区拉回检测器的舒适区。
5. **兜底**：低阈值复核 + 人工队列 + 可追溯，系统设计消化残余风险。

### 10.3 三条最重要的理论句

1. 取向句：
"工业质检里漏检是事故、误检是成本，召回是红线——这条不对等支配了从阈值到 NMS 到量化验证的每一个设计。"

2. 搜索句：
"大图小目标的本质是信息在输入端就被下采样扔掉了，正确的解法是缩小搜索空间保住信息，而不是加大模型去捞已经丢了的东西。"

3. 状态句：
"一个 loss 有没有效，不只取决于它的设计，还取决于接入时模型所处的状态——Focal Loss 从头训是利器，在已收敛的高置信模型上追加是毒药。"

### 10.4 面试时的最终口径

逐字稿：

"我对这个项目的理解可以概括成一句话：它是一个被'漏检即事故'这条约束支配的系统工程。因为漏检不可接受，所以召回是红线、所有阈值往高召回偏、误检靠人工复核兜底；因为缺陷太小，所以不能指望大模型硬吃原图，而是用 ROI 和切图层层缩小搜索空间把信息保住；因为干扰太像，所以数据、训练、损失、后处理四面合围。它是我第一个从数据采集做到现场验收的完整项目，也是我理解'部署场景决定技术取舍'的起点。"
