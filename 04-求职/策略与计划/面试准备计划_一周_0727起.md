## 7/30（周四）· 项目四 + 小目标与损失家族

> **今天有全周最硬的一块：Focal Loss 梯度推导。留足时间。**

### 09:00–12:00 · Focal Loss 专题（3h）

这是你最好的技术故事，必须啃到能手推。

1. **手推梯度**：写出 `FL = -α(1-p_t)^γ log(p_t)`，对 logit 求导，看调制因子怎么作用。
2. **四个失效机制**（《项目描述》§11.3）要能分层讲：
   - 主因：**已收敛模型上 p_t 普遍 >0.9 → (1-p_t)² <0.01 → 整个 batch 梯度范数塌缩 → 等效学习率掉 1–2 个数量级**；硬 FP 相对权重虽高但数量极少，在塌缩的 batch 里被稀释
   - 超参需重新整定，直接套 α=0.25/γ=2 会劣化
   - **Ultralytics YOLOv5/v8 的 `fl_gamma` 默认就是 0.0**（框架作者也不推荐），因为 TaskAlignedAssigner 已在做难例聚焦，叠加是重复且冲突
   - 放大错标样本
3. **定制 BCE 的本质区别**：Focal 是减法（让模型少关注简单样本），定制 BCE 是加法（多关注这一类特定错误）。已训好的模型上，加法比减法安全。

### 13:00–15:00 · 动手实验 ⑦⑧（2h）

- **⑦ 梯度塌缩验证**：构造一批 p_t 分布模拟已收敛模型（多数 >0.9），画 BCE 与 FL(γ=2) 的**梯度范数对比曲线**。有了这张图，这个故事就无懈可击。
- **⑧ NWD vs IoU 曲线**：6×6 小框和 36×36 大框各自逐像素平移，画四条曲线。一张图说清"IoU 对小目标断崖、NWD 平滑"。

### 15:00–18:00 · 项目四其余原理（3h）

| 硬骨头 | 完成标准 |
|---|---|
| **NWD 数学** | 框→二维高斯（Σ=diag(w²/4,h²/4)）→ 二阶 Wasserstein → exp 归一化；为什么永不为零 |
| **切图数学** | 5472→640 缩放 8.55×，15px 变 1.75px；切 1280 只缩 2×，变 7.5px，提升 4.3×。**能现场推算** |
| **P2 检测头的代价** | stride 4，特征图是 P3 的 4 倍，是检测头里最贵的一层 |
| **CA 注意力** | 与 SE（丢空间）、CBAM（缺长程）的区别：H/W 两个方向一维池化，保位置又有长程 |
| **为什么关随机缩放** | 固定工作距离 → 尺度是常量 → 增强在教不存在的变化。**与项目二关 mosaic 同一逻辑** |
| **IAT 为什么 P/R 双升** | 信息层面（改善输入）vs 决策层面（调阈值），前者才可能双升 |
