# 0804-2003 · 长沙速度机制与薪资谈判场（45/100）

## 速览

一面埋的坑本场填了三个（速度差分、锥筒接口、车型守密），技术上是 24 小时修复能力的又一次证据。但薪资环节把一面"未谈先降"升级成了"**自动缴械**"：期望 35-40K → 对方一句"长沙给不了" → 你主动"薪资可以谈" → 秒报现薪 → 再替对方论证长沙该降价。四步里没有一步换到任何东西。

---

## 逐问逐答分析

### 一、双模型定位（0:04-4:15）

**Q1（0:40）有了 3D BEV 为什么还要专门做 2D 模型？** → BEV 检关键动目标（车/人/骑行人）；PV 共网负责红绿灯、闸机、交通牌等多个子任务；我的子任务是高速施工锥筒+改道意图。✅ 定位讲得干净。

**Q2（2:12）成排锥筒有什么特殊？为什么不一个个检？** → 远处粘连难辨方向 → ≥3 个整体建模。✅ 熟牌。

**Q3（3:24）成排是模型出的还是后处理？**

现场：模型直接输出；标注标三类（成排锥筒/单个锥筒/改道框）；图上输出成排框+改道框两个框；**给规控只给改道意图**。

诊断：✅✅ **一面时三次改口的接口问题，本场一次说清**——"标什么/出什么/给下游什么"三层分开。这就是口径卡的价值：同一个知识，组织好了是加分项。

### 二、速度机制专题（4:19-9:30）——修复验收现场

**Q4（4:19）速度怎么检测的？** → "**真值是通过前后帧位置差分计算出来的，模型由 CenterPoint 检测头直接输出速度**。"

诊断：✅✅ 0803-1926 场被抓"不是模型直接出吗"的自相矛盾，**本场主动把"真值构造"和"模型输出"分开说**——K20 速度真值项的修复现场，24 小时闭环的又一例。

**Q5（5:34）没有历史帧信息速度出不来吧？** → "有历史帧……单帧没法计算，通过历史帧差分得到真值再训练。"⚠️ 这句又把训练真值和推理输入缠了一下（严谨版："推理时模型靠时序 BEV 特征回归速度；训练真值来自标注框差分"），面试官没深究。

**Q6（6:16）怎么避免静止目标误检出小速度？** → 静检动问题 → L1 在低速（零点几 m/s）梯度是常数、精确力度不够难回归 → 换 Smooth L1；再加速度-动静联合约束（速度为 0 强绑静止）。✅ 机理版稳定输出。

**Q7（8:19）单独输出动静量吗？准确率多高？** → 通道输出静止/运动/unknown 三值；难例评测集上约 70-80%，"因为评测集全是等红绿灯前车挪动这类难场景"。✅ 数字+口径限定语齐全——这是"报数字"的正确姿势。

### 三、占据网络与部署（9:32-13:15）

**Q8（9:32）做占据网络吗？为什么不共 Backbone？** → GOD 与 BEV 共组但两个独立模型（Backbone 不同）；不共的原因：检出目标不同，共用容易互相拖累调优。✅ 边界+理由。Occupancy 检非交通性目标/可行驶域/锥筒水马。✅

**Q9（10:44）什么芯片？** → MDC610 单激光 200 多 TOPS；MDC630 三激光 300 多 TOPS。✅ 与前几场口径一致（这组数字已稳定）。

**Q10（11:38）PyTorch 模型能直接转华为芯片吗？算子缺失怎么办？** → PTH→ONNX→OM→量化→版本构建；确实存在无对应算子的情况，需要改模型或优化算子；"算子由量化部门开发，部署同学调用，精度问题拉量化同学一起修，具体算子不是我们搞。"

诊断：⚠️ 流程说清了（✅），但"不是我们搞"的收口又把话题让了出去。标准补法："我在开发板上遇到过 XX 算子不支持，用 YY 等价替换绕过的——量产里这类问题归算子团队，但排查思路我有。"

**Q11（13:20）训练集规模？** → "几百万帧……大概 **200 万帧左右吧**……我记得是这么一个数量。"对方："那也不是很高啊。"

诊断（B04）：几百万→200 万的现场缩水+"我记得"的不确定语气，招来了"不是很高啊"的评价。数据量是参数卡训练页的一员：**定一个数（含口径：关键帧/全帧、含不含仿真），任何场合只报它**。后半段"以 case 为单位上量、30s@10Hz=300 帧"依然稳。✅

**Q12（15:30）用到哪个车型？** → "具体我就不说了……适配车企很多，60 个车型大包。"✅ **守密意识本场上线**（对照前几场直接报名单）——又一个 24 小时修复。

### 四、行为与薪资（17:00-21:40）

**Q13（17:00）为什么想离开华为？** → 修复版稳定输出（两年+大版本交付契机+分工细想学上下游），如实提及加班单休但不抱怨。✅

**Q14（18:17）期望薪资？——"我们长沙给不了啊。"**

现场全程：你报 "35-40K"（比一面的 35 起点高，✅ 锚点意识有进步）→ 对方："长沙给不了啊。"→（沉默几秒）→ 对方："你这个薪资可以谈的吗？你现在薪资多少？"→ 你："**目前 29K，十四薪。**"→ 你接着说："**薪资可以谈，因为考虑到长沙……消费水平确实要低一些。**"

诊断（B15×2，本场核心失分）：
1. 🔴 **现薪秒报**。29K×14≈40.6 万一旦出口，对方的出价上限立刻锚定在"略高于 40 万"甚至"月薪高于 29 即可"。标准应对："总包在 40 万以上，具体结构到 offer 阶段再对——我更想先确认岗位和范围。"（不撒谎、不报细、不失礼。）
2. 🔴 **替对方砍价**。"可以谈+长沙消费低"两句等于自己把 35-40K 的锚拆了。城市差异是对方的论点，让他自己说；你的位置永远是"技术定价按能力口径，若贵司带宽确实有限，我们看总包和其他补偿（签字费/期权/职级）"。**每一次让步都要换东西**——这句话在 0803 一面复盘里写过，24 小时内没能像技术项一样修复，说明谈判类需要的不是知识而是脚本演练。

**Q15（19:47）反问：华为的规控/两段式还是一段式？** → 你讲了两段式与端到端并存、共网 backbone 给端到端（"不给框，给 Backbone 权重"）——对方"那就是一段式了"你答"对，完全的一段式"。⚠️ 与前一句"部门还是两段的"打了个小架；准确说法："量产主线仍是两段式，端到端产品线是一段式、感知以共享 backbone 的方式并入。"

## 高光

1. **速度真值差分句主动说对**——0803-1926 被抓矛盾 24 小时后的修复验收。
2. **锥筒接口一次说清**（标三类/出两框/给意图）——一面三次改口的题本场满分。
3. 动静三值+70-80% 难例口径——"数字+限定语"的标准报法。
4. 车型守密意识上线；MDC610/630 TOPS 口径连场一致。
5. 修复版离职原因稳定输出，第三场无"换心情"。
