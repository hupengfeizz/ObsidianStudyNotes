## 逐问逐答分析

### 一、开场与 BEV 全览（0:00-13:00）

**Q1-2 自我介绍+项目展开** → 成熟版 + 难点四连（误检挖掘/检出不稳三面/速度 SmoothL1+联合约束/CBGS）+ PV 辅助监督。**成果句数字齐且对**：检出距离提升至 131（米）、速度动静 +3.5 个点、误检改善 5%、时延内存无明显增长、随量产版本上车。✅✅ 这是成果句的标准形态，此后照抄。

### 二、融合与 BEVPoolv2 追问（13:07-21:00）

**Q3-4 融合具体怎么做/雷达分支再讲一遍** → 双支路完整版；雷达分支单独复述（voxel 体素化→3D backbone→高度压缩成 BEV）。✅

**Q5（18:03）BEVPoolv2 离线加速具体怎么做？** → 查找表机制版。✅
**Q6（19:26）"查找表是 BEV 格子去找相机特征，还是相机特征投过来？"** → "第一种，从 BEV 格子回头索引相机坐标系的特征值。"✅ 方向答对（gather 式）。
**Q7（19:58）"一个格子对应多个相机的特征怎么处理？"** → 答成"内外参统一到自车坐标系、特征对齐"。

诊断（K07/B06）：又一次**对齐≠聚合**。正确答案就一句："多相机投到同一格子的特征做**求和/均值池化**——这正是 BEVPool 名字里 pool 的含义。"对方问的就是池化，你答的是坐标系。（与 0804-1512 场"空间相关性答成对齐"同构——**凡问'多个 X 怎么变成一个'，答案是聚合算子，不是坐标系**。）

### 三、部署排查深water区（21:06-30:35）——本场最大失血段

**Q8（21:06）端侧部署做过吧？** → **双层句首次顺序正确**：YOLO 工作里部署过 + BEV 自己在 Jetson Orin 全链路跑过（PTH→ONNX→TensorRT→C++）+ 公司量产部署是组内同学负责。✅

**Q9（22:02）"PC 端性能好、端侧掉点，排查流程是什么？"**（连问四轮）

现场：第一轮"分训练/量化两块分别评测对比精度"；第二轮被要求细节后"分块分析、看日志、查漏带模块"；第三轮问怎么定位算子问题——"确实是部署同学搞的"；第四轮问实际碰过什么问题——绕回流程+提到"辅助小网"（速度跳变时的修框辅助网络，"另外同事开发的，我跟着定位"）。

诊断（K17+B01）：
1. 🔴 四轮追问，"**逐层比对**"一次都没出现——导出浮点/量化模型逐层激活，算余弦相似度/最大绝对误差，定位首个发散层，决定该层回退 FP16 或修校准集。这句话在 0803-1926 缺过一次，这里是第二次（0807-0500 第三次后进总库 K17）。
2. 面试官要的是**一个带数字的真实案例**（"某版速度头量化后掉 8 个点，逐层比对发现 XX 层溢出，改对称量化后恢复"），你给的是组织架构图。

**Q10（26:23）算子没实现过怎么处理？** → 算子团队紧急开发，或模型侧换等价结构绕过。✅ 这句是对的——但没衔接你自己 RK3588 的 SiLU 案例（它 60 分钟后才出场）。

### 四、组织与架构边界（30:41-48:50）

**Q11-13 分工/单网还是共网/端到端训练** → 诚实清晰：四五人分工、共网/单网分人；**单网是 Sparse BEV（query 架构）**、共网 LSS；我最近搞共网的 PV image backbone。✅（"单网=Sparse"是本场新信息，与"切到 Dense"叙事兼容——量产共网 Dense、单网保留 Sparse。）

**Q14-16 鱼眼作用/共享参数吗/多少 TOPS** → 折中方案稳定版；无共享参数；610=200TOPS、**630=400TOPS**（⚠️ 前几场说 300 多——B04 小漂移）。

**Q17（40:04）"除了 LSS 和 query，还有其他 2D→3D 视角转换方式吗？——还有吗？"** → "可能有点想不起来了。"

诊断（B03+K07）：视角转换清单其实不长：**IPM 逆透视映射**（平地假设，泊车/车道线场景常用——对一家泊车公司这恰是最相关的一个！）、**伪激光雷达**（深度图转点云再走点云路线）、显式深度（LSS/BEVDepth）、隐式 query（BEVFormer 系）。四个名词一句话一个，30 秒答完。"想不起来了"丢掉的正是对方业务最贴的那张牌。

**Q18-19 Sparse 复盘/显式 vs 隐式优劣** → Sparse→Dense 叙事+诚实（"当时怀疑代码 bug、不至于这么低级，部门最近在定位"）；显式：可解释性强/特征图可视化定位直观/稳定，隐式：精度上限高/可解释性差。✅✅ 权衡题答得像样。

**Q20（48:09）BEV 融合之后的后段做过什么探索？** → "目前还没做过额外调整，主要精力在融合之前——深度不准会拖垮后面一切。"✅ 边界+理由，诚实答法的正面示范。

### 五、数据闭环与评测（48:53-60:00）——本场得分主区

**Q21 难例/长尾怎么解决** → 泊车极近距误检+**匝道汇入凭空误检触发 AEB 急刹**案例（挖掘：高速 tag→自车左右 10-20 米→突现高置信）✅✅ AEB 后果一句让案例有了业务重量。
**Q22-24 挖掘是使用还是设计/数据湖标签哪来/预打标参与吗** → 根因分析→策略→连湖挖掘；场景标签采集时自动带+自写代码逐帧校验+基线模型预测框；预打标是数据组的，我负责需求下发/质检/挖掘策略。✅ 边界诚实、链条完整。
**Q25-26 评测体系/checker 具体实现/动静怎么判** → 防护网清单（误检漏检/检出距离/时延/鬼探头横穿/大车侵占/cut-in）；误检 checker：问题目标标真值框+IoU 阈值逐帧判；动静：速度差+动静 tag 直接比对不等即 fail。✅✅ 全场最流畅的 10 分钟。

### 六、锥筒复盘与共网训练（60:03-75:00）

**Q27 两年时间分配** → 评测入手→训练→模块开发的成长弧 ✅；锥筒"当时是去**协助**支持"（B07）。
**Q28 锥筒十个月做了哪些优化** → 整体建模+三轮迭代+Mosaic 替换全套。✅
**Q29（65:17）意图标注真值怎么标？** → 三类框（单锥筒辅助/成排锥筒/改道意图框）+意图框左右下角卡死车道线+五分类输出，与成排框无重叠。✅✅ 历史最详版本，锁定为标准答案。
**Q30 共享主干怎么训** → 子任务冻结 backbone 单独训→交 neck/部分 FPN/头给共网。✅
**Q31（68:28→72:15）"共享特征不一定适配你的任务，怎么提高单任务精度？具体优化点？"** → "检测头设计+neck 部分优化……增加 neck 卷积放大小目标性能……跟共网相差不大"——面试官点破："**好像更偏向说你怎么把网络设计出来，没有太多优化的部分**。"

诊断（B06）：这题的真实答案藏在你自己的工作里：**neck 上加卷积扩容是为了补偿冻结 backbone 无法微调的损失；FPN 层级选择对齐锥筒的尺度分布；空图负样本抑制弯道误检**——三点都做过，但没有组织成"针对共享特征错配的补偿设计"这个题眼。

### 七、泊车专区与网格分辨率危机（75:01-88:50）

**Q32（75:09）鱼眼和针孔的 BEV 网格差异？** → "网格统一，分辨率 **0.4 米**。"✅✅ **口径回正**（前一天还是 0.2）——证明正确数字在脑子里，输的只是稳定性。

**Q33（82:03→85:55）"机械车库只剩十几公分，0.4 米满足吗？——泊车分辨率多少？——0.2 也不够啊？"**

现场："特殊场景会提高标注帧率和网格分辨率"→"泊车大概 0.2 米"→ 被追"0.2 还是不够十几公分"→"**具体记不清了，可能更小，0.05 或 0.1 这样……这块我没怎么做，是另外开发同学做的。**"中间还即兴了一套"离线配置映射表+场景分类器切换网格"的机制，被"靠感知识别场景？"问得前后不圆。

诊断（B04+B03+B01）：数字从猜测走向撤退的完整样本。**诚实版**："行车主网格 0.4m；泊车对厘米级间隙的感知主要靠超声波和鱼眼近距分支，BEV 网格是否单独加密我没有亲手调过，不敢报数——但方向上一定是就近距 ROI 局部加密而不是全图加密，否则算力爆炸。"承认边界+给出机理判断，比编"0.05"体面得多。**对一家泊车公司，这题是主场题，值得赛前专门准备。**

**Q34（86:47-88:30）网格调小算力怎么办？实际碰到过吗？** → "没怎么做过轻量化操作，另外同学调整"；面试官总结"所以你做的就是满足一开始的时延指标就行了"→"对，我主要是**协助**组内开发。"（B07+B14——把对方的降格总结又签收了半句。）

### 八、RK3588 与收尾（89:06-98:41）

**Q35（89:25）RK3588 部署碰到什么问题怎么解？** → **SiLU 激活 3588 NPU 不支持→换 ReLU（原生支持、精度无明显损失）；量化掉点→混合精度（backbone int8、检测头不量化隔离），兼顾效率与精度**。✅✅ K09（算子替换）标准故事首次完整出场。深入追问"怎么决定/怎么对齐"时收尾变虚（"我对部署不是特别精通……挺久没做了"——B14，把刚立起来的牌又自己放倒了半张）。

**Q36-38 在职/离职原因/规划/老家** → 修复版动机，但这次加了句"对部署确实不是很了解、上下游接触不多"——⚠️ 诚实过头：**动机里的自我暴露要选对象**（"想拓宽"是动机，"我不了解部署"是弹药，别递给对方）。规划"感知深耕"略薄。

**Q39（96:08）反问** → 感知规模/场景/技术路线（→5 产品线、纯泊车 4 鱼眼+12 超声波、十几 TOPS、LSS 轻量化探索中、感知 20 人）。✅ 情报质量高。⚠️ 未转化：对方明说"泊车产品只有十几 TOPS"——这正是接"我在 200TOPS 上做过 85ms，轻量化手段（BEVPool 查表/混合精度/共网复用）迁到十几 TOPS 的路径是……"的时机，一句没接（B10 性质）。
