### 二、架构与路线之辩（5:41-17:30）

**Q3（5:41）障碍物检测模型架构？**

小插曲：对方说"障碍物相关的"，你先纠正"我们不检障碍物，障碍物是其他模型的，把障碍物检成行人才是误检"——对方其实是把"车辆行人3D检测"统称障碍物。🟡 过度字面化的纠正制造了 1 分钟摩擦；先顺着对方的词答，再顺口补一句术语区分即可。

正式回答：BEVFusion 系两分支——雷达支路 voxel 体素化→3D backbone→转 BEV；相机支路 2D 图像→**深度概率分布预测**→内外参转 3D 视锥→拍扁成 BEV；两者通道 concat→检测头出 3D 框/速度/动静。✅ 结构完整。

⚠️ 但深度那句的原话是："划分成一些等份，每个等份一个概率分布，**落在哪个概率最高，就预测那个距离**"——这是 **argmax 版描述**（K03）。正确机制是**按概率加权求和（soft-argmax）得到期望深度**。本场同行没抠，8 天后 0804-1512 场被抠、0805-2306 场才答对。深度分布这张卡的病根从这里就可见。

**Q4（9:33）当时为什么没用 Sparse 方案？**

现场：24 年入职时确实是 Sparse，搞了挺长时间、精度不错；但出了离谱问题——**某些帧全图目标全部消失**，没得到根解，领导拍板切到 Dense（量产要可解释性、稳定性）；LSS 计算量确实大；最近下一代感知在研讨回归 Sparse。对方分享自家 Sparse4D v3 体验，你接住并展开（15:01）：query 方式构造 BEV、不显式建深度 loss、anchor 跨帧传递、时序实例化、没有 dense 的全局 attention 所以算力反而不大。

诊断：✅✅ **Sparse→Dense 叙事的完整定型版**（0801 场只有雏形）。有事实（bug 现象）、有决策逻辑（量产求稳）、有行业判断（回归 Sparse 趋势），还接住了对方的 Sparse4D 讨论——平级技术对话的样板。⚠️ 一处红线：**"下一代在研讨回归 Sparse"是内部路线图**（B15），说"行业整体在往稀疏化走、我个人也判断如此"即可达到同样效果。

**Q5（11:56）量产到什么车上了？** → "60 个车型，**这个也有点商业机密了**……车企比如赛力斯、江淮、奇瑞、奥迪。"🟡 意识到了机密边界，然后还是列了名单（B15）——"公开发布会提过的车型有 XX"是安全句式。

### 三、难点四连讲（17:32-30:50）——本场最流畅段落

**Q6（17:32）项目难点简单说一下**

1. **误检挖掘**：三判据再讲；被追问"怎么知道它消失了？"（19:04）→ 自车周围前后左右各 5 米画区域、逐帧 IoU 匹配（阈值 0.5-0.7）、连续检出 3 帧后消失即凭空误检。✅ 防守成功，细节层次比前几场又深一层。
2. **中远距不稳**：模型（DepthNet 加深——还主动讲了"深度不准→splat 落格不准→融合受影响"的因果链）/工程（BEVPoolv2 数学等价、用内外参提前完成索引池化）/数据（叠帧+运动补偿稠密监督）。✅ 被问"CRF 什么意思？"→ Conditional Random Field、开源论文方法、目标边缘深度连续化。✅
3. **类别失衡**：CBGS 重采样+loss 加权。✅
4. **速度蠕动**：位移不足一个 BEV 格子 → L1 换 Smooth L1 + 速度-动静联合约束（速度为 0 绑定静止属性）。

**Q7（28:10）"L1 换成 Smooth L1 就有效果吗？"**

现场（对方先搭了半句台"它是 L1 和 L2 的结合吧"）：低速目标速度值本身只有零点几，**L1 在 0 附近梯度是常数，导致收敛震荡、达不到精确值；Smooth L1 在 0 附近是二次函数、梯度随误差趋近 0，小误差区间能收敛得更细**。

诊断：✅✅ **Smooth L1 的"为什么"第一次完整说对**。注意条件：对方是友好同行且先递了半句。0825-0602 场（无人搭台）才算独立复现。这段原话可直接进 K04 卡片。

**Q8（27:02）PV 辅助监督** → 3D 真值反投各相机做 2D 辅助监督、轻量头训练期专用、推理零开销。✅ 已成熟牌。

### 四、锥筒与共网（31:02-42:00）

**Q9（31:02）项目二** → 成排建模+改道框与车道线强耦合（左下/右下角卡住车道线）+三轮迭代。✅ 第四次出场全胜。

**Q10（36:22）"十多个子任务怎么判断各自收敛？"** → 各子任务先独立训练至收敛 → 并入共网 → 共网上评测、与子任务精度对比无明显恶化 → 允许合入。✅ 共网工程流程答得干净利落。

**Q11（37:25）误检问题** → 路牌相似误检→难负样本回灌；弯道/上下坡凭空误检成排锥筒→**空图负样本抑制**。✅

**Q12（39:02）数据增强**

现场：用 random crop + padding 替代 Mosaic——**理由一**：成排锥筒基本只出现在图像中央，Mosaic 把图切四份会破坏这个空间先验；**理由二**：与车端推理预处理（黑边裁剪等）保持同步，提高部署后置信度一致性。

诊断：✅✅ 这是 31 场里**最好的"为什么不用通用方案"回答**——把数据增强决策讲成了"任务先验+部署一致性"两条工程原则。这段话应该原样进弹药库，凡问增强策略都从它出发。

**Q13（40:49）成果**："IoU 0.4 下 P/R 均达 0.7。**这个 0.7 虽然看起来不高，但我们评测集是每个用例单独构造的难例集，比较能反映问题**"；方向稳定性 +7 个点；随 OTA 发版上车。

诊断：✅ **前一天 0803-1959 被"precision 0.4 能上量产车吗"打懵，今天主动带辩护词出场**——数字辩护词的价值现场验证。（两场报的数字本身仍有出入：0803 场被读出"precision 0.4"、本场自述"P/R 均 0.7"——简历原文口径需要最终统一，参数卡收口。）

### 五、数据专题（42:30-46:30）

**Q14（42:30）长尾数据+错标怎么解？** → 长尾：挖掘策略捞数据湖（未标注、按场景先挖、符合预期再送标）；**错标：模型推理反查**——预测框 vs 标注框，车用 IoU<0.1、人用中心点距离量化偏差，筛出大偏差帧 → 人工复核 → 清理或打回重标。✅✅ 错标反查的量化判据（IoU<0.1/分类别度量）是新细节，可信度强。对方连环确认后表示"你做的这些某种意义上更关键"。

**Q16（49:33）主动索评** → "工作做挺多的，**有的一下子没想起来是吗**？……都理解，主要看项目经验和理解，方案都是相通的，现在去做 Sparse 也没什么难度；我们后面主要做端到端。"你的回应："确实有些可能最近交接期，**有点忘了东西**。"

诊断（B03）：索评动作第三次使用（好习惯已成型），但又一次用"忘了"签收对方的保留意见（与 0803-1926 场同款）。**该说的是**："您说的'没想起来'具体是哪一段？我现在补——另外哪些点您觉得和贵司岗位差距最大，我可以针对性准备二面。"把评价变成补考+情报。

**Q17（50:50）端到端了解过吗？** → "策略上了解：BEV 并到端到端、一段式实现；**具体模型是另一个部门搞**。"对方好意搭台"你做的就是端到端里的 stage 1 嘛""无非是把两阶段的梯度回传打通"——你只回了"是的是的""哦，确实"。

诊断（B13）：又停在"别的部门搞"。你明明知道的部分（共网 backbone 怎么共享、感知输出怎么被下游消费、轻量化裁剪）足够撑起 2 分钟——"我在端到端的位置是 stage 1 的供给方，我能讲清接口这一侧的所有事"比"另一个部门"体面十倍。对方递的"梯度回传打通"这句话也值得接："对，难点就在两段联训时感知梯度被规控目标稀释，所以我们共网时保留了感知自己的辅助 loss——这个我有实感。"
