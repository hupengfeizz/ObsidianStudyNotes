## 逐问逐答分析

### 一、融合与盲区（0:00-5:55）

**Q1（1:00）"前向激光近距离有盲区，盲区内点云和图像的特征融合、训练策略怎么处理？"**

现场：第一遍答"不依赖雷达，用图像特征通过模型把这部分补出来"——面试官直接说"**没太听明白你说的，怎么做的？**"；第二遍："定位盲区位置 → BEV 空间里把盲区 mask 掉 → 这块屏蔽激光点云 → 多相机图像语义丰富，靠模型识别能力把盲区补出来。"

诊断（B06+K15）：
1. 第一遍是结论没有机制，被打回重讲——这是本场"细节模糊"印象的第一笔。
2. 第二遍的"mask 掉盲区"听起来像现场即兴：训练时对已知盲区做模态 mask 让模型学会"缺激光时信图像"，这个思路其实就是**模态 dropout 的空间版**——你弹药库里有现成的两阶段/模态 dropout 方案，但没有用这个语言讲。标准答法："这本质是空间上的单模态失效。训练时按已知盲区几何做点云特征的空间 dropout，逼图像分支独立成立；推理时 BEV 空间天然融合，无点云区域自动由图像特征主导；再加 PV 辅助监督保证图像分支质量。"三句话，模糊感全消。

**Q2（3:31）"针孔 LSS + 鱼眼 Transformer，两种形态的特征融合怎么做？"**

现场：LSS 支路投影到 BEV 做特征级融合；鱼眼走 attention/query 方案，不做显式深度 loss，直接构造 BEV 空间；两者在通道维 concat。

诊断：✅ 结构答对了（这是你系统的真实结构，讲得也顺）。可加一句"为什么鱼眼不走 LSS"（畸变大、深度先验差，query 方案绕开显式深度）会更完整。

**Q3（4:58）"输出动态障碍物？车道线、OCC 也输出吗？"**

现场：车道线/OCC 是另外的模型（"华为叫 GOD"，检 polygon 不规则框），BEV 检规则框；今年走端到端在共享 backbone 轻量化。

诊断：✅ 边界答清楚了。⚠️ 又一次带出内部代号与架构演进（B15 轻度）——对外统一说"占用网络/通用障碍物网络"即可，不必给代号。

### 二、时序与速度（6:05-11:10）

**Q4（6:05）"BEV 里的时序是怎么做的？"**

现场：先讲了点云叠多帧+运动补偿做稠密深度真值（这是**数据增强**，不是时序）；然后才讲到点子上：历史 BEV 特征缓存 → 用自车运动做坐标变换对齐到当前帧 → 通道维拼接 → 轻量时序网络，无循环等复杂机制。

诊断（B06）：先答岔再拉回，面试官耐心等到了正确答案，但"模糊感"又加一笔。**这题的标准开头应该一步到位**："我们是特征级时序：缓存历史 N 帧 BEV 特征，按自车 ego-motion 对齐到当前帧坐标系后通道拼接。"（10Hz+历史 2 帧 0.2s 的口径也该在这里报出——本场没报。）

**Q5（8:03）"加了时序之后，每个目标能多输出哪些信息？"** → 答了常规输出（3D 框/速度/朝向/动静）。⚠️ "多"字没接住：时序带来的增量是**速度更稳、遮挡短时记忆、朝向连续性**。半答。

**Q6（8:35）"ID 也输出吗？"** → "对，每个目标绑定 ID。" ✅

**Q7（8:44→9:36）"速度精度怎么样？——为什么是前后帧差分算的？不是模型直接出吗？"**

现场：你先说"速度是通过前后帧位置差分、除以时间戳差算出来的"；面试官立刻抓住："**这不是模型直接输出吗？为什么是差分？**"你改口："最后是直接出的，差分是 loss 那块的构造逻辑。"

诊断（K20+B04）：**被当场抓住自相矛盾**——这是本场杀伤最大的一处。真相你其实懂：模型 head 直接回归速度，**真值**由标注框前后帧差分生成。第一句话把"真值构造"说成了"推理方式"。这个知识点在 0804-2003 场被逼着讲清了一次之后才修复。标准句："速度是检测头直接回归的通道；它的**监督真值**来自连续帧标注框位置差分。所以推理单帧就能出速度，训练才需要时序真值。"

**Q8（10:07）"速度结果准吗？"** → 坦承此前问题多（速度跳变/动检静、静检动），讲了 L1→Smooth L1 的优化。✅ 诚实+有动作，但 Smooth L1 的"为什么"（大误差线性防梯度爆炸、小误差二次可精调）本场没讲——0825-0602 场才补完整。

### 三、专项五连答（11:14-17:00）——本场最强段落

**Q9（11:14）"具体解过哪些专项问题？"**

现场一口气讲了五个，全部有机制有结果：
1. **凭空误检**（栅栏误检成车/人）：挖掘策略+数据补训练集；
2. **前车蠕动被判静止**（跟车/红绿灯场景）：位移小于 BEV 网格分辨率导致 → 速度 loss 换 Smooth L1 + **速度与动静属性联合约束**（同时输出互相约束）→ 速度准确通过率 **+3 个点**；
3. **中远距检出不稳**：模型（DepthNet 加深+CRF）/工程（BEVPoolv2 数学等价省算力）/数据（点云叠帧+运动补偿稠密真值）三面；
4. **行人骑行人漏检**：占比小训练信号弱 → CBGS 类别重采样 + 类别 loss 加权，召回明显提升；
5. **PV 辅助监督**：BEV loss 回传图像端链路长、梯度弱 → 3D 真值反投各相机做 2D 辅助监督，轻量头只在训练期、**推理零开销**。

诊断：✅✅ 这 6 分钟是你全部 31 场里最完整的"问题-机制-动作-数字"连续输出之一。蠕动场景的归因（位移<网格分辨率）尤其好。**可惜它被夹在前后两段模糊回答中间**，没能扭转整场印象——顺序也是武器：如果 Q1 盲区题就用这种密度答，定性就不一样了。

### 四、量化对齐（17:03-20:55）——三连丢分

**Q10（17:03）"量化这些工作你做过吗？"**

现场："我们组有专门搞部署的……他们流程我是清楚的，我自己在开发板上也实地搞过：PTH→ONNX→华为车机的 OM 文件。"面试官："没关系，有专门做的我就问一下。"

诊断（B01 半只脚）：双层句其实说了一半（专人负责+我自己跑通过），但顺序反了、开发板经历只有半句没有细节，面试官已经开始降低期待（"没关系"）。对照 0803-1004 飞鲨场同题满分答法：先"我自己全链路跑通过（平台+四步）"，再"量产里的分工"。

**Q11（17:47→20:16）"量化损失怎么评估？——那不是量化损失，是版本性能。你们浮点团队跟量化团队怎么对齐的？"**

现场：第一遍答成量化评测集几百 case 跑精度对比；第二遍扯到 4800 条用例的版本评测被纠正"**那不是量化损失**"；第三遍问"怎么对齐"时答时延/内存增大多少，最后："这个我确实不是特别清楚，主要是部署那边同学做。"

诊断（K17+B03 边缘）：三段式滑落：答偏 → 被纠 → 裸承认不清楚。缺的就是那一句"**逐层比对**"：导出浮点/量化模型的逐层激活，对比余弦相似度/最大误差定位掉点层，再决定该层回退 FP16 或调校准集。这句话在 0805-1000、0807-0500 又缺了两次，直到进入总库 K17。

### 五、行为与反问（20:57-28:54）

**Q12（21:07）"换工作的主要原因是什么？"**

现场："上半年交付大版本强度挺大，告一段落，趁契机**换个环境、换换心情**；华为分得特别细，开发自由度不高，数据管理基本接触不到。"

诊断（B05）：**"换换心情"四个字是 31 场弱动机的原型现场**。"分工细、自由度低"其实是可用素材，但要正着说："我在最细分工的体系里把 BEV 单点做到了量产深度，现在想要的是纵向打通——数据、模型、部署一条线负责。贵司 200 人团队正在从 0 到 1 建这条线，这是我来的原因。"——同样的事实，从抱怨变成动机。

**Q13（22:26）考虑杭州吗？** → "考虑，base 无限制。" ✅

**Q14（22:39）反问环节** —— ✅ 本场反问质量是前 5 场里最高的：
问了业务形态（→L4 编队运煤+L2 高速 NOA 卖车，内蒙 300-400km 真实道路）、团队规模（→年底 200 人，团队 3 年但 3 月才扩招）、**版本收敛情况**（→动态障碍物基本收敛、鱼眼盲区在做、车道线 8 月上、OCC 已上车在测）。最后这个问题直接摸清了对方的技术进度表——**顺带解释了他为什么死磕盲区问题：鱼眼盲区正是他们当前在做的东西**。你问出来了，但没有回环："原来如此，所以您刚才问盲区——我们的方案其实可以这样迁移……"（B10 遗憾，未计码）。

**Q15（27:37）"能评价一下我吗？"→"方向匹配可以，但细节聊起来比较模糊，不确定是不是你今天比较累"**

现场回应："可能就是我今天时间有点仓促，**有点忘了**。"

诊断（B03+签收）：主动索评是对的（第二次使用），但拿到负反馈后的处理是本场最后一个失分点：用"仓促/忘了"接受了定性，等于确认"我状态好时也就这样"。**标准补救**："您指的是哪一块？盲区融合我可以现在重新讲一遍——（30 秒结构化重答）——刚才第一遍确实没讲清楚，谢谢您指出来。"当场翻盘一题，印象分能救回一半。
