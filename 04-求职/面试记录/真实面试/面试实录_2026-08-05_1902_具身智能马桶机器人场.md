进步可见：**自我介绍首次主动带上硬件部署经历**（Jetson Orin+RK 板端），挖掘逻辑和 SmoothL1 稳定输出，0.4 网格、"历史两帧"口径连场正确，Vue/Java 旧账诚实救回。失血点：C++ 内存泄漏答虚（K10）、3D 增强又只有"翻转"（K22 第三击）、"没有行业经验"的降价牌被动签收、以及"继续做感知"和"希望转具身"两句动机当场打架。**跨行业面试的主线任务是迁移论证，这场一分钟都没花在上面。**

## 逐问逐答分析

### 一、系统组基建扫射（2:19-14:45）

**Q1（2:19）用什么操作系统？车上是什么系统？ROS 吗？** → Windows 日常+Ubuntu 工作站 ✅；**车上系统"确实不是很了解，没怎么接触硬件"**。⚠️ 半空——你至少知道车机是 MDC 平台（其上是华为自研车载 OS），一句"车端跑在 MDC 的实时系统上，我在模型侧对接它的推理运行时，系统层没深入"就体面得多。对一家"算法必须懂硬件"的机器人公司，这是第一印象题。

**Q2（3:36→4:37）工作站显卡多少 G？什么型号？"不会是 A100 吧？"** → 32G 显存 ✅；型号"记不清……也是英伟达的"；顶住了 A100 的诱导（"比 A100 算力弱，本地跑评测用"）。⚠️ 半分——顶住诱导值得肯定（对照 0804-1601 "A100 好像我记得"的翻车），但"记不清型号"仍是 K05 训练页的一角（V100/RTX A 系列，一个词的事）。

**Q3（5:04→5:50）Orin 部署了什么？TensorRT 直接部署？这块是自学的吧？** → BEVFusion 开源模型、照教程处理 bug 跑通、"业余学习"；工作里部署归同学、车机是 MDC610/630。✅ 双层句+诚实边界，处理得当。

**Q4（11:32）C++ 内存泄漏怎么排查、怎么规避？智能指针循环引用？**

现场："通过代码排查、梳理逻辑、尽量不用容易泄露的操作、不使用循环引用……写法规范。C++ 我们在训练这块用得比较少。"

诊断（K10）：全是"态度"没有"工具"。标准三层：**排查工具**（valgrind/ASan 跑一遍直接定位；生产环境看 RSS 增长曲线+tcmalloc heap profile）；**规避机制**（RAII——资源生命周期绑对象；new/delete 不裸用，统一 unique_ptr/shared_ptr）；**循环引用专答**（shared_ptr 互指导致计数永不为零 → 弱侧改 **weak_ptr**，访问时 lock() 提升）。三层共 40 秒，K10 卡片就这一页。

**Q5（12:54）Vue/前端做过项目吗？** → 读研时 Java Spring Boot+Vue 做过、挺久了；现在评测看板用 streamlit。✅ 简历"全栈"旧账诚实救回，还带了当下的替代实践——旧技能的标准答法。

**Q6（13:49）Git 常用指令？** → add/commit/push/clone -b/branch/checkout。✅ 及格。🟡 收尾那句"主要是一些基础单词吧"是多余的自贬（B14 计入综合）——答完就停。

**Q7（15:08）做过三维场景的数据增强吗？**

现场："BEV 一般就是对图像做翻转这种，没有过多再细的增强"；2D YOLO 里 Mosaic/random crop 用得多；被追问其他模态后补了点云稠密化（历史两帧+运动补偿）当作增强。

诊断（K22 第三击）：**"3D 增强=翻转"这句已经连丢三场**。清单卡（K22）四层背熟：图像层（翻转/裁剪/色彩，与点云同步变换）、点云层（全局旋转平移缩放、**GT-Aug 目标粘贴**——把真值库里的目标插入场景，3D 检测最有效的增强）、BEV 层（网格级旋转翻转与标注同步）、约束（多模态几何一致性是底线）。点云稠密化救场思路对（✅），但它是"真值增强"不是常规增强，说清定位更好。

**Q8（17:17）自己写过算子吗？** → 没搞过算子优化，量化部门开发、拉通修复。⚠️ 边界诚实（B01-lite），可补 RK3588 上"换等价算子绕过"的亲历一句——你有，就是没连上。

### 二、技术复核（6:32-11:10）

**Q9（6:32）突现突消和两个难点（纹理相似/负样本稀缺）的联系？** → 完整闭环：纹理相似是误检根因、难例占比小所以要定向挖掘、挖掘逻辑（自车周围 5-10 米预置框+IoU 匹配+超 3 帧+高置信）→送标回灌。✅ 该题历史最顺版本。

**Q10（9:36）SmoothL1 是实验测的还是有理论依据？** → 双轨：评测现象（低速误静/跳变）+机理（位移不足 **0.4 网格**、L1 零点附近精度不够→SmoothL1 收敛更细）+联合约束。✅ 0.4 口径连场正确。🟡 "L1 是整数的损失函数"这个表述连用三场了——改成"L1 在零点附近梯度恒为 ±1"。

### 三、动机与待遇（18:15-24:00）

**Q11（18:15）后面的想法/职业设想？**

现场："基本还是继续做感知，2D 和 3D 目标检测这块。"——两分钟后听完对方介绍（具身智能/VLA/马桶清洁机器人）又说："VLA 确实比较火，**也希望能转到具身这一块领域吧**。"

诊断（B05）：前句是给智驾公司的答案，后句是临场跟风——两句叠在一起就是"没想好"。**跨行业面试的动机必须提前定制**："我的感知能力（检测/多模态/数据闭环）是底座，具身是我认定的下一个落地场景——原因一二三。"哪怕就一句，也比"继续做感知+也希望转具身"的拼盘强。

**Q12（20:53）正岗还是外包/车内还是车外？** → 正编、车外传感器+检测框投屏。✅

**Q13（22:16）待遇需求？——"主要是你没有行业经验。"**

现场：35-40K → 对方："我们这行薪水不低，但**主要是你没有行业经验**……跨度还是有差的。"你："哦，是的。"随后对方又说"华为分的太细了，可能别的智驾会好一点"，你："好，是的是的。"你还自己补了句"我这个任务**不算是一个完全链路的**"。

诊断（B15×2+B10+B14）：
1. 🔴 "没有行业经验"是**降价牌**，不是事实陈述——它可以被当场反击："行业经验分两层：马桶识别的数据我确实没有，但**多传感器标定、检测模型量产、数据闭环、板端部署**这四样在机器人上一模一样，而这四样才是招人时最贵的部分。领域数据三个月就能补，工程体系三年都未必建得起来。"一句不说，等于承认自己该打折。
2. 🔴 "不算完全链路"是主动递刀（B14）——同一件事的正确说法是"感知这段链路我是完整的，规控在隔壁部门"。
3. "华为分太细"的降格评论又签收了一次（0805-1829 同款钩子，两小时内第二次）。
