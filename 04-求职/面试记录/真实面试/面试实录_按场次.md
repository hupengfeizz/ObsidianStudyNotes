## 二、⭐ 最重要的一张表：分数不解释结果

> **你手上现在有一个天然的对照实验。**

| 场次 | 公司要的核心能力 | 你有没有 | **有没有打出来** | 评分 | 结果 |
|---|---|---|---|---|---|
| **0824-0458 劢微一面** | 训练 + 部署全栈 | ✅ 有 | ✅ **打了** | 42 | ✅ **过了** |
| **0825-0359 劢微二面** | 全面的模型落地能力 | ✅ 有 | ✅ 一面已建立 | 48 | ✅ **过了** |
| 0825-0200 清扫机器人 | 训练 + 部署全栈（**需求几乎一模一样**） | ✅ 有 | ❌ **「部署有其他同事负责」** | 44 | 大概率没过 |
| 0825-0304 数据工具组 | 数据生产工具 / 评测体系 | ✅ 有（很强） | ⚠️ 讲了但没连到岗位 | **52** | 悬 |
| 0825-0602 港口 IGV | BEVFusion 迁移能力 | ✅ 有（最强匹配） | ⚠️ 问出来了但没转化 | **55** | 悬 |

### 三条结论

**① 分数衡量「你这场发挥得怎么样」，不衡量「你能不能拿 offer」。**
42 分的一面过了，55 分的那场悬着。决定结果的是**「这家公司要的那张牌，你有没有正好打出来」**。

**② 0825-0200 是最可惜的一场。** 那家公司的需求和劢微几乎一模一样（小团队、要全栈、要能把模型压到板子上），你在劢微打了这张牌所以过了，在那家没打所以没过。**同一张牌，同样的需求，不同的结果。**

**③ 你失败的原因不是能力不够，是「在需要那张牌的时候没有把它打出来」。**
这是一个**表达问题**，不是**能力问题**——所以修复成本极低，收益极大。

### 👉 每场面试前 5 分钟必做的一件事

> **写下：「这家公司最可能要的那张牌是什么？」**
> 从公司规模、产品阶段、JD 推断。然后**决定这场无论如何都要把这张牌打出来**，哪怕要主动创造机会。

| 公司类型 | 识别信号 | 该强调什么 |
|---|---|---|
| **务实型**（劢微、清扫机器人、港口 IGV） | 「已经量产」「卖给客户」「不做 demo」「落不了地不做」 | 量产约束、评测准入、部署落地、时延内存零增长 |
| **探索型**（无人机端到端、部分人形公司） | 「我们在探索」「刚立项」「想尝试新架构」 | 技术判断力、对前沿路线的看法、快速试错经历 |
| **平台/工具型**（数据工具组） | 「我们提供工具」「产品化」 | 评测体系、数据挖掘、自动化判据 |

## 五、下一场之前必须完成的（全场次待办并集）

### 🔴 今天（每条 10–30 分钟）

- [ ] **改简历**：「精通 Docker」→「熟悉」或删除。**并把所有「精通/熟练掌握」逐条自查降级**——标准是「这一项最基础的三个问题我答得出吗」
- [ ] **背「部署卡片」**：只要出现「部署 / 上板 / 量化 / 芯片 / 落地」任一关键词，整段说出来
  > 「量产集成有专门的部署组，**但我自己是从部署做起来的**——实习期在 Jetson Orin 上跑 PyTorch→ONNX→TensorRT，RK3588 上跑 RKNN，包括量化、算子替换、板端调优，都是自己啃的，没人兜底。到了 BEV 项目上性能这条线一直是我在扛：所有结构改动都在『时延不涨、内存不涨』的约束下做，最后**时延降 1.1ms、内存零增长**，精度全部正向。」
- [ ] **背「容器 vs 镜像」**：镜像是只读模板（分层文件系统），容器是镜像的运行实例（镜像 + 可写层 + 独立进程/网络/挂载空间）。**类比：镜像是类，容器是对象。**
- [ ] **背「YOLOv5 标签分配」**：宽高比匹配（`max(GT/A, A/GT) < 4.0`）替代 IoU 匹配 + 跨网格扩展（中心格 + 最近两个邻格）+ 三层各自独立匹配。目的是扩充正样本、缓解正负不平衡
- [ ] **背「YOLOv5 loss 三项」**：box = CIoU（重叠 + 中心距离 + 宽高比）/ objectness = BCE 且回归目标是预测框与 GT 的 CIoU（让置信度和定位质量对齐）/ cls = BCE 独立多标签。三层的 obj loss 还有各自权重（4.0 : 1.0 : 0.4）
- [ ] **背「标定误差」**：外参角度误差要求 0.1° 量级、平移厘米级；**0.1° 在 100 米处 = 17 厘米**，所以对近距影响小、对远距致命；模型侧三层应对 = 投影可视化诊断 / 外参扰动增强 / 在线补偿；**标定会随时间漂**
- [ ] **口径固化**：Orin/MDC 上**纯推理 85–90ms，端到端 110ms 以内，对齐 10Hz**。一次把两个数都给出来

### 🔴 本周（表达训练，比知识更重要）

- [ ] **「不完全是」反射训练**：找人（或自己录音）10 分钟，让对方**故意用错误的方式总结你的每一句话**，你每次都必须先说「不完全是 / 大方向对，但有一点要补」再推进
  | 触发句式 | 第一反应 |
  |---|---|
  | 「我可以这么理解吗……」 | 「不完全是，我补充一下——」 |
  | 「所以就是……对吧？」 | 「大方向对，但有一点得说清楚——」 |
  | 「那就相当于……」 | 「相当于是这样，不过关键差别在——」 |
  | 「你们是不是……都是别人在做？」 | 「不是，这块是我自己做的——」 |
- [ ] **「三步走」方案模板**（应对「给到你会怎么做」，不得少于 2 分钟）：
  **先说我不会怎么做 → 一两个月做什么 → 三到六个月做什么 → 六个月后做什么 → 反问节奏对不对**
- [ ] **「反问必须输出判断」**：句式固定 —— 「明白了。那这样的话我的判断是 ——（一句结论）。因为（一句理由）。」一场做 2–3 次
- [ ] **「第一句话主语必须是我」**：团队背景放第二句且不超过一句
- [ ] **「记不清」三步法**：给量级 → 给约束条件 → 给我从这件事学到什么。**永远不要停在「记不清」**
- [ ] **「不会的题」三段式**：我离它有多远 + 我有什么可迁移 + 我打算怎么补
- [ ] **超过 90 秒的技术回答，先给「三件事」目录，讲完问一句「要不要展开哪一个」**
- [ ] **动机替换**：❌「想成长快一些」→ ✅「**我知道根因在哪但我动不了它**」+ 具体例子（泊车凭空误检 = 标注口径问题，提单要两三周）+「**我很清楚小团队的代价，而且实习时经历过**」

### 🟠 本周（知识补齐）

- [ ] **自车运动补偿完整版**（已出现 5 次）：
  ① 单帧内**逐点去畸变**（机械式转一圈 100ms，按每点时间戳插值自车位姿）

## 七、劢微 offer：接之前要确认的四件事

> 详见 [[面试实录_2026-08-25_0359_劢微机器人二面综合面#六、拿到-offer-之后该怎么办]]

1. **「我进来第一年的主要工作，是叉车感知还是人形 VLA？比例大概是多少？」**——面试官明说「叉车车载感知比较完整了，能做的东西比较少，**更多人力投入会在人形这一块**」，这决定了你一年后在市场上的标签
2. **「VLA 那条线现在有几个人？我进来是加入还是从零建？」**
3. **「叉车这条线，你们判断未来还有多大技术投入空间？」**
4. **「地平线 160T 那个平台的迁移什么时候做？谁来做？」**——这是你能立刻贡献的地方（换平台 = 算子支持面变化，你踩过坑），**主动接下来是快速建立价值的最好方式**

**关于「这家考核比较简单」**：
- **不要低估这个 offer**——务实、有真实营收、产品在客户现场跑、正在往高增长方向投人。「考核简单」往往只是招聘流程还没工业化
- **不要高估自己在其他公司的胜算**——劢微的通过来自「你恰好打出了那张牌」，不是「你的面试表现已经过关了」
- **最理性的做法**：把这个 offer 当底牌拿着，同时把剩余面试当真刀真枪去打。**有底牌的人在面试里的状态会明显更好**

## 附：旧版两场对比（08-21 普渡 vs 优奇，保留）

| | 08-21 14:00 普渡科技 | 08-21 18:00 优奇智能 |
