# 简历知识点全清单（自评用）

## 怎么用

- **按知识领域组织**，不是按项目——因为很多点跨项目重复，按领域能去重、看清知识结构。想按项目复习时，配合《两周学习计划》一起用。
- **勾选框做自评**：`[x]` = 能讲清且扛得住追问；`[ ]` = 待复习。
- **标记含义**：
  - `【前置】` = 简历没直接写，但要理解上面的技术必须先有的基础（你是跨专业过来的，这层尤其要盘一盘）。
  - `【了解】` = 简历里标了"了解"级，门槛低，能讲一段 + 说清和主线区别即可。
  - `⭐` = 项目一核心 / 高频被问 + 你自述薄弱，最高优先级。

## 盘点小结

整份简历大致覆盖 **15 个知识领域、约 130+ 个知识点**。其中：

- **最高优先（⭐，约 25 项）**：集中在 F（相机几何）+ G（BEV）+ 项目一相关损失/评测。这是你自述薄弱、又最高频被问的地方，两周复习的主战场。
- **前置基础（【前置】）**：B、部分 F/N。跨专业过来的话，这层若不牢，上面的技术会"背得出、讲不透"，建议先自评一遍。
- **了解级（【了解】）**：G 里的前沿清单 + H 的 VoxelNet。保持能讲一段即可，别投入过多。
- **低相关（O）**：读研背景，确认自己能讲清就行，不必深挖。

建议先花半小时把整张表过一遍、把 `[ ]` 里你心里没底的标出来，就能立刻看到缺口分布——大概率会集中在 F/G 两块，正好和学习计划的 Tier 0–2 对上。
