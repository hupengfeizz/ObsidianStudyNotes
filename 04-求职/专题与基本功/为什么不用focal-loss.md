# 为什么不用focal-loss

**Focal Loss 是一种改进版交叉熵损失**，主要用来解决 **类别不均衡** 和 **简单样本太多** 的问题。

普通二分类交叉熵是：

```
CE = -log(p_t)
```

其中 `p_t` 表示模型对真实类别的预测概率：

```
如果真值是 1，p_t = p
如果真值是 0，p_t = 1 - p
```

Focal Loss 在 CE 前面乘了一个调制因子：

```
FL = - α · (1 - p_t)^γ · log(p_t)
```

核心就是这一项：

```
(1 - p_t)^γ
```

它的作用是：**降低简单样本的权重，强化困难样本。**

比如：

```
简单样本：p_t = 0.99
(1 - p_t)^2 = 0.0001
loss 被压得很小

困难样本：p_t = 0.5
(1 - p_t)^2 = 0.25
loss 还保留较大

错分样本：p_t = 0.1
(1 - p_t)^2 = 0.81
loss 基本保留
```

所以 Focal Loss 的直觉是：

```
模型已经很确定、分对的样本 → 少学一点
模型不确定或分错的样本 → 多学一点
```

它最早常用于目标检测，比如 RetinaNet，因为检测里负样本特别多：

```
大量背景 anchor / grid 是 easy negative
少量前景目标是 hard positive
```

如果用普通 CE/BCE，训练会被大量简单背景样本淹没。Focal Loss 就通过降低 easy sample 的权重，让模型更关注困难样本和少数正样本。

------

你文档里说“不用 Focal Loss”的语境是 **继续训练一个已经收敛得不错的模型**。

这时很多样本都已经：

```
p_t > 0.9
```

如果 `γ = 2`：

```
(1 - 0.9)^2 = 0.01
(1 - 0.99)^2 = 0.0001
```

梯度会被大幅压低，训练就可能变得很慢，甚至像“不动了”。

所以一句话：

**Focal Loss 是“让模型少管简单样本、多管困难样本”的交叉熵变体；它适合类别极不均衡、简单负样本很多的检测训练，但在高置信度模型上继续微调时，可能把整体梯度压得太小。**
