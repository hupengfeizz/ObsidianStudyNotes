## 一、Linux / 命令行性能排查　【8/4 全空，最高优先级】

### 被问「程序一直在跑，怎么看它的状态、怎么找瓶颈」——分四层答

**第一层 · 先看进程整体**

```bash
top                  # 实时看 CPU / 内存占用，找到 PID
htop                 # top 的增强版，能看每个核、能翻页、能直接 kill
ps aux | grep python # 找进程 PID
```

看什么：CPU 是不是打满一个核（说明单线程计算密集）、内存是不是持续涨（可能内存泄漏）、进程是不是在 D 状态（卡在 IO）。

**第二层 · 看进程在干什么**

```bash
py-spy top --pid <PID>       # 不用改代码、不用重启，直接看 Python 进程当前在哪个函数上
py-spy dump --pid <PID>      # 打印当前调用栈
py-spy record -o out.svg --pid <PID>   # 生成火焰图
```

**`py-spy` 是这类问题最标准的答案**——它能挂到一个已经在跑的进程上采样，不需要提前埋点。被问「程序已经在跑了怎么办」，说这个就对了。

**第三层 · 代码级 profile（能重跑的话）**

```bash
python -m cProfile -s cumtime script.py    # 函数级耗时排序
python -X importtime script.py             # 看 import 慢在哪
```

```python
import cProfile, pstats
cProfile.run('main()', 'prof.out')
pstats.Stats('prof.out').sort_stats('cumtime').print_stats(20)
```

内存：`memory_profiler` 的 `@profile` 装饰器逐行看内存；`tracemalloc` 看内存分配来源。

**第四层 · GPU / 系统级**

```bash
nvidia-smi              # GPU 利用率、显存
nvidia-smi dmon         # 持续监控
nsys profile python x.py    # Nsight Systems，看 GPU kernel 时间线
py-spy / torch.profiler     # PyTorch 训练的算子级耗时

iostat / iotop          # IO 瓶颈
strace -p <PID>         # 看系统调用（卡在哪个 syscall）
```

### macOS 上的对应物（8/4 被问到「苹果上会用吗」）

```bash
top                     # 一样能用
活动监视器               # 图形界面
sample <PID> 10         # 采样 10 秒，输出调用栈（macOS 自带）
instruments             # Xcode 的性能分析工具
```

Python 的 `py-spy`、`cProfile` 在 macOS 上一样能用，跨平台。

### 一句话总结版（被追问时先说这句）

> 先用 top 或 htop 定位是 CPU 密集还是内存问题；如果是已经在跑的 Python 进程，用 py-spy 挂上去看它当前卡在哪个函数，不需要重启；能重跑的话直接 cProfile 出函数级耗时排序；GPU 的话看 nvidia-smi 和 torch.profiler。

## 二、斐波那契：从递归到优化　【8/4 的手撕题】

### 朴素递归（面试官要求的写法）

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

**复杂度 O(2ⁿ)**，空间 O(n)（递归栈深度）。

n=30 约一百万次调用，秒级；n=40 约一亿次，十几秒；**n=50 约一百亿次，要几十分钟到几小时**——这就是 8/4 现场卡住的原因。

**被问「为什么这么慢」**：递归树里同一个 `fib(k)` 被重复计算了指数次，比如 `fib(50)` 会算 `fib(48)` 两次、`fib(47)` 三次……重复子问题没有被复用。

### 优化一 · 记忆化（改动最小）

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

**O(n) 时间，O(n) 空间。** 一行装饰器，n=50 瞬间出结果。手写版：

```python
def fib(n, memo={}):
    if n <= 1:
        return n
    if n not in memo:
        memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]
```

### 优化二 · 迭代（最优，且没有递归深度限制）

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

**O(n) 时间，O(1) 空间。** 面试时如果没限定必须递归，直接写这个。

### 优化三 · 矩阵快速幂（体现算法功底）

```python
def fib(n):
    def mat_mul(A, B):
        return [[A[0][0]*B[0][0] + A[0][1]*B[1][0], A[0][0]*B[0][1] + A[0][1]*B[1][1]],
                [A[1][0]*B[0][0] + A[1][1]*B[1][0], A[1][0]*B[0][1] + A[1][1]*B[1][1]]]
    result, base = [[1, 0], [0, 1]], [[1, 1], [1, 0]]
    while n:
        if n & 1:
            result = mat_mul(result, base)
        base = mat_mul(base, base)
        n >>= 1
    return result[0][1]
```

**O(log n)。** 原理：[[F(n+1), F(n)], [F(n), F(n-1)]] = [[1,1],[1,0]]ⁿ。

### 现场应对模板

写完朴素递归后**主动说这段话**，不要等被问：

> 这是朴素递归，复杂度 O(2ⁿ)，n 稍大就不可用，因为存在大量重复子问题。生产上会用记忆化降到 O(n)，或者直接迭代做到 O(n) 时间 O(1) 空间；要 O(log n) 的话用矩阵快速幂。另外 Python 默认递归深度限制是 1000，n 大了会栈溢出，这也是递归写法的实际限制。

**主动指出自己代码的局限，是加分项。** 8/4 那场是等到 n=50 跑不动了才被动应对，效果完全不同。

### Python 递归深度

```python
import sys
sys.getrecursionlimit()      # 默认 1000
sys.setrecursionlimit(10000) # 可调，但有栈溢出风险
```

## 三、其他高频手撕题（感知岗常考）

| 题 | 要点 |
|---|---|
| **IoU / GIoU / DIoU** | 感知岗第一高频。注意边界情况：无交集时返回 0、除零保护 |
| **NMS** | 按分数排序 → 取最高 → 抑制 IoU 超阈值的 → 重复。会写 soft-NMS 更好 |
| **旋转框 IoU** | BEV 岗特有，多边形求交，可以说思路不必写全 |
| 二分查找 | 注意左右边界与死循环 |
| 快排 / 归并 | 说得清复杂度和稳定性 |
| 链表反转、环检测 | 快慢指针 |
| 手写 Conv2d / BN | 深度学习岗常考，考对维度和计算的理解 |

**IoU 建议提前写熟**，这是感知岗被考到概率最高的一道：

```python
def iou(box1, box2):
    # box: [x1, y1, x2, y2]
    x1 = max(box1[0], box2[0]); y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2]); y2 = min(box1[3], box2[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    a1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    a2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = a1 + a2 - inter
    return inter / union if union > 0 else 0.0
```
