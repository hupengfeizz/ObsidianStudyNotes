## 2.2 整合学习方案

这四节课本质上是**同一个东西的四个切面**(概念 / 数学 / 反传 / 代码),老师按时间线排课导致内容被切碎且重复铺垫多。因此采用**整合讲义**方式,主线按"从一个神经元长成一个可训练的网络"重组:

```
 1. 一个神经元          z = w·x + b,  a = σ(z)                    [3_1]
 2. 一层(标量写法)     z₁ = w₁₁x₁ + w₁₂x₂ + ...                  [3_1]
 3. 向量化              z = Wx + b                                 [3_4]
 4. 批量化              Z = XW + b,(B,in) @ (in,out) → (B,out)   [3_4]
 5. 多层堆叠 + 激活      完整前向传播链路                            [3_1+3_4]
 6. 损失函数            输出 → loss                                 [已学]
 7. 反向传播 ★          链式法则,逐层回传                           [3_8]
 8. 参数更新            W -= lr · dW                                [已学]
 9. PyTorch 实现        nn.Module / autograd / optim               [3_6+3_5]
10. 工程封装            套进 zgtorch 的类框架                       [已学 2_8]
```

**这条线的终点 = 一份完整的手写 MLP**,每一步都能和代码对上号。

**执行方式**:先出整合讲义 → 拿着讲义倍速刷视频,只在讲义标「必停」处停 → 做编码任务。
