# 🤖 AI 协作约定（给任何新对话读的）

> 新对话开始时把这篇贴给 AI，或者说一句"先读 `00-Index/AI协作约定.md`"。

## 库在哪

- Obsidian vault：`/Users/apple/Documents/36/study_doc_Obsidian/`
- 原始文档：`/Users/apple/Documents/简历/`（简历、面试准备材料、面试记录等）
- vault 里**只放 Markdown**。每篇笔记开头的 `source` 属性写着它最初转换自哪个文件（仅作溯源，那些文件已不再更新）。

## 正本是 vault 里的 md，不再维护 docx

- **求职与学习材料的正本 = vault 里的 `.md`**。要改内容，直接改 md（人改或 AI 改都行）。
- `简历/` 目录下的 docx / pdf 是 2026-08-21 之前的历史版本，**不再更新、不再反向同步**。需要打印或外发时，从 md 导出 PDF（Obsidian「导出为 PDF」），导出物随用随删。
- 唯一例外：简历本身（`胡鹏飞简历`）投递时仍需 docx/pdf，投递版以 `简历/简历最终版/` 里的文件为准，改完简历后把 vault 里的 `胡鹏飞简历.md` 也更新一份。
- 改 md 时的规则：
  - **不要整篇覆盖**，在原文上增删——用户可能在文中做了 `==高亮==`、`> 💬` 批注或 `%% 备注 %%`，必须保留
  - 保留开头的 YAML 属性（title / type / project / tags / source），只更新 `updated` 日期
  - 文件名不变，否则双链会断
  - 新增的问答按原有结构放进对应主题下，用同样的 `## Q · …` 标题格式

## 结构约定

| 文件夹 | 放什么 |
|---|---|
| `00-Index` | 首页、求职总览、本文 |
| `01-学习计划` | 计划与路线图 |
| `02-课程资料` | 课表 |
| `03-技术笔记` | 题库、任务思路、实验记录 |
| `04-求职/<子文件夹>` | 简历与自我介绍 / 项目一～四 / 专题与基本功 / 错题本 / 策略与计划 / 面试记录 / 面试日程 |
| `05-学习日志` | 每日笔记（自动） |
| `90-附件` | 少量必须放进来的图片 |
| `99-模板` | 模板 |

- 新建笔记放进对应文件夹并在 [[首页]] 或 [[求职总览]] 补一行链接
- 每篇开头必须有 YAML 属性：`title` `type` `tags` `updated`，求职类加 `project`，转换来的加 `source`
- 面试邀约 → 写进 [[面试日程]] 并生成 `.ics`（不带时区的本地时间）
- 面试记录用 [[99-模板/面试记录模板]]，文件名 `MMDD-公司-轮次`，放 `04-求职/面试记录/`
- 单文件不要超过 5 MB（Obsidian Sync Standard 的上限）；大图大 PDF 不进库
- 不删除任何原件；要清理的东西移到同级 `_to_delete/` 里由人来删
